## 0. 总纲（先说清"要推翻什么"）

1. **不要盲目复用现有 UI 素材**。现在那批（`Assets/resources/UI/InkUI/`）是**静态贴图**，
   能撑住"看起来像水墨"，但**撑不住动效**。本文件里点名的部件要**按动效需求重新出图**（分层：底/遮罩/序列帧/粒子贴图）。
2. **动效必须统一到四个隐喻**：**落笔**（出现）、**晕开**（选中/点击反馈）、**提笔**（离开）、**干笔**（禁用）。
   凡是"淡入淡出 + 缩放弹跳"的写法一律不要（那是通用 UI 动效，不是水墨）。
3. **每个页面都要有"主角元素"**：父幕布的**墨点群**、背包的**包裹**、境界的**墨圈**、神通的**星图**、战阵的**九宫**。
   其余元素是配角 —— 这是"贴图感"消失的关键（见 §10）。
4. **动效一律可跳过/可关闭**；时间与曲线按 §9.3 的常量表；面板开着时 `timeScale = 0`，**所有等待用 `unscaledDeltaTime`**。
5. **功能一个都不能丢**：每页下面的"功能口径"是硬约束（数据入口、互斥规则、上限、存档字段都不许改）。

## 1. 父幕布 = 8 个子页面的引导（`图1-父幕布.png`）

**布局**：8 个墨点**错落**落在屏幕左侧一列（不是等距排列，要有疏密与大小变化，像溅上去的 8 滴墨）；
每个墨点**中间是功能图标**、**下方是功能名**（背包/境界/神通/法宝/灵阵/战阵/坐骑/外观）。

**动效（这是整个 UI 的"门面"，最要紧）**：

| 交互 | 效果 | 实现要点 |
|---|---|---|
| 常态（**时刻物理流动**＝用户原话） | 墨点**持续像墨在纸上缓慢流动**：位置用**弹簧-阻尼**跟随一个缓慢游走的目标点（每颗相位/种子不同，位移 ≤3px，周期 4~7s），**形状也做低频噪声形变**（边缘微微鼓/缩） | ⚠️ **不能用一条正弦代替** —— 用户要的是"时刻物理效果流动"，正弦只是"晃"不是"流动"。位置：`Mathf.SmoothDamp`（一阶滞后）追漂移目标；形状：`UIInkMotion` 给墨点遮罩加低频噪声偏移（沿法线 ±1~2px）。**种子用确定性哈希**（用 `Random` 会每帧乱跳） |
| 鼠标靠近 | **原地牵引**：墨点朝鼠标方向偏移（最大 6~10px，距离越近越大），松手回弹（`EaseOutCubic` 0.22s） | 位移按"鼠标与该点距离"衰减；**不要**整体位移、不要缩放 |
| 鼠标划过 | **墨水被划过的流动特效**：沿划过方向在墨点上刷开一道**更浓的水痕**（0.25s 内出现→淡掉） | 一张可旋转的"水痕"贴图 + 沿鼠标速度方向拉长；浓淡由速度决定 |
| 鼠标点击 | **墨晕开**：以点击点为心，墨色向外扩散一圈（0.3s）+ 墨点短暂变浓后回正 | 复用 `fx-ink-blot` 做涟漪；扩散用 mask/radial fill |
| 选中态 | 该墨点**墨色更浓 + 下方名字加深**，并在点下方留一小横笔（"落款"感） | 不要发光、不要描边加粗 |

**要出的新素材**（提示词见 §7-①）：
- `nav-ink-blot-1..8.png`：8 颗**大小/形状各异步**的墨点（中心留空给图标，边缘自然、可带飞白）；
- `fx-water-streak.png`：划过时那道**水痕**（横向，一端浓一端淡）；
- `fx-ink-ripple-6f.png`：**墨晕涟漪**序列帧（6 帧，240×240，从实心小圆扩到中空大环）。

## 2. 背包（`图2-背包.png`）

**布局**：左侧仍是父幕布引导；中间**包裹**（点开时出现在红圈位置）；物品从包里**飞出来在右边散布**；
右侧是**物品介绍框**（灰框）。

**动效**：
1. **点开背包**：包裹**落笔**出现（0.18s）→ **包裹打开**（序列帧 8~12 帧，0.3s）→ 物品**沿弧线飞出**、在右侧落位（每件错开 40ms，`EaseOutCubic`，落位时各来一次小墨晕）。
2. **物品网格**：鼠标**经过附近**→ 最近的 1~3 件物品有**原地牵引**（6px）；**划过**→ 该件**放大 1.15×**（0.14s）并弹回；
3. **选中**→ 右侧介绍框**落笔**刷新（不要整块重绘动画，只淡入换字）。
4. **滚轮**：物品往上滑，**循环瀑布流**（滑到底接回顶部）；滚动时网格边缘叠一层"墨流"（见素材）。

**素材**（§7-②）：`bag-parcel-close/open.png`（包裹两态）+ `bag-parcel-open-8f.png`（开包序列帧）；
`fx-ink-flow-loop.png`（可循环的竖向墨流，滚动时叠在网格上，α 0.12）；
物品图标沿用数据侧 `DisplayIcon`（**不改数据**）。

**功能口径（不许丢）**：走 `UIEntryList` / `UIEntryInfo` / `UIPanelData`；单击选中→右侧详情；
**使用后数量要同步**；不依赖颜色区分用途；大量物品要对象池/虚拟化。

## 3. 境界（`图3-境界.png`）

**布局**：中间**红圈**= 当前境界 + 修炼功法；左侧**半圆形**包围墨圈的属性信息；下方是**境界展示**信息
（可以用**不规则异形的墨水幕布**当底）。

**动效**：
1. **点开**：**墨水画一个圈**——一笔从起点顺时针"画"出圆形（0.6~0.9s，笔尖带浓淡与飞白），
   画完**墨圈轻轻一抖**定住 → 圈内**落笔**显示"炼气第 N 层"+ 当前功法名。
2. **左侧属性**：沿半圆**由下往上**逐条落下（每条错开 40ms），像一行行写上去；数值变化用**滚动 0.2s**。
3. **下方展示**：异形幕布**卷开**（0.26s），内容淡入。
4. 鼠标划过属性行 → 该行**墨色加深 + 左侧短笔延长**（0.12s）。

**素材**（§7-③）：`fx-ink-circle-12f.png`（画圈的 12 帧序列，1400×1400，**中空**）；
`panel-ink-blob.png`（不规则异形的墨色幕布 9-slice）；属性行底直接用 §4 的 `row-*`。

**功能口径**：境界条要**真的显示填充**（顺手修 `RealmShow/Fill` 的 `sprite=null` bug）；
只展示，**不改修炼逻辑**（修炼仍在洞府设施里）。

## 4. 神通（`图4-神通.png`）—— **紫色=星象图，红色=神通瀑布流**

**布局**：紫色区 = 一张**带透明通道的星象图**，图上有**六个明显空位**（细线画出来、中间粗略相连）；
红色区 = 已掌握神通的**瀑布流**；最右 = 神通信息。

**动效**：
1. **点开**：星图**落笔**淡入（0.3s，星点错开亮起）→ 六个空位**细线依次画出**（每格 60ms）。
2. **星图**：小星星**原地牵引**（鼠标靠近偏移 ≤5px）；鼠标划过空位 → 该空位**高亮**（细线变浓 + 微弱粒子）。
3. **瀑布流**：同背包的循环瀑布流；滑过某条神通 → 放大 1.1× + 显示品阶牌。
4. **装备到星位**：从瀑布流**拖**到空位 → 落入时**墨晕脉冲** + 星位**高亮粒子**；
   ⚠️ 这个高亮粒子**同样要有"鼠标从附近经过时的原地牵引"**（用户原话点名："装备上后星位会有高亮的粒子特效
   **伴随着鼠标从附近经过时的原地牵引效果**"）—— 即：粒子既持续微亮，又随鼠标靠近而偏移（≤5px，松手回弹）。
   被动神通装备后**在星图某处随机点亮一个小粒子**（不占星位，同样有牵引）。
5. **点击**星位粒子或瀑布流条目 → 最右**落笔**显示神通信息（大图 + 品阶 + 灵气/冷却）。

**素材**（§7-④）：`fx-star-map.png`（星象图，**透明底**，2048×2048，六空位 + 细连线 + 星点）；
`fx-star-particle.png`（星点/粒子，128×128，软边）；`fx-ink-pulse.png`（墨晕脉冲，复用 `fx-ink-blot`）。

**功能口径**：六槽**固定 0–5**、快捷键 1–6 不许改；拖拽装备走 `EquipToSlot`（拖入占用位**会覆盖**是现状）；
**被动不能拖进主动槽**；被动启停走 `UIPanelData` 单一入口（**御风 ⇄ 坐骑互斥**在那里）；未实现的法宝/灵阵效果**明说待开发**。

## 6. 战阵（`图5-战阵.png`）

**布局**：中心上方是**俯视透视的九宫格**（线框），**中间站着玩家模型**（朝前）；右侧是已掌握**真灵的瀑布流**；
下方是**真灵介绍**（白框）。

**动效**：
1. **点开**：九宫格**由中心往外画线**（每格 50ms），玩家模型**落笔**出现（0.2s）。
2. **真灵瀑布流**：**只以粒子特效呈现**（不是图标）——每只真灵是一团**颜色不同的墨粒子**；
   鼠标滑过 → **显示名字** + **原地牵引**（≤6px）；粒子本身缓慢自转/呼吸。
3. **拖动粒子到九宫**：拖拽时粒子被"拉长"（像墨被笔带起来）→ 落到格子里 → **真灵模型落笔**出现 + 该格墨晕脉冲。
4. **下阵 / 满额**：下阵 = 粒子回到流里；满额（**上限 5 名**）时被占的格子外圈**朱砂细线**提示。

**素材**（§7-⑤）：`fx-formation-grid.png`（俯视透视九宫线框，细墨线，透明底，1600×1200）；
`fx-spirit-particle-*`（4~6 种颜色/形状的墨粒子，128×128，软边，**不要具象图标**）。

**功能口径**：九宫保持方向、**中间固定玩家**；**同时最多 5 名**；名单 **240 个真灵要虚拟化/对象池**；
不旋转棋盘改变方向理解。

## 9. 可直接粘贴的提示词（每条都接 `素材规格与提示词.md` 的统一前缀与负面词）

**① 墨点（8 颗）**
> 一颗**溅在宣纸上的墨点**，形状自然不规则（不是正圆），边缘有**浓淡与飞白**，中心略淡（要留出放图标的空白）；
> 纯黑墨色（浓淡由透明度表现），透明背景；给 8 颗**大小与形状各不相同**的变体。

**① 水痕**
> 一道**横向的墨色水痕**：一端浓、另一端渐渐淡成丝状纤维，边缘自然晕开；透明背景，只有墨没有其他元素。

**① 墨晕涟漪（6 帧）**
> 一滴墨落纸后**向外扩散**的 6 帧序列：第 1 帧是实心小圆，逐帧变大、中心越来越淡、外圈越来越细，
> 最后一帧只剩一圈极淡的水痕；同画布同中心，首尾可衔接；透明背景。

**② 包裹打开（8~12 帧）**
> 一个**用布包着的包裹**（打结的包袱皮，水墨写意），从**闭合 → 结松开 → 布摊开 → 里面空了**的 8~12 帧序列；
> 同画布同中心，动作连贯；只要墨与纸，不要颜色、不要文字；透明背景。

**② 墨流（可循环）**
> 一条**竖向的墨色水流**纹理：自上而下有流动感的浓淡与丝状拖尾，上下两端**可以无缝循环**；
> 横向也要能平铺；透明背景，浓度克制（不超过 50% 黑）。

**③ 墨圈（12 帧，一笔画成）**
> 一支**毛笔从左侧起笔、顺时针画出一个完整的圆**的 12 帧序列：起笔处最浓、行笔有轻微粗细变化、
> 收笔留一点飞白，圆**内部保持完全透明/空白**；同画布同中心；透明背景。

**③ 异形墨幕布**
> 一块**不规则边缘的墨色幕布**（像一摊被摊开的墨），中央是素净的宣纸、四周是自然晕开的墨边；
> 四角留给九宫格安全区（中央 1/3 必须素净可拉伸）；不要文字、不要金边；透明背景。

**④ 星象图**
> 一张**古星图**：用**极细的墨线**勾出星座连线与同心圆弧，线上散布大小不一的**星点**（浓淡不同），
> 图中**留出六个明显的空位**（空位用细线描出轮廓、彼此以细线粗略相连，便于放入六个"星位"）；
> 整体像画在宣纸上的星图，**透明背景**；不要文字、不要坐标数字、不要发光特效。

**④ 星点粒子**
> 一枚**柔边的星点/墨点粒子**：中心稍实、边缘完全虚化；白色或淡金，用于叠加与高亮；透明背景。

**⑥ 九宫线框**
> 一个**俯视透视（斜上方 45° 左右）的九宫格**：九块方形地面由**极细的墨线**分隔，
> 线条在四角略微交叠加深；画面其余部分完全透明；不要文字、不要填充色块。

**⑥ 真灵粒子（6 种）**
> 一团**柔边的墨色粒子/墨雾**（不要具象动物造型），整体呈不规则的团状、边缘散成小点；
> 提供 6 种不同色调（墨青 / 墨绿 / 墨紫 / 墨赭 / 墨蓝 / 灰白）与细微形状差异；透明背景。

## 10. 施工顺序（每一页都要做到"动效 + 功能"双验收）

1. **前置**：`UIInkMotion` 组件（§9.4）+ UI 纸纹层（§10）—— 没有这两个，逐页动效会各写一套；
2. **父幕布**（8 墨点）→ 它是所有子页的容器，先做 **1 页顶 7 页**；
3. **背包**（含瀑布流组件 `UIInkWaterfall`，后面境界/神通/战阵/坐骑/外观全部复用）；
4. **境界** → **神通** → **战阵**；
5. 坐骑 / 外观（复用第 3 步的瀑布流）；
6. **每页验收**：录 0.5× 慢放 MP4（面板开 / 主要交互 / 一个错误路径），**并且**逐条走"功能口径"清单
   （选中、拖拽、开关、数值联动、上限、互斥）——**动效好看但功能掉了 = 没做完**。
