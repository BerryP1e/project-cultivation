# InkUI 动效接入与验收 · 2026-10-04

## 我改了什么

按施工单 §9 开始共用动效接入，保留第一阶段的布局、数据与父页关系。新增 `UIInkMotion` 的 `落笔 / 晕开 / 提笔 / 干笔` 接口、统一 Timing 表与全局六元素预算；动画用 `Time.unscaledDeltaTime`。没有加破境/开炉演出及跳过功能。

| 元素 | 当前实现 |
|---|---|
| 纸面展开 | 左边固定，0.26s 展开绘制宽度；所有子内容一起裁出，文字只淡入，不移动根节点、不缩放文字。 |
| 关闭 | 业务原入口立即关闭、恢复时间；复制当前可见 Image/Text 做 0.18s 离场，先淡后收，快照无按钮、脚本或射线。保留列表裁剪。 |
| 页签/行 | 页签交叉淡入，选中纸牌绘制上浮 2px；列表前八行错开 30ms，短笔悬停延长、选中变实；数据刷新复用行，不重启整库入场。 |
| 卡片/玉符 | 仅图标落笔、上浮 3px、微旋 1.5°，柔边墨晕投影扩大；按下回压 1px；槽图标悬停 1.08×。使用 anchoredPosition 避免布局变化导致偏移。 |
| 拖放 | 独立拖影上浮 12px、倾斜最多 4°，文字反向补偿保持清晰；槽位轮廓提示；实际装/卸触发 0.22s 墨晕；未接收拖放时拖影返回起点并淡出朱砂叉，数据不回滚。 |
| 数值/进度 | HUD 气血/灵气文字只插值显示，0.2s 收敛到真实值；Filled 条 0.25s 缓动及前端笔锋，满条脉冲。槽位编号、日期与技能冷却不插值。 |
| 滚动 | 保留 ScrollRect 惯性；绘制顶/底淡出，拖动和滚轮都更新；原 Mask 与命中关系不改。 |
| Toast | 背景 0.6→1，文字只淡入，0.16s 出现；向上淡出 0.2s；停留时长及消息内容来自原调用。 |
| 减少动效 | 暂停菜单独立按钮，PlayerPrefs 保存偏好；关闭位移、旋转、脉冲和插值，面板立即完整显示。 |

`UIInkReveal / UIInkClipRect` 只修改绘制网格，不切换 Filled 类型，不改原布局；`UIInkNumber / UIInkFill` 只影响显示，不写玩法数据。运行时皮肤登记的纸面接入展开；角色、修炼、丹房、灵田总览、功德堂、对话、传送、存档与暗幕菜单关闭入口接入离场。旧 `InkUIHoverMotion` 在六槽上停用，避免两套悬停争抢 Transform。

## 我量到什么

证据在 `cultivation/screenshots/InkUI-motion-checks-<分辨率>.txt`、`InkUI-motion-<分辨率>-slow5.mp4` 及六张关键帧 PNG。录像覆盖六类必做动作，另含关闭；正常操作、减少动效及快速连续换页分别检查。原 26 项装备/被动/滚动/对象池检查复跑。

- 1920×1080 与 1280×720 的 **18 项动效检查分别通过，Failures=0**；运动数峰值 **6**，快速换页后名额归零。
- 原 **26 项交互检查在两种实际分辨率分别通过**，日志为 `InkUI-motion-gameplay-<分辨率>.txt`。
- 每段录像 **240 帧、5 fps、48 秒慢放**，实际采集耗时及平均帧率写在对应检查日志，未把编码帧率当作游戏帧率。
- 本轮没有编辑或保存场景；工作区已有 `Sect.scene` 的碰撞体改动保留，不纳入动效提交。运行期复核 Errors=0；一次退出 Play 出现既有“灵田”对象未清理报错，不属于动效绘制，完整退出/玩法回归仍待验证。
- 19 个可用页面在两种实际分辨率共 **38 张截图**，命名 `InkUI-motion-panel-<页面>-<分辨率>.png`。脚本检查 PNG 像素尺寸后才计数；当前场景没有对话 NPC，对话页面未计入本轮截图验收。
- 文档检查：533 个链接，DEAD / malformed / 控制字符 / BOM / H1 / 导航头均为 0。

打开 [动效对照页](motion-review.html) 可选择两种分辨率、跳到各动作。复现：Play 内通过文件桥 `inkqa:seed` 后执行 `inkmotion:record`，用 `inkmotion:status` 查结果。录制借用原角色组件的协程，验收工具只在 Editor；原生 MediaEncoder 先写 ASCII 临时路径，完成后复制到截图目录。API 参考：[Unity MediaEncoder](https://docs.unity3d.com/ja/2017.4/ScriptReference/Media.MediaEncoder.html)。

验收只临时修改 Play 中的装备、气血及偏好，finally 还原；不调用存档、不重新生成或保存场景。录像中的临时色块仍来自缺图条目的原品阶，并非新增神通图标。

## 我看到什么，以及尚未完成的规范

逐帧发现并修复了图标布局漂移、展开时子板先露出、关闭时半截卡片越过遮罩的问题；快速换页测试另外查到隐藏墨晕占着预算，已在隐藏时释放并清理，禁止向隐藏页面发出新墨晕。纸面开合无根节点位移，文字不随图标缩放。动效预算满时主面板等空位，列表/卡片直接显示，操作入口不排队；快速换页会释放绘制名额。

本轮是 §9 的基础动效接入，**不是 §9–10 全部完成**：

- `fx-ink-blot / fx-brush-tip` 未交付时使用绘制几何的柔边墨晕与笔锋；飞白遮罩未交付，干笔接口保留素材入口，未假称已实现边缘飞白。
- 素底版与细墨线框未到位，未叠加第二层纸纹；§10 要求素底与 UI 统一纸纹一起上。纸纹横扫、慢漂移和全局墨呼吸待该批素材接入。
- 数字动画目前接 HUD 气血/灵气及命名匹配的贡献/进度文本，未宣称所有数值都已覆盖。3D RawImage 预览未复制到离场快照。
- 完整炼丹/灵田/存档/复活玩法回归仍沿用第一阶段未完成项。新演出和跳过需单独确认。
