# 第三阶段开工：无底板的墨点父导航

## 本批改动

- 按《八页重制总纲》与 `图1-父幕布.png` 建立八颗错落墨点，图标居中、名称在下方。
- 用户 2026-10-04 明确原型没有父底板：关闭父 Window 与 Sidebar 的绘制，保留其布局容器和原按钮；不创建整页纸纹覆盖。
- 八颗墨点使用不同透明图。绘制层确定性 Perlin 游走，阻尼跟随；鼠标局部吸引、离开回位；shader 持续低频边缘形变；划过使用独立水痕；点击使用径向墨晕。
- 文字不参与形变，按钮命中框不随墨点移动。减少动效开关关闭漂移、形变、水痕与墨晕。
- 场景背景暗化降低到 0.20。深色游戏背景上的导航名称改为可读的浅色并保留选中落款；这是无父底板后的可读性调整。
- 原八页按钮、事件、枚举及所有数据入口保留，未运行场景生成器，未写场景与配置表。

- 导航墨点、水痕：已接父导航。
- 墨晕、干笔遮罩、笔锋：已接现有共用组件的资源入口。
- 角皴：预备素材，尚未接局部信息框。

- 点击墨晕使用运行时 shader 控制扩散，当前没有六张离线涟漪序列帧。尺寸、帧数属于总纲的技术建议；后续仍需按视觉质量决定是否补序列。

## 2026-10-04 父导航反馈修正

用户实机发现仅牵引明显。上一版的持续 UV 形变不足一像素，深色低透明度反馈在场景上难辨；原 31 项检查以参数及事件为主，不能代表视觉验收。

新增 UIInkDensitySimulation + InkDensity.shader：每颗墨点使用两张 128×128 ARGBHalf RenderTexture，30 Hz 交换密度/速度状态，以平流、扩散、噪声旋流和鼠标扰动近似连续墨流。八颗的状态纹理共约 2 MiB。它不是刚体物理或完整不可压缩流体求解器；尚未测量目标硬件 GPU 耗时。原贴图仍负责初始形状，不再独自承担动效。

水痕按鼠标位置/方向绘制，增加浅色湿边以适应深色场景；点击向墨密度注入扩散，并绘制 0.55 秒湿边。减少动效停止模拟，关闭页面不继续推进，销毁时释放纹理。命中框与文字保持稳定。

QA 新增真实 GPU 密度读回：静置两次取样平均绝对差必须大于 0.0001，且步数增长。1920×1080 实测 0.027141，1280×720 实测 0.033445；两种分辨率各 32 项检查通过，现有业务 26 项回归通过。点击与划过实机帧保存在 cultivation/screenshots/InkUI-fluid-1920x1080-frame-39.png、frame-41.png；双分辨率录像沿用原入口，不入库。该数值证明模拟演进，最终观感仍需用户检查录像。
