# 水龙炮

> **管什么**：水龙炮的施放、伤害类别、暂定参数和特效方向。
> **不管什么**：统一伤害算法见 [战斗与伤害](../architecture/战斗与伤害.md)；技能槽见 [主动技能与神通](../architecture/主动技能与神通.md)。
> **本文件怎么查**：1 行为与参数｜2 特效与资源｜3 测试入口。
> **来源**：用户指定 Effect_28_PurifierBeam，特殊属性、主动神通伤害；其余数值为可调整的初版。

## 1. 行为与参数

地面、御风、骑乘全状态统一使用 Flying Mage 的 `attack_FlyingAtk02.fbx`，派生片段为 `技能动作/神通施法/水龙炮_施法`。经 `ActiveSkillCaster` 分流到 `WaterDragonSkillRunner`，由 `PlayerAnimationController` 播放，不调用普攻的伤害执行器。表列旧施法动作不参与本术播放，以专用执行体的共享Resources路径为准。

`ability_shuilong_pao` 占主动槽，按对应数字键施放；也支持现有Alt鼠标落点引导。全状态先播动作，到43%（源片段1.6秒的0.688秒）从实际左手位置出水并定住该姿势，引导期间随目标移动调整方向和长度。目标死亡、超距、施法者死亡或销毁时停止结算。

停止出水后解开定姿，让动作自然播完剩余收招；同时粒子停止发射，在0.65秒内渐淡、收细后销毁。尾散保留停止瞬间的方向，不随收手或目标位移突然扫转；不继续造成伤害。施法及收招占用动作，自动普攻/其他施法不能截断，销毁或打断时释放自己的占用。

| 参数 | 初版值 |
|---|---|
| 伤害 | 特殊＋主动神通，每次倍率 0.9 |
| 消耗 / 冷却 | 24 灵力 / 6 秒 |
| 最大距离 / 持续时间 | 20 米 / 1.5 秒 |
| 首次伤害 / 间隔 | 0.25 秒 / 0.4 秒 |
| 水柱横截面系数 | 0.05（原0.07，稍细） |
| 尾散时间 | 0.65秒，透明度与粗细平滑衰减 |

持续与伤害计时从实际出水开始，前摇不扣减1.5秒有效引导时间。

参数源为 `cultivation/Assets/Data/Tables/主动神通表.csv`。玩家指定的是特效及伤害分类，倍率、距离与时间均未定稿。

## 2. 特效与资源

游戏预制体 `Assets/resources/Abilities/WaterDragon.prefab` 保留 PurifierBeam 原粒子结构，移除依赖演示场景全局倍率的脚本。原生梁沿 **+Z**，中心 Z=37.5、长度75；`AbilityVfxUtility.对准光束` 分别标定横截面与长度，不能套焚天炎术的翻转和49.1米基准。

`WaterDragonSkillRunner` 调用 `NpcInstance.ReceiveAttack`，伤害读取 `攻击类别`，不另写公式。图标 `UI/InkUI/Abilities/water-dragon.png`；学习物品 `item_ability_shuilong_pao`。P 菜单添加玉简、背包使用后，在神通页装备。

源FBX保持原样；`DivineCastingBaker` 菜单 **修仙 / 动画 / 重建神通施法（不动场景）** 生成非循环Humanoid片段，按既有御风0.946根高度归一化，保留源全身姿势，保留源动作腕指曲线并限制异常外翻，保留派生资产GUID。动作通过Resources加载，所有使用现有施放器的场景自动生效，无需逐场景改线。

PurifierBeam使用自定义加法材质的 `_TintColor`；仅StopEmitting会残留最长5秒的实心梁，所以尾散同时通过MaterialPropertyBlock衰减颜色与透明度，不改共享材质。

## 3. 测试入口

锁定目标施放，观察第一跳伤害和光束方向；让目标移动、死亡或超距检查结束。隔离 Play 验证记录 `.local/diagnostics/eight-abilities-verify.txt`；截图 `cultivation/screenshots/eight-abilities-preview-1920x1080.png` 与 `1280x720.png`，截图不入库。

施法烘焙使用 `HandMotionRetargeting` 保留源动作逐帧的腕指曲线及关节限位，不再使用待机的固定屈指/缩腕规则。源Avatar和玩家Avatar均包含双手手腕与30根手指骨；在玩家骨架上对每段动作采样61帧，32根关节全部实际运动，局部旋转与限位后的源动作最大角差为0°。

2026-10-09全状态实机检查 `devtools/validation/all-state-casts-runtime.cs.txt`：地面、御风、实际碧水兽骑乘各施放三术，共9次，覆盖动画节点、左右手挂点、凝聚/尾散、追踪伤害、命中特效、自然收招及角色根高度；全部通过，无运行错误。腕指实际骨骼检查为 `devtools/validation/casting-hands-check.cs.txt`。临时脚本、报告和预览不入库。

补充 `devtools/validation/flight-casts-edges.cs.txt` 验证前摇中断不出水、施放器停用后停止结算并柔和尾散、解除定姿/占用、无执行体残留。尾散使用Renderer级MaterialPropertyBlock，粒子拖尾材质不按submesh索引寻址。
