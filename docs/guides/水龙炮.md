# 水龙炮

> **管什么**：水龙炮的施放、伤害类别、暂定参数和特效方向。
> **不管什么**：统一伤害算法见 [战斗与伤害](../architecture/战斗与伤害.md)；技能槽见 [主动技能与神通](../architecture/主动技能与神通.md)。
> **本文件怎么查**：1 行为与参数｜2 特效与资源｜3 测试入口。
> **来源**：用户指定 Effect_28_PurifierBeam，特殊属性、主动神通伤害；其余数值为可调整的初版。

## 1. 行为与参数

`ability_shuilong_pao` 占主动槽，按对应数字键施放。必须锁定活着的单位；从玩家胸前发出粒子束，随目标移动调整方向和长度。目标死亡、超距、施法者死亡或销毁时结束。

| 参数 | 初版值 |
|---|---|
| 伤害 | 特殊＋主动神通，每次倍率 0.9 |
| 消耗 / 冷却 | 24 灵力 / 6 秒 |
| 最大距离 / 持续时间 | 20 米 / 1.5 秒 |
| 首次伤害 / 间隔 | 0.25 秒 / 0.4 秒 |

参数源为 `cultivation/Assets/Data/Tables/主动神通表.csv`。玩家指定的是特效及伤害分类，倍率、距离与时间均未定稿。

## 2. 特效与资源

游戏预制体 `Assets/resources/Abilities/WaterDragon.prefab` 保留 PurifierBeam 原粒子结构，移除依赖演示场景全局倍率的脚本。原生梁沿 **+Z**，中心 Z=37.5、长度75；`AbilityVfxUtility.对准光束` 分别标定横截面与长度，不能套焚天炎术的翻转和49.1米基准。

`DirectedAbilityRunner` 调用 `NpcInstance.ReceiveAttack`，伤害读取 `攻击类别`，不另写公式。图标 `UI/InkUI/Abilities/water-dragon.png`；学习物品 `item_ability_shuilong_pao`。P 菜单添加玉简、背包使用后，在神通页装备。

## 3. 测试入口

锁定目标施放，观察第一跳伤害和光束方向；让目标移动、死亡或超距检查结束。隔离 Play 验证记录 `.dsh/_diag/eight-abilities-verify.txt`；截图 `cultivation/screenshots/eight-abilities-preview-1920x1080.png` 与 `1280x720.png`，截图不入库。
