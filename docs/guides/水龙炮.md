# 水龙炮

> **管什么**：召龙吐息的施法、时序、挂点、材质和参数。
> **相关**：[战斗与伤害](../architecture/战斗与伤害.md)、[主动技能与神通](../architecture/主动技能与神通.md)、[龙类小怪素材](龙类小怪素材.md)。
> **来源**：2026-10-11用户指定倒放Hit显形、Attack定格并结合Run震颤，龙嘴释放水炮，结束消融；玩家使用玄霄雷诀A3。最新修正为Attack55%、更强的震颤、龙位于后侧，主角自然播放动作，原暂停节点对齐出水。

## 1. 行为与时序

`ability_shuilong_pao`由`ActiveSkillCaster`分流到`WaterDragonSkillRunner`。地面、御风、骑乘统一复用`技能动作/玄霄雷诀/A3`，保留这段成品Humanoid动作的全身、手腕和手指曲线。不调用普攻伤害执行器，仍属于特殊属性的主动神通。数字键锁定施放及Alt鼠标落点引导均保留。

1. 玩家起手即自然播放A3，同时召唤龙并开始显形，全程不调用主角的定姿接口。
2. 主角前43%的动作进度驱动龙的完整预备流程：倒放Hit显形、Hit首帧平滑融合到Attack首帧、攻击缓启缓停到55%。各阶段共用进度时钟，在不同播放倍率下也保持同步。
3. 主角到43%时，龙在同一个LateUpdate到达Attack55%定格并从下颚生成水柱。这个节点对应原来的主角暂停节点；主角随后继续正常播放并自然回到待机。
4. 吐息时保持Attack55%的基础姿态，取Run相对首帧的局部旋转变化叠加。Run以2.4倍速采样，混合权重由0.12提高到0.30，关节震颤上限由3度提高到8度；震颤0.25秒渐入，保留0.07秒指数阻尼和平滑循环。头、脖子、下颚和根位移不受跑步姿势覆盖。
5. 吐息持续1.5秒；主角动作自然完成不会截断吐息。结束后水柱停止发射，0.65秒渐淡并收细；龙身0.8秒内消融，身体震颤在前0.25秒平滑回归定格姿势。

龙预备流程的原始时间为Hit0.375秒、姿势融合0.32秒、缓启缓停攻击约0.864秒，合计约1.559秒。运行时按主角前43%进度缩放整段流程，正常1倍A3播放时约0.688秒出水，保留各阶段连续插值。

显形和龙攻击前摇均不造成伤害，也不扣减1.5秒有效吐息时间。持续时间、首次伤害和伤害间隔从实际出水开始计算。

龙位于玩家后侧，位置参考补偿后的实际髋骨，偏右1.25米、向后1.2米，兼容御风及骑乘高度。位置及朝向以指数插值跟随，避免目标移动时硬转。模型维持首版2倍大小；近目标时按实际55%定格炮口前伸距离后移，让龙嘴保留在目标前方。水柱每帧从实际嘴部对齐锁定单位身体中心或鼠标落点。炮口位于`Bip001 下颚Nub`外侧，不使用辅助人形骨架的`Bip001 Head`。收招后冻结龙位置及最后一帧水柱方向，避免尾散扫向其他位置。

目标死亡、销毁、超距或施法者失效时立即停止结算并消融。主角动作自然完成由`动作播完`事件标记，与动作被主动停止分别处理。显形阶段中断也能清理；施法者对象销毁后，执行体仍独立完成龙身消融。执行体被停用/销毁时清理自己创建的模型、光束和PlayableGraph。动作占用及完成事件订阅只由当前执行体释放，不能误解开其他动作；吐息期间仍防止其他攻击覆盖施法。

## 2. 参数与伤害

| 参数 | 当前值 |
|---|---|
| 伤害 | 特殊属性＋主动神通，每跳倍率0.9 |
| 消耗 / 冷却 | 24灵力 / 6秒 |
| 最大距离 / 有效吐息 | 20米 / 1.5秒 |
| 首次伤害 / 间隔 | 出水后0.25秒 / 0.4秒 |
| 水柱横截面系数 | 0.05 |
| 龙模型缩放 / 材质基础不透明度 | 2.5（首版1.25的2倍） / 0.88 |
| 水柱尾散 / 龙消融 | 0.65秒 / 0.8秒 |

伤害、消耗等仍来自`Assets/Data/Tables/主动神通表.csv`及生成的神通资产；本轮未改这些数值。通过`CombatDamagePipeline.命中`结算，手动落点继续接入`CombatImpactPipeline.接触`。施法前检查水柱、召唤龙和玩家动作资源，缺失时不扣灵力。动作及收招占用期间，自动普攻或其他技能不能覆盖。

## 3. 资源与实现

| 资源 / 代码 | 用途 |
|---|---|
| `Assets/resources/Abilities/WaterDragonSummon.prefab` | 龙模型、Generic Avatar、三段源动画、嘴部挂点与灵体材质引用 |
| `Assets/Art/Characters/Imported/DragonMob` | 共用导入模型、Attack / Hit / Run及原贴图；不重复拷贝FBX |
| `DragonMob/Materials/WaterDragonSpirit.mat` | 水蓝色灵体材质，基础不透明度0.88，比原真灵0.70更实；关闭投影 |
| `Assets/Shaders/WaterDragonSpirit.shader` | 表面光、边缘发亮、局部噪声裁切消融；不修改真灵共享材质 |
| `WaterDragonBreathVisual` | 手动PlayableGraph控制倒放、融合、定格与有限幅度的震颤 |
| `WaterDragonSkillRunner` | 施法占用、目标有效性、水柱方向、伤害时序、收招清理 |

水柱继续使用`Assets/resources/Abilities/WaterDragon.prefab`的PurifierBeam粒子。原梁沿+Z，长度75；`AbilityVfxUtility.对准光束`独立标定横截面与长度。仅停止发射仍会残留长寿命粒子，所以同时用Renderer级MaterialPropertyBlock衰减`_TintColor`。龙身也使用属性块，显形及消融不会改写共享材质。

玩家A3直接复用成品，不再由`DivineCastingBaker`重建旧的水龙炮专用片段；该工具只重建冰暴术/瞬雷天闪共用的追踪弹动作。所有现有场景通过共享Resources路径加载，无需逐场景复制。召唤预制体登记在`devtools/maintenance/runtime-resource-roots.json`，清理资产时递归保留其非Resources模型、动画及材质依赖。

## 4. 验证入口

`devtools/validation/all-state-casts-runtime.cs.txt`验证地面、御风及实际碧水兽骑乘各三术，共9次施放：玩家A3不定姿、43%出水同步龙Attack55%定格、主角自然完成后吐息继续、倒放Hit、龙嘴挂点、伤害、消融及根高度；同时回归冰暴术/瞬雷天闪。

`devtools/validation/water-dragon-breath.cs.txt`覆盖手动落点、实际两倍模型、移动目标方向、近距离炮口、超距停伤、显形中断、施法者销毁、执行体停用和残留检查。`devtools/validation/flight-casts-edges.cs.txt`覆盖原有施法占用与追踪弹中断边界。`water-dragon-continuity.cs.txt`在隔离预览逐骨骼检查显形/融合/定格/跑步循环接缝，以及30/60/120Hz下震颤退出与消融连续性。

2026-10-11最新时序与姿势调整后，全状态117项、吐息边界25项、逐骨骼/时钟连续性21项通过。30/60/120Hz均在主角43%节点同步龙55%定格；跨越整个预备阶段的卡帧仍能正确显形。强化Run混合相对旧权重的实际关节最大差约4.94度。隔离预览对照Attack55%：下颚旋转与源定格一致，身体骨骼额外旋转不超过8度。六玩家场景共享接线和资源依赖已检查，复用玩家A3的32个腕指关节均有绑定及运动。显形、定格、震颤和消融画面已检查。临时报告和截图位于被忽略的`.local/diagnostics/dragon-mob`；不保存测试场景或测试存档。
