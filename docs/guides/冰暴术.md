## 1. 效果与数值

天品主动神通，`ability_bingbao_shu`；结算复用 `ActiveSkillKind.追踪弹 = 3` → `HomingBoltSkillRunner`，没加新档（依据「类似瞬雷天闪」）。用户要求：球换成 `frost-crystal`，命中特效换成敌人**脚下**的 `frost-frozen-tomb`，冷却结束只能放一次，球在手上同样有动画暂停，伤害设大一点。

```
播普攻动作 普攻_远程_01（同瞬雷天闪）
  ↓ 40% 节点 → 生成 frost-crystal 冰珠（挂 R_Hand）+ 动画定住 1.5s（等粒子长出来）
  ↓ 放开动作、冰珠带追踪飞向锁定目标（22 m/s）
命中 → 敌人**脚下**生成 frost-frozen-tomb + 一次【特殊 + 主动神通】伤害
```

| 项 | 值 |
|---|---|
| 神通id / 名称 | `ability_bingbao_shu` / 冰暴术 ✓ |
| 结算方式 | `追踪弹`（复用，未加新档） |
| 球 / 命中特效 | `…/frost-fx/frost-crystal` / `…/frost-fx/frost-frozen-tomb`（**贴地**，脚下）✓ |
| 需要锁定目标 | 是（沿用瞬雷天闪） |
| 可积攒次数 | **1**（冷却完只能放一次）✓ |
| 伤害倍率 / 属性 | **4**（比瞬雷天闪的 3 大）/ 特殊 ✓ |
| 品阶/灵力/冷却/范围 | 天品 / 55 / 10s / 20 ⚠️ 我填的占位 |
| 施法动作 | **留空**（追踪弹档必须留空，动作由 runner 按普攻动作播） |

学习物品：`item_active_ability_bingbao_shu`（冰暴术 神通玉简，天品）→ 效果 `学主动神通`。

## 2. 代码在哪

**本档没有新 runner**，只给 `HomingBoltSkillRunner` 加了两个能力（它原来写死服务瞬雷天闪）：

| 文件 | 改动 |
|---|---|
| `Abilities/HomingBoltSkillRunner.cs` | 新增 `命中特效贴地`（放脚下）、`命中特效存活按自然`（存活至少取 prefab 自然时长，避免硬切）；日志/物件名改用**神通自己的名字**（`名称`），不再硬编码 "[瞬雷天闪]" |
| `Abilities/ActiveSkillCaster.cs` | `施放追踪弹()` 把表里的 `命中特效路径` / `命中特效贴地` 传给 runner |
| `Data/ActiveDivineAbility.cs` | 新增 `命中特效路径` / `命中特效贴地` / `三段特效路径`（寒墟也用） |
| `Data/Tables/主动神通表.csv` | +1 行 +3 列 |

### 2.1 命中特效放在脚下

原来命中特效固定放 `目标 + 命中特效抬高(1m)`（胸口）。本术要**冰冢从地里长出来**：`命中特效贴地 = 是` → 放 `目标根部`（y = 脚底），且 `对齐到锚点: false`（不做几何中心重定位）。瞬雷天闪保持**不勾**、打胸口，两者互不影响。

### 2.2 命中特效存活别写死

`frost-frozen-tomb` 自然总时长 **20.7 秒**（`spikes-st-*` 寿命 0~20 随机、`cracks-main` 5s + 10s）；原来写死 2 秒会把它**硬切**。现在存活 = `max(手动值, prefab 自然时长 × 1.05)` = **21.74s** ✓（同冰刺/寒墟口径，见 [沧澜寒渊录](沧澜寒渊录.md)）。

## 3. 实测（3C_Testbed + 练功木桩）

冰珠在手上 (0.11,1.83,0.32)，定住 1.5s 后从 (0.10,1.84,0.32) 放飞，目标「练功木桩」(-1.25,1.10,4.46)，距离 4.42m｜22m/s｜转向 720°/s。

| 检查项 | 结果 |
|---|---|
| 出弹节点 | **0.403**（40% 口径）✓ |
| 动作定住 | ✓ 1.5s，与瞬雷天闪一致 |
| 追踪命中 | 距离 4.42m，22m/s ✓ |
| 命中特效落点 | **脚下** y=0.00（-1.25,0.00,4.46）✓ |
| 命中特效存活 | **21.74s**（= 20.7 × 1.05，不再硬切）✓ |
| 伤害 | 229.32（倍率 **4**｜特殊｜会心 1.3、免会心率 0.0%）✓ |
| 灵力 | 150 → 93.35（扣 **55**）✓ |
| 充能 | **1**（放完进 10s 冷却）✓ |

## 4. 可以调

- **伤害倍率**（表列）= 4，嫌大/小直接改表；**冷却 10s / 灵力 55 / 品阶 天品**都是我填的占位。
- 球尺寸 / 飞行速度 / 定住时长在 `HomingBoltSkillRunner` 字段（`球缩放` / `飞行速度` / `长球停顿时长`）。
- 冰冢（20.7s）留得久：关掉 `命中特效存活按自然`，再把 `命中特效存活` 填想要的秒数。
