## 1. 效果（策划说明）

> 用户原话：「主动神通：冰暴术。效果：类似瞬雷天闪，只不过发射的球变成了 `frost-crystal`，
> 命中后特效变成了在敌人脚下的 `frost-frozen-tomb`，并且冷却结束只能使用一次。
> 其他的基本一样，包括球在手上还有有那个动画暂停，这个技能伤害可以设置的大一点」

```
播普攻动作 普攻_远程_01（和瞬雷天闪一样）
  ↓ 动画 40% 节点 → 生成 frost-crystal 冰珠（挂在 R_Hand）
  + 动画**定住 1.5 秒**（让冰珠把粒子长出来）
  ↓ 放开动作、冰珠带追踪飞向锁定目标（22 m/s）
命中 → 在敌人**脚下**生成 frost-frozen-tomb  +  一次【特殊 + 主动神通】伤害
```

## 2. 代码在哪

**这一档没有新 runner**，只给 `HomingBoltSkillRunner` 加了两个能力（原来它写死服务瞬雷天闪）：

| 文件 | 改动 |
|---|---|
| `Abilities/HomingBoltSkillRunner.cs` | 新增 `命中特效贴地`（放脚下）、`命中特效存活按自然`（存活至少取 prefab 自然时长，避免硬切）；日志/物件名改用**神通自己的名字**（`名称`），不再硬编码"[瞬雷天闪]" |
| `Abilities/ActiveSkillCaster.cs` | `施放追踪弹()` 里把表里的 `命中特效路径` / `命中特效贴地` 传给 runner |
| `Data/ActiveDivineAbility.cs` | 新增字段 `命中特效路径` / `命中特效贴地` / `三段特效路径`（寒墟也用） |
| `Data/Tables/主动神通表.csv` | +1 行 +3 列 |

### 2.1 「命中特效放在脚下」

原来命中特效固定放 `目标 + 命中特效抬高(1m)`（胸口）。冰暴术要**冰冢从地里长出来**，所以：
`命中特效贴地 = 是` → 放在 `目标根部`（y = 敌人脚底），并且 `对齐到锚点: false`（不做几何中心重定位）。
瞬雷天闪保持**不勾**，还是打胸口 —— 两个神通互不影响。

### 2.2 「命中特效存活」别写死

`frost-frozen-tomb` 的自然总时长 **20.7 秒**（`spikes-st-*` 的粒子寿命 0~20 随机、`cracks-main` 5s + 10s 寿命），
原来 hit 特效写死 2 秒会把它**硬切**。现在：存活 = `max(手动值, prefab 自然时长 × 1.05)` = **21.74s** ✓
（和冰刺/寒墟同一套口径，见 [沧澜寒渊录 §2.4](沧澜寒渊录.md)）。

## 4. 可以调

- **伤害倍率**（表列）= 4；嫌大/小直接改表。
- **冷却 10s / 灵力 55 / 品阶 天品**都是我填的占位。
- 球的尺寸、飞行速度、定住时长：在 `HomingBoltSkillRunner` 的字段上（`球缩放` / `飞行速度` / `长球停顿时长`）。
- 冰冢（20.7s）在地上留得久，若嫌久：把 `命中特效存活按自然` 关掉，再把 `命中特效存活` 填想要的秒数。
