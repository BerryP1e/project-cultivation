# 雷云（被动神通）

> **管什么**：被动神通「雷云」的实现 —— 效果、与千劫雷狱的区别、三个特效、云的插值拖尾、实测与数值疑点。
> **不管什么**：原生雷电表现与共享依赖见 [资产与目录](../architecture/资产与目录.md)；另一常驻光环被动见 [千劫雷狱](千劫雷狱.md)。
> **本文件怎么查**：§1 效果与数值 → §2 与千劫雷狱的区别 → §3 三个特效（§3.1 原生雷束、§3.2 连到敌人中部、§3.3 云跟随）→ §4 测试 → §5 待定的耗灵问题。

地品被动神通，`ability_leiyun`。

## 1. 效果与数值

```
装备该被动神通后**持续消耗灵力**
在角色身边生成一朵雷云（特效 lightning-cloud）
当角色**锁定目标**时，雷云每隔一段时间召唤闪电
  · lightning-ray 细淡紫雷束：一端是**锁定目标**、一端是**雷云**
  · 然后在敌人那里生成受击特效 lightning-arc-flash
  · 受击特效的大小取决于**敌人尺寸**
  · 敌人受到【特殊 + 被动神通】伤害
```

| 项 | 值 |
|---|---|
| 神通id / 名称 / 品阶 | `ability_leiyun` / 雷云 / 地品 |
| 维持消耗灵力 | **2**/秒（表里的「维持消耗灵力」列，组件读它） |
| 灵力增益 | +15 |
| 被动法术伤害加成 / 减免 | +3% / +1%（加成走 `AttackKind.被动神通` 那一档） |
| 学习物品 | `item_passive_ability_leiyun`（雷云 心得）→ 效果 `学被动神通` |
| 组件 | `LeiYun.cs`，靠 `PlayerAbilityLoader.被动神通表` 自动装卸 |

## 2. 和【千劫雷狱】的区别（容易混）

|  | 千劫雷狱 | **雷云** |
|---|---|---|
| 触发条件 | 敌人进入**范围**就自动挨打 | **锁定了目标**才劈 |
| 表现 | 命中时竖直雷罚 + 一圈黑环 | 头顶一朵云 + 一道线连到目标 |
| 伤害 | 特殊 + 被动神通 | **特殊 + 被动神通**（同一套加成） |
| 范围来源 | 神识范围（黑圈大小） | `最大距离`（锁定目标太远就不劈） |

两者可以**同时启用**（各自独立扣灵）。

## 3. 三个特效

| 部位 | 资源 | 处理 |
| --- | --- | --- |
| 云 | `CombatVFX/CombatMagic/lightning-fx/lightning-cloud` | 头顶插值跟随，偏移 3.5 米 |
| 闪电 | `CombatVFX/CombatMagic/lightning-fx/lightning-ray` | 只显示 ray/glow，宽度 0.22，淡紫改色 |
| 命中 | `CombatVFX/CombatMagic/lightning-fx/lightning-arc-flash` | DamageResolver 确认命中时才生成，随目标高度缩放 |

### 3.1 原生 lightning-ray 拉伸

`LightningRayVfx.Spawn` 以目标中部为根，+Z 指向云的实际位置。保留原 Stretch Renderer、粒子速度、原生寿命与淡出，只调整粒子宽度和 lengthScale，使长度覆盖云到目标的三维距离。雷云仅保留 ray/glow，地面装饰关闭发射和渲染，保留嵌套子节点；使用淡紫色替换原色并保留亮度、透明度曲线。

不是旧的闪电链 Billboard 拉伸实现。原材质、贴图、网格、Shader 统一引用 Art/VFX/Shared 下的资源，不复制整包。闪电与命中实例按原生总时长销毁，避免在受击瞬间硬截断。

### 3.2 闪电连到敌人**中部**，不是脚下

和闪电链一个口径：`敌中点 = 敌人根 + up × (敌人高度 × 0.5)`，免得线贴地穿模。雷云那一端用 `云位置`（云的**实际**世界坐标，即插值后的位置）。

### 3.3 云跟着角色（**插值拖尾**）

用户原话：「雷云跟随在角色旁边，感觉卡的太死了，能否让它有一种比如插值旋转，主角移动后跟随的感觉，而不是卡死在主角旁边」。

以前 `维护云()` 每帧 `云.position = 角色 + 雷云偏移`（**硬贴**，所以看着"卡死"）；现在走 `Vector3.SmoothDamp` **插值跟随**：角色一动，云先拖在后面再慢慢追上，停下后自己归位。朝向用 `Quaternion.RotateTowards` 插值。

| 字段 | 默认 | 说明 |
|---|---|---|
| `跟随用插值` | `true` | 关掉回到老行为（硬贴），可对比手感 |
| `跟随平滑时间` | `0.35` | 越大越"懒"、拖得越明显 |
| `跟随最大速度` | `14` | 追上去速度上限（米/秒），0 = 不限制 |
| `跟随瞬移距离` | `20` | 角色瞬移（传送/复活/上坐骑）超过这个距离就**直接跟上**，免得拖长尾巴；0 = 永远插值 |
| `朝向插值速度` | `240` | 度/秒，只在 `雷云跟随朝向` 打开时有用 |

**调参规律（实测确认）**：角色匀速跑时 `稳定落后距离 ≈ 角色移动速度 × 跟随平滑时间`。实测（假角色 6 m/s、平滑 0.35s、跑满 3s 进稳态）：**滞后 2.09m vs 理论 6 × 0.35 = 2.10m** ✓。所以**默认 0.35 在 6 m/s 时约拖后 2m**；想更明显就把 `跟随平滑时间` 往 0.5~0.8 调。停下后约 **1 秒**内归位（实测等 2s 只剩 0.11m）。瞬移 60m 后 2 帧内跟上（阈值 20m）✓。

> ⚠️ `云位置` 用**插值后的真实位置**，所以闪电也从拖在后面的那朵云发出 —— 这是想要的效果。
> ⚠️ **探针注意**：测"角色跑起来云拖多少"时**别用 `玩家.transform.position += …` 推角色** —— `PlayerController` 每帧按输入重算位置把它覆盖掉（实测推了 2.14m，角色只走 0.67m，滞后量全测错）。用"没人管"的假角色来测，或直接读角色**真实**位移算速度。

## 4. 测试

```
面板被动目录含雷云 ✓ ；[PlayerAbilityLoader] 新建并启用 LeiYun ✓（不用手工挂组件）
① 云生成 @ 玩家上方 +3.50m ✓（= 雷云偏移.y）
② 没锁定目标，等 2.6s → 出手 0 次 ✓（没锁定不劈）
③ 锁定木桩 → 每 2s 掉 57.33 血 ✓（t=2.4/4.2/6.0s 各 ↓57.33，出手=3/4/5）
④ 停用后：生效中=False、云收掉 ✓
```

## 5. ⚠️ 待定：耗灵 2/s **低于**玩家回灵 4/s

玩家默认 `AttributeType.SpiritRegen = 4/s`，而本被动只扣 2/s → **灵力一直满着**，"持续消耗灵力"实际上没有代价。**千劫雷狱（3/s）也是同一个问题。** 要真有消耗压力，`维持消耗灵力` 得提到 **> 4**（建议 6~8）。数值待策划定。
