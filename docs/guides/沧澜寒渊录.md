# 沧澜寒渊录（特殊属性普攻四式）

2026-10-10：寒墟已拆入这门功法，不再提供独立主动神通、快捷槽或学习玉简。功法自身的学习方式和属性成长保留。

## 1. 四式与伤害

装备后按 A1 → A2 → A3 → A4 → A1 循环，自动锁定普攻及无锁定 Alt 普攻共用同一序列。每次动作成功播放才推进序号；死亡、被其他动作覆盖或切换功法会取消尚未出手的攻击。

| 式 | 动作（与玄霄雷诀完全相同） | 出手进度 | 特效与命中 |
|---|---|---|---|
| A1 | `技能动作/普攻_远程_01` | 40% | `frost-shock`，锁定目标脚下冰震；手动落点半径0.6米 |
| A2 | `技能动作/玄霄雷诀/A2`，原动作左右镜像 | 40% | `frost-spike`，目标脚下冰刺；手动落点半径0.6米 |
| A3 | `技能动作/玄霄雷诀/A3`，FlyingAtk02 | 43% | 一道 `frost-wave`，从出手位置向前扫过12米长、2.6米宽的路径 |
| A4 | `技能动作/玄霄雷诀/A4`，FlyingAtk03_short | 50% | `frost-ring`，以玩家为中心、半径5米群攻，与锁定目标的位置无关 |

四式都通过 `AttackSpec(DamageNature.特殊, AttackKind.普通攻击, false, 技能倍率)` 进入现有伤害管线。使用会心判定、普攻伤害加成及受击方普攻减免；不吃主动神通或被动神通加成，也不走物理暴击。默认倍率为1，原寒墟主动倍率、耗蓝与冷却不再叠入普攻。功法基础冷却保持1.1秒，动作速度与冷却随攻速换算。

A3固定出手时的起点和方向，角色随后移动不会拖动伤害走廊。以胶囊覆盖每帧新扫过的整段路径，低帧率也不会漏掉中间敌人。A3/A4一次攻击对一个NPC只结算一次，多碰撞体不会重复扣血；范围内敌对NPC与本次锁定目标可受伤，其他友好NPC跳过。没有额外的“每个敌人再召冰环/冰刺”二、三段伤害。

## 2. 动作、特效与引导

四式直接复用玄霄现有重定向片段，包括腕掌、手指曲线及动作过渡；地面、御风、骑乘都走同一组动作和出手节点。

资源前缀：`CombatVFX/CombatMagic/frost-fx/`。

- A1维持实测旋转 `(-90,0,0)`，用 `spikes-second` 子节点对齐目标脚底；找不到时只对齐水平。A2原生朝上，旋转为零。A1/A2按目标体型缩放，基准高度1.8米，默认夹在0.6～2.5倍。
- A3原生波沿局部+X延伸约11.5米，生成在路径中点，旋转+X对准出手方向，按12米长度缩放。只生成一整道波，不在每个敌人脚下重复生成。
- A4根节点落在玩家脚下，默认基准半径5米。视觉寿命与一次伤害窗口分开。
- 所有效果按 `特效摆放.量特效总时长(prefab) × 1.05` 清理，保留原生淡出。A1自然总时长9.1秒，默认约9.56秒清理；手填1.2秒只作无法测量时的兜底。人为缩短存活上限会截断余粒。

无锁定时按Alt或Alt+F，左键确认普攻：A1/A2显示落点圈；A3显示前进走廊；A4显示玩家周围的5米圈。神识边界继续显示淡墨波动圈，邪眼按原规则跟随普攻瞄准。

宗门野外保留远程功法的浅层体素破坏：A1/A2落点半径0.6米、深度0.325米；A3随路径推进按固定空间间隔切削，半径1.3米、深度0.325米；A4玩家周围半径5米、深度0.325米。走共享局部更新队列，不恢复近战体素破坏。

## 4. 验证（2026-10-10）

隔离3C Play共177项检查通过：真实功法装载、四式循环与实际动画、节点出手、四种特效、路径多敌命中、友好过滤、多碰撞体去重、波起点不随玩家移动、冰环与引导以玩家为中心、Alt四式和切换功法取消未出手攻击。

实际扣血对照：攻击100、普攻加成0.5、目标普攻减免0.2时，四式每名受击者均扣130；主动加成从7提升至1000，伤害仍为130；普攻加成提高至1后均扣180。物理暴击属性同时调高不改变这组特殊伤害。临时脚本和报告保存在本地忽略目录 `.local/diagnostics/canglan-runtime*`。

正式宗门野外四式真实Alt施放检查通过：A1/A2各更新1个地面分块，A3更新8个，A4更新11个；更新队列结束后切削位置仍有地面碰撞。四种原生特效朝向已拍图检查，第三方原始资源保留。
