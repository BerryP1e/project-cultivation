## 2. 五个要素在代码里怎么落地

全在 `飞弹妖魔Ai`（用户那套"飞弹五要素"就是照它写的）：

| 要素 | 做法 | 注意 |
|---|---|---|
| **1 出生点** | `普攻挂点/神通挂点`（骨骼名）+ `挂点偏移` | 偏移**必须量**（§4），因为这些怪的武器是**蒙皮网格不是骨骼**，玄蜂连尾巴骨骼都没有 |
| **2 飞行路径** | `NpcProjectile.设置直线飞行` —— 起飞锁定方向，**躲开就打不中** | 不是追踪弹（追踪是 `设置追踪飞行`，瞬雷天闪/冰暴术用那个） |
| **3 能否被阻挡** | 用**纯粒子弹道**（`*_Projectile_Only`）+ 自己的飞行器 → **不和场景碰撞**；只检测 `拦截层` | **`拦截层` 现在是 0 = 谁都拦不住**（神通/法宝/灵阵还没做）。做出来之后把它们放进一个层、填进 `拦截层` 即可，飞弹会自动停下并消散 |
| **4 消灭点** | `消灭距离`（默认 22 米）飞出去就**淡化消散** | 淡化 = 缩放渐隐（`淡出然后销毁`），**纯网格弹体（箭）一样有效** |
| **5 命中效果** | `特殊` → 会心判定；`物理` → 暴击判定。物理没配命中特效时**自动兜** `特效/命中/Hit_Physical` | 箭魔/玄蜂**故意留空**命中特效，就是要那个物理兜底 |

两招的**倍率 / 冷却**：普攻倍率 1 / 冷却 **3s**，神通倍率 2.2 / 冷却 **8s**
（沿白鹿精口径；用户只对近战那批明确说过 8s，这批没提，我按同一套填的）。

## 4. 出生点：**武器顶端 / 尾部怎么量**（菜单 `修仙 / 怪物 / 量飞弹出生点`）

用户说的是「右手骨骼」「武器顶端」「尾部（模型末端）」这种人话，
而 `挂点` 要的是**一个骨骼名 + 一个局部偏移**。麻烦在于：

- **武器根本不是骨骼** —— `GouTouJunShi_01_Weapon` 是**蒙皮网格**（只有 1 根骨骼 `Bone01`，
  网格本身长 1.97 米）；`LaoGuiJing_wuqi`、`JianMo_01_02` 同理
- **玄蜂连尾巴骨骼都没有** —— 整个模型就一个蒙皮网格，只有脚趾/头顶那几个 `*Nub`

所以工具的做法是（`Assets/Editor/Tools/飞弹出生点量测.cs`）：

1. 把动作 `AnimationMode.SampleAnimationClip` 采样到**用户给的百分比**那一帧；
2. 用**手动蒙皮**算出目标点（`骨骼矩阵 × bindpose × 顶点` 加权 —— `Renderer.bounds` 和
   `BakeMesh` 在编辑模式下都不跟骨骼，见[怪物近战判定 §5](怪物近战判定.md)）：
   - `武器顶端` = 指定网格里**离它自己骨骼最远**的顶点（= 尖端）
   - `武器中部` = 指定网格顶点包围盒的**中心**（箭魔要的是中部）
   - `模型末端` = **整个模型**里**最靠后**（本地 Z 最小）的顶点（尾巴/尾针）
3. 在**所有骨骼**里找离该点**最近的那一根**（武器网格自己的骨头优先），
   输出 `挂点 = 骨骼名`、`挂点偏移 = 骨骼.InverseTransformPoint(世界点)`。

量出来的结果（已写进各个类）：

| 怪 | 挂点 | 偏移 | 说明 |
|---|---|---|---|
| 狗头军师 | `Bone01` | a1 `(-1.658, 0.826, 1.921)` / a2 `(-2.734, -0.130, 0.240)` | 离骨骼 1.97 米 = 武器尖端 ✓ |
| 老龟精 | `Bone07` | a1 `(-1.863, 0.285, 0.410)` / a2 `(-3.122, -1.245, -1.054)` | 离骨骼 2.32 米 ✓ |
| 箭魔 | `Bone11` | a1 `(0.266, 0.375, 0.450)` / a2 `(0.289, 0.671, 0.380)` | 包围盒中心 ✓ |
| 蜘蛛精 | `Bip01 Tail3` | `(0.222, 0.437, -0.010)` | 工具自己找到的尾骨 ✓ |
| 玄蜂 | `Bone04` | `(-0.549, 0.380, 0.899)` | 没有尾骨，取最近骨骼 ✓ |

> **每招的偏移不一样**（a1 / a2 分开量）：武器在两次动作里位置不同，
> 而发射发生在**各自的百分比那一帧**，所以偏移必须按招分别量。

### 坑（这一节的两个都是当场踩的）
1. **`InverseTransformPoint` 要的是世界坐标**：我第一版把**角色本地坐标**直接喂进去，
   量出来是 `248 / -208` 这种几百米的鬼数字。
2. **同名 FBX 会骗过 `Resources.Load`**：`MingYao_01.FBX` 和 `MingYao_01.prefab`
   **同目录同名**，`Resources.Load` 拿到哪个不确定 —— 拿到 FBX 会显示"没有控制器/没有 AI"，
   量出来全是错的。工具里改成**按文件夹全取、挑带 `NpcInstance` 的那个**。

## 5. 箭魔 / 玄蜂：用 `Object135` 做实体箭

用户指定：「使用箭魔的子组件 `object135` 作为飞弹，**注意箭头朝向目标**」。

`Object135` 是**蒙皮网格**（246 顶点，1 根骨骼 `Bone12`）→ 用 `BakeMesh` 烘成静态网格资产
`特效/飞弹/专属/箭矢_Object135_Mesh.asset`，再做成 prefab `特效/飞弹/专属/箭矢_Object135.prefab`。

### 烘的时候必须做两件事（**第一版漏了，用户当场看出"箭是斜着飞的"**）

| 坑 | 现象 | 修法 |
|---|---|---|
| **网格里的箭是"斜"的** | 烘出来包围盒是 `1.23 × 0.50 × 1.61` —— 看着像个"扁盒子"，实际里面是**一根斜着的杆**（斜着放，AABB 就被撑成方的）。直接当弹体 → **箭斜着飞**，不是正对飞行方向 | 用**主轴**对正：找 **相距最远的一对顶点**当轴向（`(-0.601, 0.196, 0.775)`），`Quaternion.FromToRotation(轴, Vector3.forward)` 转过去。对正后包围盒变成 **`0.150 × 0.122 × 1.916`** —— 一眼就是根 1.9 米的箭 ✓ |
| **网格中心不在原点** | 包围盒中心 `(-0.96, 0.85, 1.47)` → 箭会**飘在手外面 ~1.9 米** | 顶点全部**减去包围盒中心**，居中 |

### 朝向（"+Z = 飞行方向"）怎么定
`NpcProjectile` 是 `transform.forward = 飞行方向`，所以箭尖必须在 **+Z**。判断办法两条一起用：
1. **算**：取轴向两端各 18% 的顶点，算**平均横向铺开** —— 细的那端是箭尖
   （实测 `-Z` 端 0.023、`+Z` 端 0.060 → **尖端在 -Z，反的**）
2. **看**：侧视渲一张，+Z 放方块、-Z 放球，一眼就知道尖端朝哪边

确认反了 → 重烘时多乘一个 `Quaternion.Euler(0, 180, 0)`。
证据图：`screenshots/箭矢侧视图.png`（反的，箭羽在方块那侧）/ `箭矢侧视_翻后.png`（对的，**箭尖对着方块**）。

> prefab 是**光板一层**（MeshFilter + MeshRenderer），**没有**用来纠朝向的子节点 ——
> 朝向已经烘进网格里了，这样 `NpcProjectile` 怎么转它都对。

实测：箭飞出去**朝向与指向玩家的夹角 = 0°** ✓（箭尖一直对着玩家）。

## 6. 混合怪（蜘蛛精）为什么要"距离门槛"

蜘蛛精 a1 是**近战**、a2 是**飞弹**。而 `可用出手方式()` 是**随机挑**的 ——
它站在 12 米外也可能随机挑到 a1，**对着空气挥爪子**。

所以给 `NpcAttackConfig` 加了两个字段（**对所有怪都通用**）：

| 字段 | 意思 |
|---|---|
| `出手最小距离` | **太近不出这一招**（0 = 不限） |
| `出手最大距离` | **太远不出这一招**（0 = 不限） |

蜘蛛精：a1 只在 **≤3.5 米**出、a2 只在 **≥3.0 米**出（留 0.5 米重叠，免得出现"两招都不能出"的空档）。
**实测**：贴到 2.5 米 → 出手 3 次**全是 Attack1 近战** ✓；放到 11 米 → 出手只有 **Attack2 飞弹** ✓。

### 顺手修掉一个真 bug
**怪死了、飞弹还在飞** → 命中回调访问已销毁的施法者 → `MissingReferenceException`
（堆栈：`生成装饰特效` 里的 `name`）。飞弹的命中回调是挂在 `NpcProjectile.到达时` 上的闭包，
怪被销毁后**照样会跑**。
**修**：`生成装饰特效` 里名字兜底（`this != null ? name : "已销毁的施法者"`）；
**伤害不掐**（弹都飞出来了，该打还得打）。实测：出箭后立刻销毁施法者 → 异常数 **0** ✓
