# 角色界面统一布局

当前规则（2026-10-14）：背包、法则、神通按列表、展示、介绍分区；共用水墨幕布和简洁按钮。外观的列表、介绍和条目底，以及法宝/坐骑展示底同步使用柔边墨云；其余页内部布局保持。

## 视觉与交互

大幕布的核心是水墨、明显流动、底部渐变、纵深层次。CharacterCurtain.shader 使用远近两层不同速率的墨云和缓动视差；UIInkDensitySimulation 在256×144的持久密度/速度纹理中推进墨流，鼠标划动会带动局部云雾、旋涡和墨丝，指针离开后继续消散。规则水纹只保留很弱的辅助光感。幕布向窗口外延伸54单位，四边以约92～117单位的变化云雾渐隐，避免硬切矩形。使用非缩放时间，游戏暂停时仍流动；减少动效选项固定时钟并停用墨流互动。配色按当前场景调整为暖灰、墨绿与淡米色，上部较暗、下部较亮，介绍和列表底共用低对比墨云，左右与顶部软边、底部逐渐溶入大幕布。色彩在当前线性管线中转换后输出。

列表卡片使用 CharacterCard.shader：圆角细框、暗色纹样、底部品质色渐光和名称底栏。主图标与边框留白，数量靠近右下，不显示物品等级。列表首尾使用视口渐隐，卡片等距排列，不再按数量散乱变形或错列。按钮改为程序绘制的半透明圆角和细边框，移除金色花边、纸卷与大墨团；原点击、禁用和文字状态仍有效。

背包为左侧六列虚拟化卡片与右侧介绍：名称、品阶、类别、大图标、持有数量、可滚动介绍及物品使用操作。UIEntryList、UIPanelData 与物品使用器继续负责选择、堆叠数量及扣除。

法则默认进入装备总览：左侧为当前装备法则的汇总增益，右侧为原人物御风动画、六个法则仪轨和拖拽槽位。点击「法则背包」或右侧法则进入背包页。背包左侧三列收藏，境界按钮循环筛选全部/九境界，搜索框按名称匹配；中间沿用人物和仪轨，右侧显示选中法则属性、主属性进度和精粹洗练。属性名与数值在同一行，小固定值保留足够小数位，避免显示成 +0。人物仪轨相机根据展示区域宽高比调整视野，左右法则完整留在展示区域内。

「熔炼法则」展开炉鼎面板：一键放入、拖入、开始熔炼及取回继续走 LawRefinementSystem。精粹仍放在左上，熔炼粒子飞向精粹。Esc 先收起炉鼎，再从法则背包回总览；总览再按 Esc 才关闭角色面板。返回不会解除角色界面的暂停与输入锁。

神通从左到右为三列已悟卡片、原三维星空装备栏、独立神通展示、属性和介绍。UIInkSkillVolume、六个立体双环星位、悬浮视差、流动连线、随机被动星点和双向拖拽全部保留，只移动区域。选中、点选待装备、拖入、换位、卸下和被动启停继续使用原控制器。

法则和主动神通可直接拖动未选中的条目：按下时锁定拖拽来源，拖动开始同步选择，释放到槽位沿用原装备流程。法则新版列表使用滚轮或空白区滚动，卡片拖动直接拿起法则；滚动过程中不会把被按下的条目换成另一个。

外观列表、条目和介绍区共用柔边墨云，法宝/坐骑的模型仍使用原隔离3D舞台。展示相机保持透明背景；没有条目或模型加载失败时隐藏预览贴图，空状态相机留在隔离舞台，避免误拍游戏场景原点。

UIAbilityPreview 改为独立的人物与练功木桩舞台，木桩为固定演示目标。人物使用当前外观与原施法动画，在完整动作/表现之后间隔一秒重复；骤雨保留起手、第二段下蹲出剑、共享弧长剑幕和 SwordFlight 出口直刺曲线，展示预算144柄。天降读取 FallingSpellPattern 的数量/间隔与原飞行、命中素材；追踪弹演示弹体、命中段，水炮沿两点对准原光束，小剑阵手动推进源 AbilityVfxEmitter。被动雷云/雷狱显示落雷，护罩显示护体，凭虚御风等机制性被动保持简化人物展示。

预览的动画和粒子按非缩放时间独立推进，先起播再暂停并手动模拟，避免未起播系统只有动画而没有实际粒子。实例移除游戏逻辑、声音、碰撞与刚体，演示不扣灵力、不计冷却、不改装备，也不触发真实伤害或地面破坏。关闭页面停用舞台，销毁时清理图和材质；法则与神通预览都响应外观变化，重新打开时也同步当前网格、材质。完整战斗结算仍由原神通执行器负责。

## 本轮表现缺陷修复

焚天炎术 Effect_13_Distort 的主体材质引用缺失，恢复为现有 Effect_Common_Distort_4；实际渲染存在火焰像素且紫色错误像素为0。冰暴术 frost-frozen-tomb 的 rays-* 原为9倍长度的 Stretch，改为普通 Billboard 和短闪光，保留冰冢网格、裂纹、环波与自然生命周期。

NpcProjectile 接入的八类 PFX 弹体不再同时使用源15m/s世界粒子位移和根节点推进：主体/Trail改为Local、起速0，飞行器是唯一位移来源；原生粒子轨迹保留worldSpace，沿路烟、火花和星光仍在World，按距离补发。伤害、追踪、拦截和消散规则保持原管线。

ui-presentation-bugs.cs.txt 专项验证112项，包括八种弹体实际飞行后仍居中、沿路世界空间保留、十四门主动动画、实际粒子、循环及无真实装备/暂停影响、换装后的两个展示人物。
