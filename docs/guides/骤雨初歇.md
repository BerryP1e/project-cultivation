# 骤雨初歇

2026-10-13现行实现。天品物理主动神通：引导剑从底部沿变形椭圆条带滑过，留下幻影并凝实为288柄灵剑。剑共用一条弧长基准，均匀排成环绕角色的斜铺剑幕，保留少量边缘微光。随后按连续起伏的高速节奏逐把主动射出，曲线脱阵后沿固定切线直刺目标周围四米区域，并在地面短暂停留。玄霄四式调色见[命中特效管线](战斗命中特效管线.md#31-四式统一a1雷色2026-10-13)。剑雨落花的施放及命中音效仍关闭。

## 均匀剑幕与幻影

`SpiralSwordCurves.Ribbon`使用椭圆极径、变化离心率和长轴进动：

```text
θ = u × 圈数 × 2π
 a = 2.2 + 0.12θ
 e = clamp(平均离心率 + 波动幅度 × sin(频率 × θ + 随机相位), 0.12, 0.88)
 b = a × sqrt(1 − e²)
 r = a × b / sqrt((b cosθ)² + (a sinθ)²)
 φ = 随机相位 + 进动速度 × θ
 x,z = r × cos/sin(θ + φ)
 y = 基础高度 + 正弦起伏 + 0.35e + 4.2u
```

总体包络向外展开，实际半径会局部缩回。每次施放只随机一次参数。主体比旧版缩小径向扩张、拉开高度，避免大面积水平辐条。

全体剑共用一个640段弧长查表，按`(i+0.5)/剑数`等距排布；不再将不同长度的四列曲线分别归一后重叠。那种排法会造成一簇簇的间距，本版同时由384柄减为288柄，让相邻剑略有留白。局部朝向以条带宽度为主，并统一斜铺约24°，剑面形成连贯剑幕。校准网格长2.2米、剑尖为+Z、原点在剑尖。

一柄1.15倍尺寸的引导剑从底部扫至外缘，全尺寸幻影随它经过出现，透明度从8%经SmoothStep在0.3秒内凝实。末段凝实后才进入蓄势和出剑。未发射剑沿弧长缓流；开放条带端点淡出、淡入。所有剑共享相同弧长流动规则，保持均匀间距。剑幕整体透明度为0.85，头尾各12%弧长用SmoothStep渐变为约8%的中段透明度，边缘微光同步变淡；不通过随机缺剑破坏间距。出发后用0.08秒将端部半透明剑凝实，保持直刺的力量感；实际伤害和碰撞不随透明度改变。

## 少量边缘微光

条带曲线只供计算，不渲染轨道线。没有LineRenderer、环带线或连续线状尾迹；旧线材质及Shader已删除。

星光复用Point19柔点纹理，每6柄在剑尖或剑柄边缘交替留一颗微光，沿剑带移动和轻微闪烁。法线游移只有0.025米，不再向宽度、厚度和周围空间随机撒满光点。默认成形期约48颗；在飞剑每柄最多一颗离散微光，接触后关闭。默认总量不超过112颗，固定缓冲保留1024上限以兼容配置；条带轮廓主要由剑形成。

## 快速逐剑出发

Fisher–Yates只随机发射顺序，每柄有独立时间戳。连续调节的是速率：

```text
φ = 2π × 出剑经过时间 / 出剑波动周期
wave = 0.7 cosφ + 0.3 cos(1.63φ + 0.4)
rate = (1 + 出剑波动幅度 × wave) / 发射间隔
```

默认约154柄每秒并平滑起伏，起步接近峰值。以速率倒数的中点采样生成每柄独立时刻，无同时批射及批次间停顿。同帧推进多柄时，按各自发射时间、条带位置推进，飞行进度有区别。达到64柄在飞预算时顺延剩余时序，避免积压后一次喷出；已接触的插地剑释放飞行预算。

起飞前依次朝各自区域落点准备，起飞速度直接达到配置速度的80%，不再从0.55米每秒缓慢提速。朝向始终取实际轨迹导数，不额外插值朝向敌人中心。

## 曲线脱阵与范围直刺

目标或鼠标点只定义范围中心。落点使用黄金角均匀覆盖圆盘：

```text
rᵢ = 范围 × sqrt((i+0.5)/剑数)
θᵢ = i × 2.39996323
落点XZ = 范围中心XZ + rᵢ × (cosθᵢ, sinθᵢ)
```

每柄出发时将落点投影到实际地表，忽略玩家、NPC和过陡表面；找不到地表时使用对应高度的规划落点。旧剑保持原落点，新剑读取当前目标位置。目标销毁后保留最后中心，手动施放中心固定。伤害仅在实际接触时发生。

`SwordFlight`的出口保留起点径向截面的62%，整体偏转0.14～0.28圈，不把出口收成敌人中心的尖点。前58%使用三次Hermite曲线：起点位置及起飞速度为一端，出口位置和后段直线速度为另一端。出口位于地表上方，后42%为`出口 → 各自落点`的匀速直线，交接位置和速度连续。这个末段的方向固定，剑尖跟随它，不再寻找敌人或向共同圆锥尖点扭转。

首次接触地面后，剑尖轻埋0.08米，保留入射方向停留1.1秒，再淡出0.35秒；生物或其他接触只短暂淡出。插地剑没有后续碰撞或重复伤害。这样会形成覆盖敌人周围的剑雨，而不是全部吸到敌人身上。

## 管线与资源

`ActiveSkillKind.螺旋剑雨=10`保留旧枚举和ID。`ActiveSkillCaster`验证资源、神识、灵力和动画占用，成功起手后仅扣一次灵力和启动一次冷却。执行体细分实际曲线，以SphereCast检出首次接触；`CombatHitBatch → CombatDamagePipeline`结算主动物理伤害，每剑对目标根去重。环境表现走`CombatImpactPipeline → CombatVfxPipeline`。

命中派生体取Knife hit的Sparks、SparksExpl、SmokeExpl、Shockwave，去掉重复剑本体，保留小爆闪和冲击波，压缩寿命及粒子预算；不添加音效或场景灯光。顿帧沿用仅受击方规则和共享触发间隔，环境形状为None。

一个网格粒子系统表示全体剑，加一柄仅布阵期存在的引导剑；最大支持384柄及一个引导粒子，逐帧不创建独立剑对象或线渲染器。固定32扫掠及64重叠缓冲。暂停冻结时钟、渲染位置和接触；取消立即清理，所有剑淡出完后自然回收，13秒保护超时兜底。不写存档或正式场景。

成品为`Assets/resources/Abilities/SpiralSwordRain`，派生发光材质集中于`Assets/Art/VFX/Project/SpiralSwordRain`。共用sword2校准网格、纹理、能量05/03成品和Knife hit依赖。菜单 **修仙/神通/重建骤雨初歇（不动场景）**；数值由神通/物品表管理，几何及时序由`SpiralSwordPattern`管理，保留成品GUID及Resources动态根。
