# 太虚炼气诀四式

2026-10-20：`basic_remoteattack_01`由单式扩展为A1～A4循环，复用玄霄雷诀和沧澜寒渊录的四个成品动作；出手节点为40%、40%、43%、50%，动画随攻速缩放。太虚、玄霄与沧澜三套普攻均取消动作结束后的额外冷却，旧场景中保留的基础冷却数值不再参与计算。左键一次推进一式，普通锁定不自动连打；装备邪眼后可自动接下一式。

| 段数 | 表现 | 默认伤害倍率 |
| --- | --- | --- |
| A1 | 原右手火球 | 1 |
| A2 | 同主题火球，弹体为A1的1.35倍 | 1.25 |
| A3 | 目标处召唤一枚火岩陨的原生陨石，接触后爆炸，范围2.2米 | 1.6 |
| A4 | 身后两侧共六颗A1火球，短暂停留后沿各自二次曲线外绕，再追向目标或飞向鼠标点 | 每颗0.35，总计2.1 |

数值是本轮初值，可在`BasicRemoteAttack01.四式倍率`等字段调整。四式均走特殊属性普通攻击，引用火岩陨只复用表现和接触执行体，不消耗神通灵力，不带入其主动倍率、冷却或施法动作。陨石在实际碰撞时结算，范围内同一NPC的多个碰撞体去重；六火球各自单次结算。未锁定时仅攻击落点附近敌对NPC；锁定弹捕获出手时的目标，后续换锁不改变在途飞弹。

实现入口为`BasicRemoteAttack01`、`FallingSpellRunner.尝试普攻陨石`及`NpcProjectile.设置外绕出膛`。动作打断、闪避、死亡或卸装会取消尚未出手的攻击，不借其他动作进度补发。原主动火岩陨保留其独立的主动神通伤害分支。
