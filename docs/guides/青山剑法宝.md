# 青山剑法宝

青山剑替代原青云剑诀的自动飞剑功能，独立于修炼功法。在传法阁兑换「青山剑·待认主」（120 宗门贡献），背包点击「滴血认主」解锁，再到法宝页装备。重复认主禁用，重复道具保留，新角色不会自动获得。

## 操作与成长

装备后自动攻击神识范围内的锁定目标。右键右下角法宝图标打开信息窗：平放的透明背景 3D 飞剑、当前剑数、下一级击杀进度及招式状态。图标点击时轻微缩放，ESC 或关闭按钮退出。E 直接施放法宝技能，不再使用长按手势；对话、菜单和演出期间阻止场景输入并暂停飞剑。

每击杀 50 个同级或更高级妖魔增加一把剑，初始一把，最多九把（400 次有效击杀）。只在装备青山剑期间计入玩家造成的有效击杀，采用妖魔当前等级补正；低级妖魔、立即重生练功目标和战阵真灵不计。升级即时补出新剑，不因卸下或换功法重置。

一剑保持角色右后方原位置；二剑在后方左右对称；三至九剑在角色身后扇形铺开，剑尖整体向下、向内，保留间隔，整组额外向后让出 0.65 米，避免贴着角色身体。剑列以缓动和轻微转向延迟追随玩家，单剑错相上下浮动并小幅摆动，移动拖尾受限；瞬移时重置跟随惯性。多剑采用相位错开的螺旋轨迹飞出，从不同方向穿刺锁定目标，每轮改变切入角度。飞出、穿刺和绕回曲线共享交接处切线，螺旋偏移在端点平滑收束，剑身转向使用插值，避免突然折角。物理结算保持 100% 命中，仍须满足飞剑穿体判定。

P 键调试面板提供 1～9 级按钮，认主后可直接调整青山剑等级（对应剑数），有效击杀进度同时设为该级起点；不用重新装备，关闭调试面板后即时显示新剑列。

## 万剑归宗

三剑起解锁 E 主动技能，要求锁定神识范围内的存活目标。流程为：

1. 所有飞剑归位，化成灵光向上升空并消散。
2. 目标根节点正上方约两秒凝聚巨剑，剑尖垂直向下；补偿实际剑尖与模型轴心的偏移，使贯穿轴线对准目标根节点的 X/Z。粒子轮廓取自实际模型。巨剑最小为普通飞剑的 10.13 倍，后续每剑增加 0.15 倍。
3. 剑尖首次接触目标时触发一次伤害与 Effect_07_OneHandSmash，Z 轴朝下。命中特效基础倍率 0.22（此前的四倍），随巨剑尺寸放大；以 0.55 倍速播放，八秒后清理。
4. 巨剑继续向下贯穿约 1.2 秒，保持完整尺寸。穿过目标根节点水平面的前端用材质裁切逐段隐藏，并在切口生成消散粒子；整把剑穿完才移除模型。命中后即使目标死亡，也会完成贯穿。
5. 粒子余辉持续消散约 1.2 秒，普通飞剑恢复悬浮和自动攻击。


当前初始数值：冷却 18 秒、物理主动神通伤害倍率 6。更换法宝、玩家死亡或首次接触前目标失效会清理技能临时物体；首次命中后的贯穿和消散阶段正常完成。可在驱动组件调整数值。

首次接触时也破坏目标根节点/手动落点周围的体素，半径为原配置乘2/3，三剑默认由6米缩至4米，并随巨剑尺寸放大。敌人伤害范围、巨剑模型和命中特效尺寸不因这次体素调整而缩小；规则见[正式地图体素试点](正式地图体素试点.md)。

Alt+E的落点圈使用相同体素半径计算，包含剑数增长和巨剑基础倍率；超距变色使用法宝实际神识范围。

## 场景同步

古古镇、宗门、个人洞府、宗门野外和镇妖塔五个游戏场景均挂载法宝控制器与青山剑驱动，同步悬浮后移、漂浮跟随、巨剑尺寸和贯穿参数。移除旧飞剑功法绑定，普攻登记改为太虚剑决；场景自举和一致性体检同时登记两种法宝组件。仅修改对应组件和绑定，不整体重序列化或覆盖场景布局。
