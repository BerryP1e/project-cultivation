# 基础飞剑与灵虚剑决攻击模组

更新：2026-10-22。灵虚剑决不再作为修行功法学习，攻击模组由独立“基础飞剑”提供，方法id为basic_lingxu_sword_01。操作和保存见[武器与修行功法](武器与修行功法.md)。

## 三式与独立剑

A1为原法师AttackA（1.2秒），A2为AttackB（2秒），A3为SkillA（2秒）。按顺序轮转，E逐次施放，伤害为物理普通攻击，判定18%～95%、距离2.6米、接触外扩0.55米。沿用实际剑身接触与一轮去重，不破坏体素。修行功法左键攻击仍用其原动作，不使用手持武器施法替换。

剑不是手持，挂在Animator下的“灵虚剑/LingxuSword”独立动画路径。Prop1烘焙TRS保留源剑路；角色和剑由同一Animator播放，不能误挂到手骨。A2出剑阶段身体RootQ已收束侧向偏航，原位置/转动/缩放曲线与手指不随意覆盖。

## 地面与御风

用户明确设定：飞剑在地面也使用御风身体姿态。WeaponCarryAnim将地面idle映射灵虚版御风悬停，走/跑八方向各自映射同方向灵虚御风成品；不能恢复普通走路，也不能把所有方向替成向前。

LingxuFlightSword在Animator后只管理独立剑收放：空闲真实飞行时移至脚下、剑尖向人物前方；停步、锁定/选中战斗或出招后短时间保留身后位置。地面移动保留原已标定的身侧垂剑。脚下位置依据当前双脚重新计算，不从上一帧已改过的节点递推，避免漂移与穿鞋底。

攻击及收招过渡期间完整交还原Prop动画，不能由收放组件覆盖实际攻击轨迹；连续出招间不反复回脚下。收放时长0.3秒，出招后战斗保持1.2秒，数据保留在现有prefab。修改时同时检查地面视觉、实际御风、攻击进出、重新装备和跨场景恢复。
