# 镇妖葫与真灵收服

镇妖葫是第一个可用法宝。在传法阁兑换「镇妖葫·待认主」，于背包点击「滴血认主」后获得镇妖葫；在角色面板的法宝页装备后，右下角独立法宝槽显示图标和 **E**，不占用神通 1～6。界面、对话或演出锁开启时不能施放。

战阵已从 I 键角色面板及左侧导航移除，剩余七个入口收拢排列。装备并认主镇妖葫后，右键右下角法宝图标打开独立战阵窗口，图标轻微缩放反馈点击。按下 E 立即施放或取消收服，不再等待松开或长按。青山剑右键打开成长信息窗，E 在三剑后施放万剑归宗。

真灵阵位只是配置：必须装备镇妖葫才会实际放出。切换或卸下镇妖葫时，真灵立即停止行动，身形散为粒子并飞回玩家；阵位保留，重新装备后恢复出战。独立战阵窗口暂停游戏并阻止场景输入，ESC 或关闭按钮恢复；未装备镇妖葫不能打开。

锁定一个可凝成真灵的目标后按 E，葫芦从玩家身上抛出、放大，在目标旁悬停，瓶口指向目标并轻微晃动。Teleport_3 的原有粒子环改为沿目标至瓶口的轴线移动、逐渐缩小：大端在目标，小端在瓶口，瓶口保留细粒子。

每秒造成一次弱特殊伤害。只有本次葫芦至少造成一次实际伤害，原锁定目标在施放期间死亡，才会收服；允许其他攻击补刀。目标模型在死亡隐藏之前定格，随后缩小飞入瓶口，葫芦晃动、飞回玩家并消失。吸入完成后授予对应真灵，重复捕获同种真灵不会重复添加列表项。途中改变锁定不会改变本次收服目标。

无敌目标、战阵真灵、立即重生的练功目标不能收服。再次按 E、卸下法宝、目标消失、玩家死亡、超距或超时都会回收；未完成吸入不授予真灵。默认距离 25 米，最长施放 30 秒，冷却 6 秒，伤害倍率 0.05，放大比例 1.65，可在镇妖葫定义或法宝表调整。

## 数据保存

- `PanelDatabase.真灵` 是可收服目录；`UIPanelData.已获得真灵` 才是玩家捕获记录，目录刷新和表格导入都不再赠送真灵。
- `UIPanelData.法宝` 是目录，`已拥有法宝` 保存拥有 id，`当前法宝` 保存装备。
- 存档 v17 使用原来的 `SaveData.法宝` 保存拥有 id，新增 `当前法宝` 和 `收服系统已初始化`；保存捕获真灵 id 和战阵站位。按目录查找定义，不依赖目标此时在场景里。
- 跨场景快照同时携带拥有法宝、当前法宝、真灵和战阵站位。过渡期间再次套用存档时，这部分优先使用快照，避免覆盖未手动保存的新捕获记录。

## UI 与资产

战阵入口控制在 `Assets/Scripts/UI/GourdFormationUI.cs`，右键图标入口在 `Assets/Scripts/UI/TreasureSkillHud.cs`；出战装备限制由 `SpiritFormationManager` 执行，回收效果在 `SpiritRecallEffect.cs`。这些调整仅在运行时拆出既有战阵页面，不重序列化场景。

法宝和坐骑共用 `UIEquipmentShowcasePage`：上方透明背景真 3D 模型、左右拖动，下面为简介、持有图标分页和装备按钮。坐骑依然只显示已学会的坐骑，并保留坐骑与凭虚御风的互斥。

原始 FBX 保留在 `Assets/TripoModels/镇妖葫/镇妖葫.fbx`。运行时模型在 `Assets/resources/法宝/镇妖葫/镇妖葫模型.prefab`，定义在 `Assets/Data/Generated/TreasureDefinition/treasure_zhenyaohu.asset`，原生渲染图标在 `Assets/resources/法宝/镇妖葫/镇妖葫图标.png`。

菜单 `Cultivation/Treasures/Build Zhenyaohu Assets` 仅生成模型包装、图标、定义和目录引用，不保存或重建场景。包装保留 FBX 自带的轴向旋转，瓶口在包装坐标 `(0, 0.96, 0)`，朝向 +Y。

进入 Play 后通过运行时脚本调用 `ZhenyaohuChecks.Begin()` 可验证施放、伤害归属、死亡吸入、回收、JSON 和跨场景接力。测试不写入用户存档；报告在忽略目录 `.dsh/_diag/gourd-checks.json`。
