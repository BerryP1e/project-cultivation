# 御风闪避

更新于2026-10-13。仅凭虚御风的稳定悬浮状态开放；地面、升空、落地、骑乘及上下坐骑过渡不能闪避。

## 操作与参数

空格加 WASD 或方向键，沿相机相对的输入方向闪避；单按空格，相对人物当前视觉朝向后闪。斜向不增加距离，锁敌时保留当前朝向基准，转身由动画表现。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 距离 | 6米 | `PlayerFlightDodge.距离`，撞墙缩短实际距离 |
| 时长 | 0.45秒 | 完整移动及伤害免疫窗口 |
| 冷却 | 0.9秒 | 从起手计时，至少覆盖闪避本身时长 |
| 动作衔接起点 | 45% | 从中段逐渐混入闪避方向对应的八向御风，结束时完全交接 |

位移使用累计距离曲线 `t - 0.08 sin(2πt)`，保留轻微起收势但末段不减速到零，不受移速和攻速倍率放大。无额外灵力消耗，御风维持消耗照常。`PlayerController` 只调用 `CharacterController.Move`，不设置位置或同时叠加普通水平移动；悬浮高度继续由御风控制。

## 动作与资产

| 方向 | 来源与处理 |
| --- | --- |
| 前、左、左前 | 已确认的 `Assets/Animations/凭虚御风/Kimodo/御风_左旋闪避.anim`，保留躯干及收腿趋势 |
| 右、右前 | 使用真实玩家Avatar和人形镜像状态烘焙，保留与左旋相反的完整转身 |
| 后及后侧斜向 | `avoid_back_inplace.fbx`，以御风为腿部基准，减弱蹬地、足踝滚动及起跳/下蹲高度，取后撤身体变化趋势 |

成品在 `Assets/Animations/凭虚御风/闪避/<自由手或功法>/`，原Kimodo定稿动画和源FBX保留。肩臂使用局部肌肉曲线，自然跟随躯干旋转；自由手降低平举幅度，持械右臂采用握持基准和少量惯性，腕部受限，40条手指曲线保留。根XZ归零，起止回到御风姿态，起手0.055秒融合。

从闪避45%处开始向 `Yufeng_Forward` 的八向树融合：`FlyX/FlyY` 依据闪避世界方向与当前视觉朝向计算，兼容锁敌及模型Yaw补偿，不跟随过渡期间改按的方向。融合时间取闪避剩余时长，移动权重逐步升至100%，目标片段从开头播放，结束时保留已经混合的相位，不重新起播。`DodgeActionRate` 默认1，仅闪避期间让Action状态按固定0.45秒窗口加速；八向片段保持正常倍率。结束/中断复位该参数，其他普攻和施法沿用原有倍率。

移动与免疫仍由完整0.45秒位移时钟决定，动画提前混合不会提前失去免疫或叠加普通水平位移。最后一帧按实际输入交接御风速度，同时立即同步动画速度，避免上一帧零速平滑值触发一次待机。继续按方向无需重新加速；松开方向正常收回悬停。

八九玄功、太虚剑决、灵虚剑决有独立变体，统一配置为 `Assets/resources/Abilities/YufengDodgeAnimations.asset`。灵虚剑闪避时由 `LingxuFlightSword` 根据本帧髋骨保持后方位置，不沿用剑的攻击轨迹。其他功法使用自由手版本。

菜单 **修仙 / 动画 / 重建御风闪避（不动场景）**，实现 `YufengDodgeBaker`。重复构建保留成品GUID，并确保共享AnimatorController的Action状态有默认1的 `DodgeActionRate` 速度参数；八向御风重建也保留此配置，不修改游玩场景。删除不用的地面手脚IK目标，离线压缩线性关键帧；肌肉误差不超过0.0005，根四元数单分量误差不超过0.00008。12段动作文本资产由约66.7MiB减为34.9MiB，无运行时压缩开销。

## 管线与中断

`PlayerController.Awake` 自动补充 `PlayerFlightDodge`，各场景使用同一组件和Resources配置。闪避输入在执行顺序-100读取，先于普通移动和普攻；普通控制器推进时钟并执行碰撞移动。

`PlayerVitals.无敌` 独立合并闪避免疫，与调试、复活和过场保护互不覆盖。伤害管线在随机判定及护盾消耗前返回Immune，直接伤害也免疫；物理/特殊、普攻/主动/被动六组合统一处理。最后一帧位移完成后关闭免疫。

闪避占用共用动作入口，期间不能被新普攻或施法抢走。可以打断普攻和特殊待机：近战停止刃光及待触发判定，远程丢弃尚未发射的子弹，已发出的子弹正常继续。已经独占动作的引导施法需先结束。闪避期间不响应手动御风/骑乘切换；强制落地、死亡、界面输入锁或禁用玩家移动立即取消免疫和占用。顿帧暂停本单位的位移与动画时钟，不改变全场时间。

## 残影与擦身慢镜（2026-10-12）

`FlightDodgeVfx` 最多六份蒙皮快照，每0.045秒采样，0.26秒内淡出；网格循环复用，退出销毁。残影保留较暗的青灰色，2026-10-13将不透明度从0.14提高到0.24，略微延长消散以强化可见度，螺旋风丝和少量游离粒子随闪避旋转。`BakeMesh` 已包含当前骨架缩放，残影节点使用单位缩放，避免正式玩家1.80072倍缩放重复放大；不改角色共享材质。Shader集中于 `Assets/resources/VFX/FlightDodgeGhost.shader` 并登记运行资源根。

闪避期间临时启用以判定高度为球心、半径1.25米的擦身范围；`NpcProjectile` 检查本帧完整弹道线段加子弹半径，近战仅在有效挥击窗口检查武器Bounds。范围只触发反馈，不改变CharacterController、真实伤害半径或飞弹寿命，不会把路过的粒子、场景石头和树当成攻击。实际命中管线Immune和旧正数直接伤害入口也可触发。

每次闪避最多触发一次：世界0.2倍速、约0.3秒真实时间，最后0.08秒平滑恢复；镜头视野最多收窄8%，0.035秒进入、0.12秒退出，只作用于跟随该玩家的TopDownCamera，不改滚轮基准距离。世界共用时间倍率使所有生物、飞弹、技能节点、粒子与物理保持同步；不是单个受击单位的顿帧。`DodgeNearMissFocus` 保留原timeScale/fixedDeltaTime，暂停、演出、禁用移动和卸载及时取消；若其他系统改写倍率，不覆盖对方的新值。调试/复活/过场免疫不触发，伤害与护盾保持免疫，反馈不消耗伤害随机数。
