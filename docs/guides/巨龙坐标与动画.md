2026-10-14补充：预制体根节点的 `NpcAnimator` Inspector 增加 **预制体动画预览**，直接列出 Animator 已绑定的六段成品动画，并显示带材质的巨龙。选择动作即可播放；可以暂停、重播、开关循环、调整0.1～2倍速度，拖动秒数滑条检查具体姿势。拖动预览区域旋转视角，滚轮缩放，点击「适配视野」复位缩放。

## 整体旋转的处理

源骨架位于 `BossLeiLong (merge)/BossLeiLong`，蒙皮位于 `BossLeiLong (merge)/BossLeiLong_MengPi/BossLeiLong`。两条支路各有 X=-90°；源动画还会写回骨架边界旋转，技能一和死亡包含额外动态变化。只改预制体静态旋转会在播放时被动画覆盖。

取 `Q = Quaternion.Euler(90, 0, 0)`，在两个实际模型边界同时写入 `p' = Q*p`、`q' = Q*q`，边界之下的关节局部动作保留。六段动画的边界四元数曲线使用精确线性组合转换，关键帧时间和插值切线同时转换；位移曲线对应 `(x,y,z) -> (x,-z,y)`，不是只修待机首帧。技能一的抬头/俯身及死亡的转向因此仍保留原动作趋势。

骨架与蒙皮节点接受相同的整体旋转，蒙皮局部矩阵满足 `(Q*M)^-1*(Q*B) = M^-1*B`，所以原网格顶点、法线、权重和 bindpose 仍然匹配，无须另给网格或某条骨骼重复旋转。根部 CapsuleCollider 中心接受相同旋转，长轴由 Y 改为 Z，原尺寸保留。中间容器保持单位变换，没有添加旋转补偿父物体或运行时修正脚本。

## 重烘焙与验证

工具：`cultivation/Assets/Editor/Tools/JuLongCoordinateBaker.cs`。停止 Play 后执行菜单 **修仙 → 动画 → 烘焙巨龙整体X轴＋90°（不动场景）**。工具始终从原 FBX 读取六段动画，更新现有成品并保留 GUID；会辨别原始/已转换姿态，碰撞体不会重复累加旋转。若用户修改了模型边界或容器坐标，会报错提示检查，避免把自定义调整误当原始素材。

验证入口：`devtools/validation/julong-coordinates.cs.txt`，通过 `exec_editor_script` 执行。每段动画采样38个时间点（包括非关键帧），再换137°生成朝向和非零位置，总计456组姿态；实际骨骼及全部6512个蒙皮顶点与源动作整体 +90° 对照。六个原生控制器状态也分别对照原片段替换控制器，包含原生循环混合，另检查碰撞体轴向与尺寸。
