## 2. 接口与文件

`CombatVfxPipeline.命中(id, AttackResult, point, direction, size)` 负责命中成功检查，再按目录生成表现；`播放` 用于地表撞击或攻击主体，独立于是否打中生物。两者都不重复调用伤害公式。

配置资产是 `Assets/resources/Combat/CombatVfxCatalog.asset`：每项保存id、源prefab、缩放、旋转、是否跟随来向、散布半径与最长存活。代码在 `Assets/Scripts/Combat/CombatVfxCatalog.cs`、`CombatVfxPipeline.cs`、`ExtremeVfxAdapter.cs`。菜单 **修仙 / 战斗 / 重建命中特效目录（不动场景）** 由 `CombatVfxAssets` 生成九项映射；重建会恢复本轮默认配置，调参后不要无意重建。

执行体保留源根缩放/旋转，忽略演示场景中的根位置。第三方EFX原有生成器在实例上关闭，由适配器接管：按原脚本的世界偏移、绝对缩放、数量和生成间隔生成子特效；挂在静止的生命周期根下统一回收，不挂到正在移动的发射器上，避免子雷光重复叠加父级位移。不调用包内的全局IgnoreLayerCollision/爆炸推力。纹理动画使用MaterialPropertyBlock，不复制材质。使用原生节点/子对象寿命，不再给0.1～0.2秒的雷光额外延长0.2～0.3秒；节点只在原寿命最后20%（最多0.12秒）淡出。目录最长存活只负责回收兜底，不决定伤害窗口。源prefab和第三方脚本保持原样。

**2026-10-09原生表现复核**：原包粒子使用Shape模式；Flash、CrackedGround等节点的极小transform缩放只用于发射形状，不能当作粒径倍率。上一版强改Hierarchy使闪光、碎屑和裂纹被再次缩小，现保留源模式并独立按实例根的最终统一缩放调整粒径、空间速度、重力和雷光宽度；不修改simulationSpeed、粒子寿命、原发射率或时间曲线。对照原始预制体在0.04/0.12/0.3/0.7秒的画面，确认根部闪光、飞溅粒子和地面碎屑/熔岩裂纹恢复。普通闪电瞬时雷光的短促节奏来自原资源自身。

普通命中按玩家体量缩小，灯光范围随实例缩放，并沿用源衰减速度，避免把周围场景持续照白。Slash原脚本会拉伸整个根节点，现只伸展独立的斩痕网格，最长约3米，粒子保持原有比例；装饰碎片的碰撞体关闭，避免影响角色移动。当前目录缩放：Slash_Normal/Slash_Fire为0.12，ThunderHit为0.3，Impact_Spark为0.2，Break_Lava为0.05（源根缩放15），前三式雷主体为1.5，EpicZeus为2.5；调用方仍可按体型或范围乘倍率。

2026-10-09可见度调整：玄霄四式主体和ThunderHit统一放大至上一版的2.5倍，重建目录也保留这些数值。沿用适配器同步缩放粒径、碎屑、闪光与嵌套子特效；模拟速度、寿命、攻击节点、伤害/体素范围均不变，EpicZeus的装饰雷击散布仍限制在原5米圆盘内。共享Resources目录覆盖各玩家场景。

现有三个近战方法的锁定命中与Alt方向挥砍、太虚炼气诀锁定/环境命中，以及玄霄主体/闪电链都经过该入口。青山剑、NPC和未指定的其他神通仍保留既有特效，不根据伤害属性自动替换成新资源。

## 3. 玄霄四式

`BasicThunder01`按A1→A2→A3→A4→A1循环。前三式单体攻击后沿用概率闪电链；第四式范围内逐个结算特殊普通攻击，一个NPC有多个碰撞体也只打一次，已锁定目标无视好感度，其余仅打敌对单位。第四式不额外发起闪电链，避免群攻中重复蔓延结算；EpicZeus的随机雷击装饰限制在同一个5米圆盘内。神识内Alt/F鼠标落点瞄准也可触发对应当前式。

共用伤害倍率与原基础冷却保留，攻速缩放动作与冷却。本次40%/40%/43%/50%出手节点及5米范围为初版，可在组件调整；A3、A4不借用水龙炮/追踪弹的施法停顿。出手时记住目标和片段，切目标不会把当前动作的伤害移到另一个敌人；被其他动作中断时取消未出手的攻击。

派生动作放在 `Assets/resources/技能动作/玄霄雷诀/A2.anim`、`A3.anim`、`A4.anim`，A1直接复用已修复的 `普攻_远程_01.anim`。菜单 **修仙 / 动画 / 重建玄霄雷诀四式（不动场景）** 使用 `ThunderComboBaker`，保留源FBX和派生资产GUID。A2以Unity人形镜像状态烘焙，根曲线显式左右反射，并保留A1根运动提取设置，避免额外转体；A3/A4沿用0.946根高度基准。所有手腕和手指曲线保留源动作并限制异常外翻，不使用待机固定手姿。

## 4. 焚天落地

焚天先播放`技能动作2`，在实际动作进度38%才召唤火球并创建AreaSkillRunner；节点前没有该范围特效或伤害执行体。按动画归一化进度判断，暂停/播放速度变化不会提前召唤。全段动作占用施法，收招结束释放；38%前被打断、玩家死亡、锁定目标死亡或施放器禁用时取消待召唤。Alt手动落点也走同一节点。伤害表中的0.75秒首次伤害延迟、3秒窗口从召唤时刻起算，沿用原数值。

节点实机检查`.dsh/_diag/fentian-timing.cs.txt`覆盖原速/0.5倍/1.8倍播放、暂停、38%前打断、施放器禁用和Alt落点；检查实际召唤进度、起手无伤害、落地熔岩、两层爆炸移除和收招占用释放。

按用户要求，焚天施放实例中的`Effect_13_Explosion`、`Effect_13_Explosion_2`层及其子发射器引用已移除；扭曲、火球、尾烟和独立Break_Lava落地保留。该处理在共享施放器的焚天分支完成。

焚天落地的大片红色闪光来自Break_Lava自身的橙红点光源：源强度16、半径15米，适配后的范围还会跟随视觉缩放。每颗火球都会生成独立`CombatVfx_meteor_ground`，只隐藏火球主体不会停止这些新实例。现保留弱局部照明：目录`灯光强度倍率=0.04`、`灯光最大半径=1.5米`，峰值强度0.64；衰减速度同比降低，保持原约0.23秒渐暗时间，范围上限在缩放后按世界单位限制。参数传给动态子特效；火焰自身发光、熔岩、火星、烟雾及伤害/破坏不变，其他特效默认强度倍率1、不限制半径。目录还可显式关闭场景灯光，但焚天当前保留上述弱光。

真实施放验证23次落地及23组并存熔岩：连续灯光采样均不超过1.5米/0.64，仍有非零局部照明和活跃粒子；玄霄灯光和第三方源预制体未被改变。EpicZeus散布另以世界半径及调用方范围倍率计算，避免雷主体视觉放大2.5倍时连带扩大装饰雷击的落点范围。

`ActiveSkillCaster`仅对焚天实例的 `Effect_13_Shell` 添加 `MeteorGroundImpact`，保留源lifetimeLoss/bounce/dampen/killSpeed及扭曲、尾烟子发射器。启用体素地图时，关闭特效自带的不可见碰撞地板，使用真实静态表面碰撞，火球可落在坡面和已挖出的坑底。过滤角色与过陡墙面，每个落地点单独播放熔岩并排队局部椭球切削，水平半径为表中范围的1/12（默认1米），垂直深度再乘1/3（默认约0.333米）。AreaSkillRunner不再对焚天挖中心大坑，只保留原敌人持续伤害；熔岩和落地回调不增加第二份敌人伤害。

`.dsh/_diag/fentian-voxel.cs.txt`在真实宗门野外检查首次范围伤害不挖坑、每颗火球只排队一次、落地熔岩与破坏点一致、1米半径、实际坡面高度、已有坑底再次落地及环境还原。检查多个分散落点和更新期间地面射线连续性；不修改源场景或TerrainData。

地形显示时序由共享体素调度负责：单次接触的关联地块准备好即提交，不再等所有火球或其他攻击结束。当前焚天首次落地至首坑显示约0.30秒，发生在火球继续发射期间；保留原地面至新网格/碰撞就绪，无先开孔后补面的空洞。跨技能时序与验证见[正式地图体素试点§4.2](正式地图体素试点.md#42-首次接触与连续攻击提交2026-10-09)。

## 5. 验证

原生表现复核脚本 `.dsh/_diag/extreme-native-timeline.cs.txt` 对照源预制体与接入实例的四个时刻，检查玄霄主体和焚天落地的可见闪光/飞溅/裂纹。`.dsh/_diag/extreme-native-ownership-check.cs.txt`实际移动父雷光，确认已发出的子雷光不被再次带动，并检查原Shape/simulationSpeed和最终回收；本次修正后再次通过67项战斗回归，运行日志无错误。

临时实机脚本 `.dsh/_diag/extreme-pipeline-runtime.cs.txt` 使用真实玩家与共享施放器：四式及循环回A1、动画节点、统一ThunderHit、第四式群攻/重复碰撞体去重/友方与范围外过滤、Alt落点、真实焚天逐颗落地、三种近战与太虚炼气诀的命中映射，以及所有嵌套特效的最终回收。

最终实机回归67项通过，完整日志无运行错误；包含下一式引导半径及装饰碎片不阻挡角色。镜像检查 `.dsh/_diag/thunder-pose-check.cs.txt`在玩家骨架采样61帧，镜像后的臂/手/足位置相对几何镜像最大差约0.015米（模型原始缩放），保留模型左右骨架的细小差别。`.dsh/_diag/thunder-hands-check.cs.txt`验证A3/A4双手手腕和30根手指骨都实际绑定且与源姿势一致：A3有32根运动，A4有12根运动，另外20根保留源动作静态手势。视觉预览为 `.dsh/_diag/extreme-fx-preview.cs.txt`。这些脚本、报告和截图不入库。

所有游玩场景通过共享代码/Resources读取同一配置和动作，无需分别复制特效或保存场景。只读预览检查了构建列表中的六个玩家场景，确认共享施放器、播放器、有效玩家Avatar及九项特效/三段派生动作均可读取；检查后编辑器原场景不变。
