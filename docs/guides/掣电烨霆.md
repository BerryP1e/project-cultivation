# 掣电烨霆：鬼火随行与即时续吐

2026-10-14：日常实体龙取消，改为玩家身侧的幽蓝鬼火。保留一份预热后停用的模型，施放时粒子从鬼火炸开，优先凝成头颈胸翼，再完整生成后肢和尾巴；显现与快速前摇同步。单次喷射延长到 **1.725秒**。追击按键立刻恢复速度、撤去暗幕并进入 **0.24秒**短蓄力，上一段外焰和雷雾还未消散时下一喷接上。当前预算不再排队。

## 装备与入口

支持1～6技能键、锁定目标与现有Alt手动落点。玩家以玄霄雷诀A3持续引导，阻止普攻与其他主动动作，保留走路或御风的底层动作。一次首发只消耗24灵气；每次实际接受的续吐再消耗24，失败按键不扣费。

## 日常与凝形

根部缩放2.5，沿用身侧参考 `(4.050743, 0.03000614, -0.6459469)`，保留显示节点位置与2.819921缩放。鬼火位置有0.45秒尺度的平滑滞后，再自行向身侧靠近；无日常行走、扑翼、起飞、降落等待。

预热的一份模型停用GameObject与PlayableGraph，不逐帧采样骨架、不渲染蒙皮。模型、纹理、动作、材质直接复用，避免按键时重复加载和实例化巨龙。隐形实体不做另一套AI；只维护鬼火的位置参考。

首发立即取玩家实际御风/升空状态选择地面或空中吐息；起落中也可出手，不等待旧动作结束。凝形粒子最多768颗，优先汇向头颈与胸翼，再完成后肢和整条尾巴，目标随攻击动作更新。显现约0.6秒，与0.58秒前摇同步。专用 `CheDianManifest` Shader 使用骨骼加权的顶点红通道排序并以噪声蚀边，尾尖晚于上半身出现；不按空间位置切掉弯回前方的尾尖。所有顶点alpha均为255，最终是完整龙。现有网格增加约26KB颜色数据，不在运行时复制网格。

最后一喷结束、或玩家放弃续喷窗口后，立即从尾部和后肢向胸颈、龙头逐渐粒化，约1.6秒汇回鬼火。0.7秒收势与回收同时推进，不先站着等待。粒子按消融部位错时启动并同步加快；回收后模型和播放图再次停用。攻击时龙保留出手位置，回收粒子追随当前鬼火位置。

## 玩家引导动作

A3实测时长1.6秒：0.32～0.64秒举手保持，0.64～1.08秒出现明显后顿，1.12秒后开始收手。首发把举手过程对齐龙的前摇；持续喷射及选择窗口保留0.60秒附近的呼吸变化，每次实际喷射重新播放0.64～1.00秒的后顿，再混回举手段，避开收手尾段。

`CheDianPlayerChannel` 只创建无网格、无脚本的取样骨架。左肩臂腕指完整取A3，脊柱/胸部约68%、头颈55%、髋25%，走路时躯干权重降至原来的80%；腿脚继续走原走路/御风动画。上半身根据双肩方向朝向当前喷射目标，左臂进一步校正三维指向；角色转身移动时仍保持瞄准。引导结束0.65秒平滑退出；闲置时取样骨架及图停用，卸装销毁。

引导开始立即取消未出手普攻与旧Action，占用既有施法锁。远程及近战旧判定均被取消；其他主动技能、闪避和行游动作不能覆盖引导。当前星位的续喷按键仍可穿过锁，且不再次消费冷却储备。暂停与全局慢放同步推进玩家、龙和取样时钟。介绍页复用相同取样逻辑但无真实施法锁或伤害。

## 储备与严格输入

冷却最多储备4段，每10个游戏秒回复1段。首次接受施放时，将当前已储备段数锁定为本轮预算，同时把冷却储备清零并重启10秒计时。本轮第1喷立即消耗一个预算，最多留下3次即时追击机会。随后冷却积攒的新段数不能加入已开始的这一轮。

- 前摇、喷射、短蓄力与收势期间的额外按键直接拒绝；没有请求队列、自动续吐或等待起落的延迟请求。
- 喷射末尾在现有光束尚未消融时，若本轮仍有预算且灵气足够，开启约1.3秒真实时间的选择窗口；包括玩家、龙和场景在内统一降到18%速度。
- 窗口内再按一次，立即消耗本轮预算、撤去暗幕、恢复原时间倍率并进入0.24秒再次发力；无需等窗口走完，也不先播放1秒后摇。旧外焰继续保留，新喷射直接续接。
- 不按则自然结束，本轮未用预算全部作废。即使还剩3段，也不会返还或后来自动喷出。
- 移动技能星位保留当前冷却储备和计时；卸装再装备也不会凭空补满4段。一次窗口确认后的同帧重复调用会因已经进入短蓄力而拒绝。
- 暂停保留窗口剩余真实时间并拒绝输入；卸装/死亡取消全部预算、效果与焦点时钟，恢复界面后不会遗留18%慢放。

对应HUD星位会高亮，龙身侧额外出现 **仅一个已装载的临时三维星位**。仪轨210°/秒与165°/秒反向旋转并轻微缩放；世界压暗、龙周身与提示位置保留柔边聚光，镜头轻推向龙头、视野缩小约10%。确认时暗幕立即消退，镜头平滑返回，不改玩家的滚轮缩放参数。
