## 3. 丹方怎么定义

丹方就是 `灵丹定义` 上**多填了几个字段**（`主材id` 非空即视为可炼）。一套数据两用：
`灵丹库` 里那 9 颗**破境丹**同时是丹方，也同时是破境时消耗的道具。

| 字段 | 作用 |
|---|---|
| `主材id` + `主材数量` | **一味主材**。留空 = 不可炼制 |
| `辅材` | **多味辅材**，格式 `物品id:数量\|物品id:数量` |
| `灵气消耗` | 基础灵气消耗（走 `PlayerVitals.当前灵气`） |
| `一品成功率` | **一品**的成功率（这是最高成功率） |
| `品阶衰减` | 每往上开一品，成功率 × 这个系数 |
| `品阶加耗` | 每往上开一品，灵气消耗 × 这个系数 |
| `最高可炼品` | 这个丹方最多炼到几品 |
| `产量下限` / `产量上限` | 炼成后产出几个 |

### 品质是怎么算的

**品是玩家主动选的**，不是随机出来的：

```
第 N 品成功率   = 一品成功率 × 品阶衰减^(N-1)
第 N 品灵气消耗 = 灵气消耗   × 品阶加耗^(N-1)
```

> 【为什么"品"是**选**而不是**掷**】需求说"品质越高成功率越低" ——
> 这句话只有在**玩家主动选品**时才成立（否则就是"随机给品质"，
> 那"成功率低"就没有对应的取舍了）。选品 = 主动赌高收益，这才是有决策的玩法。

**实测（炼气破境丹，`一品成功率=0.85` / `品阶衰减=0.82` / `品阶加耗=1.35`）**：

| | 1 品 | 9 品 |
|---|---|---|
| 成功率 | **85%** | **17%** |
| 灵气消耗 | **20** | **221** |

**高品 = 更难 + 更贵**，且这两个值都由上面三个系数推出来，不用手填 9 组数。

## 4. 炼制流程与代价

`炼丹炉.炼制(丹方id, 品)`：

1. `能炼()` 校验：丹方合法 → 品在范围内 → **材料够** → **灵气够**
   （任一条不过就**不受理**，什么也不扣，并给出人话原因）
2. **扣材料 + 扣灵气**（不论成败）
3. `Random.value < 成功率` 判定
4. 成功 → 产出进背包（走 `UIPanelData.给物品`，和任务奖励同一条入口）

> **失败也扣材料与灵气** —— 这是"炼丹是主动玩法、消耗资源"的定位。
> 界面上会明确写"材料与灵气已耗去"，不做静默。

### 界面布局

```
┌────────────────────────────────────────────┐
│ 丹房 · 炼丹         灵气 150/150  加成 +10% │
├──────────────┬─────────────────────────────┤
│ 丹方          │ 炼气破境丹                  │
│ [炼气破境丹]  │ 【材料】生灵草 ×3（有 12）   │
│ [筑基破境丹]  │ 　　　　凝露花 ×2（有 5）    │
│              │ 【1 品】成功率 85% 耗灵气 20 │
│              │ 品 [1][2][3]…[9]（各带成功率）│
│              │        [ 炼　制 ]            │
└──────────────┴─────────────────────────────┘
```

**品按钮上直接印成功率** —— 一眼看出"高品更难"，不用点进去看。

## 5. 被动技能加成（接口已留）

需求：做几个被动技能 `xx炼丹术` 提升 xx 品丹方成功率；另做几个减少炼丹的灵气消耗。

`炼丹炉` 上已有两个公开字段，**等着被被动技能灌进来**：

| 字段 | 作用 |
|---|---|
| `成功率加成` | **加法**加成（0.1 = 各品成功率 +10%），上限 95% |
| `耗气减免` | 灵气消耗减免（0.2 = 少花 20%） |

**还没做**：真正把这些被动技能做成可学会的条目并接到这两个字段上。

## 6. 加一个新丹方 / 新丹药（操作步骤）

1. 在 `Assets/Data/Tables/物品表.csv` 加**产物**那一行（`物品id` 必须与丹方 id 一致）；
   需要的话再加**主材 / 辅材**的物品行。
2. 在 `Assets/Scripts/Data/灵丹定义.cs` 的 `灵丹库.确保()` 里加一条 `灵丹定义`，
   填上主材/辅材/灵气/成功率系数/产量。
3. 跑菜单 **「修仙/从配置表生成资产」**（否则产物 id 在物品库里不存在，收成会丢）。
4. 进游戏点**炼丹阁**验证：材料不足时它应给出**具体缺哪一味**，而不是静默失败。

> ⚠️ 加完记得**跑一次场景一致性体检**（见 [ai/踩坑总库](../ai/踩坑总库.md)）。
> ⚠️ 改 CSV 用 Excel 会**丢 UTF-8 BOM**，见 [踩坑总库 §F7](../ai/踩坑总库.md)。
