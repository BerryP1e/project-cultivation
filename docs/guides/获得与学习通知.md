# 获得与学习成功通知

按用户提供的黑幕通知参考实现，上方居中，基准为屏幕高度80%处。文字浅白，无物品图标；宽度随真实文字长度变化，两侧各64单位淡化，文字左右各留16单位纯黑余量。长文字在屏幕宽度90%内换行，增加高度，不能伸进两侧渐隐区域。

UIRewardNotice 独立 Overlay 画布，sortingOrder 5001，不带射线接收器，CanvasGroup 不拦截指针。用非缩放时间，背包暂停时照常推进。

新通知从当前队列底部下方上移淡入，0.20秒达到位置并成形。旧通知在这0.20秒内以 SmoothStep 平滑上移，压紧时边缘间隔8单位；随后0.14秒平滑展开为16单位。不瞬移重新排队，同时来的多条也保留起始间隔。文本行高参与位置计算，长通知不与相邻文字重叠。

同一批通知按最后一条到来时间共同计时：1.5秒开始淡出，1.7秒整批消失。新一条到来时对已存在通知从当前坐标和透明度重新缓动，避免中途弹跳或突然闪亮。这是“统一消失时间”的当前实现。

接入路径：

- UIPanelData.给物品 → ToastUI.获得物品 → UIRewardNotice，按实际发放名称与数量显示。
- LawFragmentSystem.获得 → ToastUI.获得法则 → 同一通知样式。
- 物品使用器：功法、主动神通、被动神通、坐骑、丹方、外观的学习/解锁成功后显示实际内容名称。失败或重复学习不弹成功通知，扣除仍沿用原流程。

2026-10-21追加：ToastUI.提示 也统一转入此通知，包括法则装备、卸下、槽位已满、保存及普通操作提醒；不再生成右上角旧墨刷提示。提示文字仍表达原始成功/失败含义，不能把错误改写成获得成功。全部使用同一1.5/1.7秒时钟，不额外发放奖励、不改存档格式。入场有独立限步时钟，触发帧保持透明且在目标下方，后续每帧最多推进0.04秒，避免资源加载长帧跳过淡入滑入；生命周期仍按真实非缩放时间统一结束。
