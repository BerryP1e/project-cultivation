# 特效资源清单

> **管什么**：`Assets/resources/特效/` 下**全部特效 prefab** 的路径、规模与特征，按分类分节，供挑特效 / 填路径用。
> **不管什么**：目录约定、怎么加载、导入新包怎么整理 → [特效系统](特效系统.md)；某个特效怎么配到怪身上 → [飞弹与子弹](飞弹与子弹.md)。
> **本文件怎么查**：先看「汇总」定位分类，再进对应小节按名字搜；每节开头有「统一前缀」，表里 `路径` = 前缀 + 表中值。
> **来源**：由 `NpcEffectInventory` **自动生成**（菜单 **修仙 / 资源整理 / 生成特效资源清单（全部）**）。**改完资源重跑菜单，不要手改本文件。**

扫描根目录：`Assets/resources/特效`　共 **467** 个 prefab。
>
> **路径怎么读**：每个小节开头写了该节的「统一前缀」，表里 `路径` = **前缀 + 表中值**，
> 拼起来就是能直接填进 `NpcAttackConfig.子弹特效路径` / `NpcAttackConfig.命中特效路径` 的 Resources 路径
> （相对 `Assets/resources`、**不带扩展名**）。**每行路径的最后一段就是资产名。**
>
> **列义**
> - `粒子` = 粒子系统个数（含子物体）
> - `外径` = 散布半径 × 2 + 最大粒子尺寸（粗估，用来判断「要不要缩放」，不是精确包围盒）
> - `特征` = **建议档位** + 标记。档位：`1` 飞行道具（适合当子弹）· `2` 单次爆发（适合当命中 / 爆炸）·
>   `3` 循环效果（拖尾 / 常驻）· `8` 其他 · `9` 空壳（没粒子也没脚本）· `0` 读不出来。
>   标记：`循环` = 有粒子勾了 loop，`动` = 有粒子带速度或挂了脚本（脚本名最多列 3 个，更多就写 `多脚本`）
>
> ⚠️ **`特征` 里的建议档位是按「粒子数 / 循环 / 会不会自己移动」猜的**：
> 对 `特效/飞弹` 这种「一个主题 = 一份单体飞弹」的包准；
> 对 `特效/法术`（一套法术 = 主 prefab + 一堆 Parts/Base 子件）**不准**
> （实测 312 个里 171 个被误判成「飞行道具」）。看那个包时只看路径和外径。
>
> 目录约定、怎么加载、怎么导入新包 → [特效系统](特效系统.md)。
