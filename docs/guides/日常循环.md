# 时间与日常清单

当前保留四项完成记录：收灵草、成功炼丹、打坐、进入镇妖阁。没有常驻“今日”面板，不恢复旧剧情伏笔、异象、巡览门槛或任务阶段。时间规则见[时间系统](时间系统.md)。

| 清单项 | 完成来源 |
| --- | --- |
| 收灵草 | 灵田.收获事件 |
| 炼丹 | 炼丹炉.炼制完成且结果成功；失败不计 |
| 打坐 | 时间管理器.今日次数>0 |
| 入塔 | 当前场景为Demon-Suppressing Tower |

日常循环组件对灵田/炉实例变化补订阅，切场景后不能只依赖Start订阅。跨天通过当前游戏天数比较，不仅订过了一天事件，保证读档也能正确刷新。每日记录保存游戏天数与四位掩码，同一天读档保留完成状态。

SaveSystem先挂起待读取的天数/掩码，日常组件就绪后领取；主线管理器已移除，不再负责开关或恢复。游戏时钟默认现实600秒为一天，不算退出游戏后的离线时间，暂停时不推进。生产、机会和日常各用同一游戏日体系。

维护入口：Core/日常循环.cs、Time/时间管理器.cs及SaveSystem日常挂起/领取接口。验证同日恢复、跨天刷新、切场景重订阅、失败炼丹不计与暂停。旧四阶段主线和两个伏笔已删，不列作待开发事项。
