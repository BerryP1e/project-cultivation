# 直接运行场景的测试背包

更新：2026-10-22。仅在编辑器直接启动3C_Testbed，且没有正式SaveSession、没有QA隔离目录覆盖时启用DirectSceneTestInventory。正式主菜单新建/读档、其他场景、自动QA与构建版本不赠送全目录物品。

从当前有效ItemDefinition目录按物品id去重，每种放一件；后续新增定义自动加入。法则只通过九境界宝箱测试，清除随机法则碎片、炉中实例及装备槽，不直接赠送碎片。武器测试同时填入当前WeaponCatalog的已拥有武器，方便装备页测试；正式角色仍须使用获得物品取得武器。

测试模式写Library/DirectSceneTest/saves，不写Application.persistentDataPath正式角色目录；返回StartScene退出该模式。启动时必须先确认是否已有QA覆盖，不能把QA数据再视为“正式场景直接测试”。旧验收中的125种是当时目录计数，不是应硬编码的数量。

维护入口为Assets/Scripts/Debug/DirectSceneTestInventory.cs、WeaponCatalog及SaveSystem测试目录选择。检查应按当前目录集合逐个比对、排除正式/QA流程、核对正式存档指纹，不依赖固定旧物品数量。
