# 防护罩

> **管什么**：四种护罩、属性减伤、棱柱次数和持久化。
> **不管什么**：基础公式见 [战斗与伤害](../architecture/战斗与伤害.md)；保存入口见 [存档系统](../design/存档系统.md)。
> **本文件怎么查**：1 四种护罩｜2 受击入口｜3 次数持久化｜4 特效与验证。
> **来源**：用户要求 GloryShield 文件夹四套作为不同被动，去除受弹演示；物理/特殊减伤和四棱柱绝对免伤为用户要求，第四种双减伤及百分比为暂定方案。

## 1. 四种护罩

| 神通id / 名称 | 原特效 | 初版作用 |
|---|---|---|
| ability_huzhao_wuli / 玄甲 | HoloShield | 物理伤害减25% |
| ability_huzhao_teshu / 灵光 | HolyShield | 特殊伤害减25% |
| ability_huzhao_shuangchong / 两仪 | InfernoShield | 物理与特殊均减15%（第四种暂定） |
| ability_huzhao_juedui / 四御 | GloryShield | 四次完整免伤，每次少一棱柱 |

均为被动，学会后启用，无持续耗蓝。学习物品id为 `item_` 加表中神通id。减伤比例在被动神通表，非正式平衡值。

## 2. 受击入口

`PlayerVitals.受到伤害(amount, DamageNature)` 在无敌/死亡/零伤害过滤之后调用 `PassiveShieldAbilities.过滤伤害`。NPC攻击与 `PlayerTarget` 保留 AttackSpec 的物理/特殊分类，旧单参数调用默认为物理。

绝对护罩优先消耗一棱柱并免除整次伤害。没有棱柱时再计算属性护罩；多个有效减伤相乘，例如玄甲＋两仪使100物理伤害变为63.75。未命中、零伤害、无敌期间不消耗棱柱。

## 3. 次数持久化

`UIPanelData.绝对护罩剩余次数` 初始4，每次有效攻击减1。停用重开不回满；跨场景快照和 SaveData 均保存次数。第五次开始正常受伤（仍可由其他护罩减伤）。旧档缺字段时按4初始化。

**初版没有自动充能规则**；恢复条件待玩法确认，不能擅自把每次启用都当成重新充能。持久化避免通过传送、读档或开关技能凭空恢复次数。

## 4. 特效与验证

游戏资源 `Assets/resources/Abilities/{PhysicalShield,SpecialShield,DualShield,AbsoluteShield}.prefab`，移除 IncludeHit 内 MultipleShot 与弹道演示，保持罩体动画和四枚独立Crystal粒子。按实际身高缩放，并把罩体中心对齐角色身体，避免只覆盖下半身。

Play验证物理/特殊各自减伤、双减伤、4→3→2→1→0棱柱、第五次扣血、无敌不扣、停用不重置及保存恢复。八种神通初版共通过83项隔离Play检查。截图 `cultivation/screenshots/eight-abilities-preview-1920x1080.png` 和 `cultivation/screenshots/eight-abilities-preview-1280x720.png` 为隔离预览，不等同于完整跨场景操作录屏。
