# 防护罩

> **管什么**：四种护罩、属性减伤、棱柱次数和持久化。
> **不管什么**：基础公式见 [战斗与伤害](../architecture/战斗与伤害.md)；保存入口见 [存档系统](../design/存档系统.md)。
> **本文件怎么查**：1 四种护罩｜2 受击入口｜3 次数持久化｜4 特效与验证。
> **来源**：用户指定四套GloryShield；最新规则为三种减伤被动互斥且维持耗蓝，四御改主动、每次施放补满四次免伤。消耗、冷却和百分比为暂定平衡数值。

## 1. 四种护罩

| 神通id / 名称 | 原特效 | 初版作用 |
|---|---|---|
| ability_huzhao_wuli / 玄甲 | HoloShield | 物理伤害减25% |
| ability_huzhao_teshu / 灵光 | HolyShield | 特殊伤害减25% |
| ability_huzhao_shuangchong / 两仪 | InfernoShield | 物理与特殊均减15%（第四种暂定） |
| ability_huzhao_juedui / 四御 | GloryShield | 主动施放恢复四次完整免伤，每次少一棱柱 |

玄甲、灵光、两仪为被动，同一时间只允许启用一个；获得、UI开关和直接设置都自动关闭其他减伤护罩，旧档曾同时开启多个时保留一个。每秒消耗2灵气，蓝不足扣到零并自动停用；蓝为零时即使尚未执行Update也不能减伤。灵气恢复后需要手动重开。减伤比例和维持消耗在被动神通表。

四御为主动神通，占主动槽，初版消耗20灵气、冷却12秒，无需锁定，每次成功施放恢复4次免伤。可与一个减伤被动共存，无持续耗蓝。学习物品id仍为 `item_ability_huzhao_juedui`，效果已改学主动神通，沿用原图标。

## 2. 受击入口

`PlayerVitals.受到伤害(amount, DamageNature)` 在无敌/死亡/零伤害过滤之后调用 `PassiveShieldAbilities.过滤伤害`。NPC攻击与 `PlayerTarget` 保留 AttackSpec 的物理/特殊分类，旧单参数调用默认为物理。

已激活的四御优先消耗一棱柱并免除整次伤害。没有棱柱时再计算唯一启用的属性护罩，例如玄甲使100物理伤害变为75。未命中、零伤害、无敌期间不消耗棱柱。

## 3. 次数持久化

`UIPanelData.四御已激活` 与 `绝对护罩剩余次数` 初始false/0；成功施放后true/4，每次有效攻击减1，耗尽时取消激活状态。装载器即使没有已学减伤被动，也会保留正在生效的四御组件。第五次开始正常受伤（仍可由唯一开启的减伤护罩减伤）。

SaveData v16与跨场景快照保存激活状态及剩余次数，读档、传送和装载器刷新不会回满。旧档/旧场景中学过的被动四御按稳定id迁移为已学主动四御，但旧初始4次不能自动变成已激活的主动免伤。旧被动资产保留用于旧场景引用迁移，面板目录排除同id被动版本，只显示主动四御。

## 4. 特效与验证

游戏资源 `Assets/resources/Abilities/{PhysicalShield,SpecialShield,DualShield,AbsoluteShield}.prefab`，移除 IncludeHit 内 MultipleShot 与弹道演示，保持罩体动画和四枚独立Crystal粒子。

罩体使用玩家根节点胶囊碰撞体的固定身高与中心，尺寸取碰撞体身高的1.35倍，位置与缩放固定在角色根空间。无胶囊的对象仅在首次初始化时采样身体边界。不要逐帧按蒙皮 `Renderer.bounds` 重算，迈步和转身会改变包围盒，导致护罩忽大忽小、中心跳动；开关被动也不重新采样。

最新隔离Play共36项检查：护罩互斥、持续耗蓝/耗尽关闭、三种属性过滤、主动四御消耗与冷却、4→0免伤与冷却完成后再次施放恢复、无敌不扣、v16保存/旧档学习迁移、学习玉简、邪眼每轮扣蓝，以及真实跨场景快照保留剩余2次。没有切换用户正在测试的场景。
