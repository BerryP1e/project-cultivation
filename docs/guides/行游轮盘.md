# 行游轮盘

2026-10-14：御风与坐骑改用 Tab 轮盘，同时准备、运行时互斥。

按住 Tab 在鼠标附近打开十二扇区轮盘，移向左上「凭虚御风」或右上「坐骑」，松开执行。十个空位保留后续用途；中央、扇区间隙、空位松开均取消。重复选择当前状态会落地或下坐骑。Shift 保留地面奔跑，不再切换行游。

选中位置平滑放大到 1.055 倍，水墨形变由既有 UIInkFluid 驱动并裁切在扇区内部。轮盘贴近屏幕边缘时自动收进可见区域；打开时锁定场景操作，世界继续运行。Esc、失去焦点、死亡或玩家停用均取消并释放输入锁。

御风与坐骑允许同时准备。选坐骑先完整播放御风落地，再启动原坐骑出生/骑乘流程；选御风先完成坐骑消融/下坐骑，再升空。过渡、出招、施法和闪避期间不接受第二次切换。检查已学神通、灵力、坐骑修炼门槛和模型资源；明确选择已学御风可重新启用该被动，不撤掉准备坐骑。学习后动态添加的御风会重新绑定移动、动画和坐骑引用。

准备状态继续使用当前坐骑、已学被动及已停用被动字段，不新增存档版本。验证通过内存 JSON 往返检查两项同时保存和恢复，不写玩家存档。

入口：PlayerController.Awake 自动补 PlayerTraversalController 与 PlayerTraversalWheel，场景无需重写。UITraversalSector 绘制真实环形扇区；PlayerTraversalController 协调 YufengFlight、MountRider 的原生流程。UiEscRegistry.SceneInputBlockedByOthers 仅排除轮盘自身输入锁，不绕过其他界面。

验证：devtools/validation/traversal-wheel-runtime.cs.txt 在独立 Play 完成 333 项检查，覆盖十二扇区、释放时执行、取消/失焦、真实御风与碧水兽双向过渡、保存恢复和后学御风实际升空；运行日志零错误。截图和报告归 .local/diagnostics/traversal-wheel，不保存场景。
