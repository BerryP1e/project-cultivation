## 1. 效果与参数

**用户要求**：以鼠标落点为方向，释放一道**连续向前的冰柱**（特效 `frost-wave`），对路径上的敌人造成特殊 + 主动神通伤害；随后这些敌人脚下出现 `frost-ring` 造成第二次伤害，`frost-ring` 特效结束后脚下再出现 `frost-spike` 造成第三段伤害；二段和三段都是特殊 + 主动神通伤害。

- **更正 ①**：施法动作是太虚练气决的那个普攻动作，也是在**动画的 40% 节点**开始生成特效。
- **更正 ②**：不是生成很多个 `frost-wave` —— `frost-wave` 本身就是一道连续向前的冰柱；要的是它**一段在玩家这里（起始那边）**、一段朝向应该朝向的方向。

```text
普攻动作 普攻_远程_01（1.2s，和太虚炼气诀的普攻同一个片段）
  ↓ 播到 **40% 节点**
放**一根** frost-wave：**近端在玩家脚下**、柱身沿鼠标方向伸出去（自然长 11.5m）
  ↓ 伤害从玩家往前方扫（扫到谁打谁）
【一段】特殊 + 主动神通          （倍率 ×1.8）
  ↓ 这些敌人各自记账，0.6s 后
【二段】脚下 frost-ring  + 伤害   （按敌人体型缩放）
  ↓ 再过 1.5s（可配；填 0 = 自动取 frost-ring 自然时长，最多 3s）
【三段】脚下 frost-spike + 伤害
```

### 2.1 出手跟着**普攻动作**的 40% 节点走

和「追踪弹」（瞬雷天闪/冰暴术）同一套口径：`Start()` 播 `普攻_远程_01`，`Update()` 里 `if (动画.动作进度 >= 出手进度) 出手();`（默认 0.4）。播不上动作（没有动画组件 / 找不到片段）就**立刻放冰柱**，免得变成哑炮。

### 2.2 ★ 冰柱是「一个特效」，要同时做两件事

别再一节节铺 `frost-wave` —— 这个 prefab 本身就是一根 **11.5 米长的连续冰柱**。实测（原样生成、跑 0.6s，读粒子世界包围盒）：

| 生成旋转 | 尺寸 X / Y / Z | 说明 |
|---|---|---|
| 不动 (0,0,0) | **11.49** / 8.31 / 2.30 | 长度沿**世界 X** → 长度轴 = **本地 +X** |
| 绕 X −90 | **11.74** / 4.34 / 9.36 | X 仍是长轴（绕 X 不影响 X） |
| 绕 Y 90 | 2.30 / 7.87 / **11.36** | 长轴跟着转到 Z ✓ 印证「长度轴 = 本地 +X」 |

粒子中心相对生成点只有 (−0.12, 0.69, −0.06) → **柱体是以生成点为中心的**。所以摆放要两件事一起做：

1. **旋转**：`Quaternion.LookRotation(方向) × Quaternion.Euler(0, −90, 0)` —— `LookRotation` 让本地 +Z 对准方向，再绕 Y 转 −90 把**本地 +X** 换到那个位置；
2. **位置**：`玩家 + 方向 × (柱长 ÷ 2)` —— 不挪的话玩家会站在柱子**中间**，而用户要的是「**一段在玩家这里**（起始那边）」。

柱长由 `冰柱基准长度`（默认 **11.5**，实测值）决定；换特效要重新量（原样生成 → 跑 0.5s → 读粒子的世界包围盒最长边）。

### 2.3 三段怎么排期

- **一段**：冰柱放出后，伤害**从玩家往前方扫**（`范围` 米），扫过谁打谁（按 `NpcInstance` 去重）。
- **二段**：被打中的敌人各记一条账，`伤害间隔` 秒后在**脚下**放 `frost-ring` 并结算。
- **三段**：二段之后再等 `三段延迟` 秒，在同一位置放 `frost-spike` 并结算。

`三段延迟` 填 **0 = 自动**：取 `frost-ring` 的自然时长，但**最多** `三段最长延迟`（默认 3s）—— 因为 `frost-ring` 粒子寿命带长尾（自然总时长 **10.1s**），真等它 10 秒连招就散了。

### 2.4 其它特效要点

| 要点 | 说明 |
|---|---|
| 二/三段落点 | **敌人脚下**（`npc.transform.position`），`对齐到锚点: false` |
| 二/三段缩放 | 按**敌人体型**：`敌人高度 ÷ 基准敌人高度`，夹 0.6~2.5（木桩 1.6m → 0.89） |
| 存活 | 一律 `特效摆放.量特效总时长() × 1.05`，**不写死**（写死就是硬切，见 [沧澜寒渊录](沧澜寒渊录.md)） |
| `调试方向` | runner 上的字段：非零 = **强制用这个方向**（不看鼠标）—— 自动化测试与截图摆拍用 |

## 3. 实测（3C_Testbed + 练功木桩）

```text
[寒墟] 播动作「普攻_远程_01」（1.2s），播到 40% 放冰柱
[寒墟] 出手（动作进度 0.403）：方向 (-0.75,0.00,0.67)，冰柱长 11.5m、近端在玩家脚下（生成点 (-3.46,0.02,1.01)）
[寒墟] 一段·冰柱扫到「练功木桩」 伤害 103.19（离玩家 5.2m）
[寒墟] 二段·冰环「练功木桩」 伤害 103.19（缩放 0.89）
[寒墟] 三段·冰刺「练功木桩」 伤害 103.19
[寒墟] 结束：一段 1 / 二段 1 / 三段 1，合计 309.58
[测试] 冰柱粒子=1541｜沿朝向投影：近端 -0.16m 远端 11.28m（柱长 11.44m）｜最大横向偏移 4.49m
```

| 检查项 | 结果 |
|---|---|
| 出手节点 | **0.403**（= 40% 口径）✓ |
| 柱体位置 | 近端 **−0.16m**（≈玩家脚下）、远端 **+11.28m**（沿朝向）✓ 柱长 11.44m ✓ |
| 三段都打到同一个敌人 | 1 / 1 / 1，合计 **309.58** ✓ |
| 伤害属性 | **会心**（= 特殊档的暴击类型）✓ |
| 二/三段缩放 | 0.89（= 1.6m ÷ 1.8m）✓ |

拍图：`cultivation/screenshots/寒墟冰柱.png`、`…/寒墟与冰暴术特效.png`（该目录已 gitignore）。

> ⚠️ **「最大横向偏移 4.49m」是特效自带的宽度**（冰柱不是一条直线，是宽 8m 多的冰浪），不是朝向错了。

## 4. 可以调 / 还没做

- **伤害扫描长度 vs 柱长**：扫描用表里「范围」（14m），柱体视觉长 **11.5m**。想让伤害和视觉严格对齐，就把「范围」填成 ≈11.5。
- **二/三段特效太大**：调 `基准敌人高度`（调大 → 缩放变小）或 `二段缩放`/`三段缩放`。
- **数值**全是占位（见 §1 表里的 ⚠️）。
- 「对路径上的敌人造成伤害」目前是**伤害随时间从玩家往前扫**（0.9s 扫完 14m），配合柱体自身的生长（`frost-wave` 的 duration 0.43s）观感是"冰柱窜出去"；要改成一次性结算就说。
