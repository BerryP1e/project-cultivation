# 镇妖阁法宝与塔内循环

更新：2026-10-16。用户界面称镇妖阁，原场景和塔控类型名继续保留 Tower，避免无意义重命名。

## 进入和退出

镇妖阁是 treasure_tower_realm 法宝，模型沿用原宗门镇妖阁建筑。新角色拥有并装备它。在洞府按 Q，记录实际家园位置和朝向后进入 Demon-Suppressing Tower。它使用独立法宝槽，不挤占神通栏。

塔内按 Q 退出，无须清怪、等待或继续装备该法宝。死亡也走同一退出路径，恢复为存活角色并回到实际施放点。旧的死亡十秒选择/返回上一层流程不再用于当前玩法；退出不传去已退役的 Sect。

塔内保存后从主菜单读档，返回点仍来自 SaveData.镇妖阁返回点。楼层记录使用当前选择的槽位；正常离场、死亡及切菜单不会默认改写槽位 0。没有记录返回点时才回洞府默认入口。

## 原塔控保留

TowerController、TowerProgress、TowerFloorTable、SpawnZone 与原 NPC 等级补正继续管理本层刷怪、清层、原有下一层入口和层数状态，不另写一套爬塔系统。怪物基础值仍来自 NPC 配置，等级/数量/强度按层表展开。

清层后的原生选择及刷新规则由现有塔控负责，Q 退出是额外的统一返回入口。塔内实际击杀、掉落、法则与经验使用原战斗链路；野外悬赏只统计野外本次妖群，塔内击杀不替代执事阁悬赏。

当前三表字段、生成规则和数值调整应以实际 Tower 配置及[配置表字段](../reference/配置表字段.md)为准。原倍率制作记录见[旧塔文档](../design/当前游戏体系.md)，其中宗门入口、死亡退层和旧场景接线已作废。

## 相关文件与验收

入口为 TowerRealmTreasure、TreasureCaster；塔内行为为 TowerController / TowerProgress；场景落点和首次读档为 SaveApplier。法宝在法宝表、PanelDatabase 和模型资源中登记。

home-tower-runtime 检查原生进出/清层；home-idle-integration 使用真实菜单读档、真实野外悬赏击杀、塔内保存、Q 退出与致死伤害返回。所有文件写隔离存档，不覆盖正式角色。规则总入口见[家园与镇妖阁](../design/家园与镇妖阁.md)。
