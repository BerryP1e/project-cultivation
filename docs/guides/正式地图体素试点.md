# 正式地图体素环境

> 当前覆盖整张宗门野外 Sect_Wilderness 的地面、94处岩石与1444个实体树干部件。其他地图和宗门建筑没有转换；源场景、prefab、TerrainData不落盘改写。独立样例见 [体素局部破坏原型](体素局部破坏原型.md)。

## 1. 操作

正常战斗已接入体素破坏。无锁定目标时：

| 操作 | 效果 |
|---|---|
| 按住 Alt | 默认显示当前功法普攻的鼠标引导 |
| Alt + F | 选择普攻；已启用的邪眼跟随同一落点，无独立快捷键 |
| Alt + 1～6 / 小键盘1～6 | 选择相应主动技能槽 |
| Alt + E | 选择青山剑的万剑归宗；仍需至少三剑 |
| 鼠标左键 | 确认施放；沿用动作节点、消耗、冷却与充能规则 |
| 松开 Alt / 右键 / Esc | 取消瞄准；右键或Esc取消后可重新按技能键选择 |

普通范围招式显示落点环，寒墟显示前进走廊，同时显示边缘缓慢波动的淡墨神识范围圈。普攻按鼠标方向出招，远处落点不会阻止挥砍，实际伤害仍限于武器接触或飞弹射程；邪眼独立攻击神识范围内的原始落点。主动技能和法宝超出可施放距离时引导变色，点击不扣资源或进冷却。角色死亡、演出、暂停、全屏面板、灵田摆放和鼠标压在UI上时不接收场景施放。已有锁定时沿用原战斗流程。Alt + F不会同时触发NPC或设施交互。

P面板「野外体素环境」仍保留调试工具：勾选「测试挖掘」后，Alt + 左键直接以0.45米半径挖掘，此时优先使用调试挖掘，不触发战斗。关闭此选项即可恢复技能瞄准。

焚天与巨剑的落点圈和实际体素破坏共用范围计算：焚天默认3米，三剑巨剑默认4米，巨剑圈随剑数和巨剑模型倍率调整。敌人伤害范围不随体素缩减而改变；邪眼缩小的是光束尺寸，神识圈仍显示原射程。巨剑落点超距提示使用法宝自身的神识范围。

- 「切回原模型」恢复原地面、模型、树冠、植被和碰撞；再次启用可继续查看本次破坏。
- 「还原环境」清除破坏与未回收断木，恢复本次运行的初始环境；已收进背包的灵木不回退。
- 永久关闭：取消 `Assets/resources/Voxel/MapPilots/Sect_Wilderness.asset` 的「启用试点」。菜单「修仙 / 体素 / 定位宗门野外试点配置」可定位。

不做破坏存档、旧档迁移或恢复。

## 2. 覆盖范围与树木

| 类型 | 当前处理 |
|---|---|
| 200×200米地面 | 保留原高度、坡度与四层地表混合；受击区补4米实体，底部保留0.35米承托 |
| 岩石 | 94实例、10套共享烘焙 |
| 树干 | 1444部件、7套共享烘焙；透明树冠沿用原素材 |
| 花草、灌木 | 不逐片体素化；地面锚点被挖掉时隐藏渲染和碰撞，支持还原 |
| 水面、角色、刷怪区、传送点、任务物件 | 保持既有逻辑 |
| 建筑 | 尚未转换；不能套用岩石圆滑处理，需另外设计硬边、梁柱与承重 |

1444是树干部件数，并非树木棵数。清单排除透明叶片、无网格旧组件、触发器与含交互逻辑的物件。

树干受损后分帧检查根部连通性，只移除原本有支撑、现在断开的部分。主要上部失去支撑时，将剩余断木网格与树冠组成一个刚体：先受重力、推力和扭矩倒下，约2.2秒后飞向玩家，约0.9秒后进入背包，每个倒下的树冠获得1份「灵木」。没有逐体素刚体。断木不与玩家碰撞；切回原模型时暂停断木，环境还原/离开场景取消未完成回收，不补发物品。

树冠源网格在编辑器清单中单独保存，避免运行时静态合批的合并网格被误复制成整片森林。「灵木」来自物品表，生成资产为 `Assets/Data/Generated/ItemDefinition/item_lingmu.asset`，获得时沿用物品提示。

## 3. 攻击与破坏时机

| 攻击 | 体素结算位置与范围 |
|---|---|
| 焚天炎术 | 首次伤害节点，体素破坏半径为表中范围的1/4，当前12米→3米；持续伤害不重复挖同一球，敌人伤害范围仍用原配置 |
| 雷动千闪 | 起点与实际闪烁落点，使用原范围伤害半径 |
| 冰暴术 / 瞬雷天闪 | 飞弹真正到达或撞上体素时；默认2.5米命中特效半径，跟随命中特效缩放，不把20米追踪距离当爆炸半径 |
| 寒墟 | 随推进扫描走廊，宽2.6米；每个扫描点半径1.3米 |
| 小剑阵 | 每把剑的真实落地位置；按帧间射线检测现有地面/体素，包含已挖出的坑底；半径按剑阵缩放约束在0.45～1.5米 |
| 邪眼 | 光束首先击中的体素；半径0.5米。无锁定时跟随普攻瞄准，仍检查被动启用、间隔和灵力。锁定与手动激光均缩至原尺寸1/5（0.12→0.024），射程不缩短 |
| 青山剑万剑归宗 | 首次接触时，以目标根节点或手动落点破坏；原半径乘2/3，默认6米→4米，随巨剑大小放大；巨剑继续贯穿与消散，敌人伤害范围不变 |
| 太虚炼气诀普攻 | 动画节点出弹，真实飞行到达/撞上体素时破坏0.6米半径 |
| 八九玄功 / 太虚剑决 / 灵虚剑决 | 近战普攻不再破坏体素，仅保留对生物的接触判定与伤害；跟随普攻触发的邪眼仍按被动神通独立破坏 |

普通NPC伤害继续走现有CombatCalculator。玩家飞弹增加可选体素碰撞，默认关闭，未改变敌方飞弹逻辑。手动施放不创建伪NPC；无法禁锢的空地也不能骗过禁锢锁链的目标检查。镇妖葫收服仍需要真实妖魔，不向空地施放收服。

## 4. 外观、数据与性能

首次受击时从原模型切到平滑体素，会同时改变形状、UV投影和光照。已匹配源贴图、顶点法线、漫反射/Standard模型及光滑度；但最近表面投影仍可能在尖角拉伸。因此按用户要求，岩石和树干完整状态也统一显示共享体素静态mesh，不再在首次破坏时整块切换外观。透明树冠仍保持原素材。

每套烘焙另外合并一份「完整外观」，所有同型实例共享网格和开启GPU实例化的材质。完整物体仅多一个渲染节点，沿用原碰撞；首次受击才复制采样数组、准备局部分块和切换碰撞。开局只预加载入口两块岩石的可修改分块，并非提前为全图生成所有分块碰撞体。

17套资产位于 `Assets/Environment/Voxel/Bakes/Rocks/` 与 `Trees/`。每套最多160000采样格位；目标世界采样边长约岩石12厘米、树干8厘米，大物件受上限约束更粗，小物件加密。离线采用BVH距离、归一化几何判定、简单开放端口补面和连续等值面；源包围盒外禁止生成实体。复杂非流形壳体仍需美术处理；特殊材质、法线贴图和木材年轮不保证完整复原。

地面分区为16×16个Terrain孔洞格，约3.125×3.125米；采样边长0.1953125米。邻区共用采样带，网格裁到边界，后建邻区继承切削历史。准备完成后只在运行时TerrainData副本上遮孔，切换实际碰撞。空块除清空sharedMesh外还禁用MeshCollider，避免引擎残留旧烹饪碰撞；引擎激活对象时可能重新绑定空Mesh，禁用状态必须保留。

攻击范围查询、土体修改、树根检查、断木生成、网格与碰撞重建共用约4毫秒软预算，按阶段轮转，预算用完才停；32个工作单元是防止空转的安全上限，已取消每帧只做两个单元的限制。一次网格生成、碰撞烹饪或地形遮孔仍不可抢占；当前检查有约8～12毫秒峰值，不代表独立包帧率保证。

### 4.1 大范围破坏与无缺面切换（2026-10-08）

当前平滑面由连续SDF直接用Surface Nets提取，没有对生成后的三角网格做拉普拉斯迭代。此次不改变距离场、采样密度、表面算法和破坏半径。

- 新地块先修改距离场，再直接生成破坏后的网格，取消「先生成完整地块、再挖掉重建」的重复步骤；不引用不存在的地面预烘焙Mesh。
- 已有地块生成待提交网格，并预烹饪碰撞，准备期间保留原来的可见网格和碰撞。待本批攻击登记完成、所有关联地块就绪后，在同一帧统一提交；新增地块一次上传合并的Terrain孔洞区域，最后同步物理变换。
- 后续攻击会废弃受影响块尚未提交的旧结果，按最新距离场重建；还原清空准备中和待提交的网格。防止旧结果盖回新坑，也避免先移除上层网格、坑底尚未生成时短暂露空。

同一编辑器、正式地形四分区交点、每次调用一次共享调度并等待下一帧的前后对照：

| 场景 | 修改前等待 | 修改后等待 | 修改前/后缺面帧 |
|---|---|---|---|
| 首次0.85米破坏 | 152帧 / 1.33秒 | 29帧 / 0.42秒 | 0 / 0 |
| 已有坑周围4米扩挖 | 444帧 / 4.24秒 | 83帧 / 1.22秒 | 7 / 0 |
| 首次3米破坏 | 203帧 / 1.85秒 | 31帧 / 0.51秒 | 0 / 0 |

每帧用49条向下射线检查受击区域；修改后再以真实焚天、巨剑及重叠攻击验证零缺面，最终所有地块的顶点、法线、索引与颜色和完整重建一致。以上秒数包含编辑器帧调度，非发布包性能保证，也不含技能自身的蓄力/飞行时间。新表面仍需准备时间，准备好后整体切换。

统一体素外观提高了GPU几何成本：全图岩石/树干合计约1206万三角形，实际只渲染摄像机可见实例，并共用网格/材质；这个总量不是每帧实际渲染量。尚未做远距离体素LOD与GPU压力认证。已破坏地块保留到场景退出或还原，没有流式卸载；连续大范围摧毁仍需后续内存优化。
