# 鼠标战斗与邪眼

左键执行一段功法特殊普攻，E执行一段武器物理普攻；两者各自推进连招并共享动作占用。左键按下一次执行一段功法普攻，按住不连续出招。未锁定时远程与近战朝鼠标方向攻击，射程仍由自身招式控制；右键可手动锁定神识范围内的目标，锁定后移动朝向、普攻和攻击神通对准目标，仍须左键逐次普攻。普通锁定击杀后清除，不自动续锁。已有动作未结束或冷却未好时不追加出招。

角色脚下常驻白色方向环，始终指向鼠标。站立时仅轮盘改变朝向；起步和出招时人物再转向。移动与瞄准方向夹角大于60°进入八向移动，回落到35°以内退出，避免边界反复切换。地面与御风各用自己的方向动画；原有锁敌转向保留。地面持戟前进使用指定Knight run01，侧移与后退使用Knight原地八向步态。

神通快捷键默认按住显示指引，松开最初按下的键施放；按住期间左键不提前确认，右键或Esc取消。取消后再松键不会释放；切换神通采用最新按下的键，开界面、失去焦点或更换槽位内容会撤销指引。主键盘、小键盘和自定义快捷键使用同一规则。仅在松键成功施放时扣灵力并启动冷却，失败不留待自动重试。已开启的持续锁链再次按键直接关闭。

自中心技能的范围圈贴在角色周围；锁链可直接指向神识内目标，不要求邪眼红圈。镇妖葫、青山剑和浮世万象的Q先进入引导再左键确认，镇妖阁保留直接进出。武器拆分后的左键功法/E武器规则见[武器与修行功法](武器与修行功法.md)。

邪眼从被动神通改为地品法宝 `treasure_devil_eye`，原激光的三秒间隔、三灵力消耗和特殊/被动伤害轴保留。装备且持有时自动寻找神识范围内最近敌对目标，接管普攻和激光，击杀后续锁下一个，走位由玩家控制。右键空地清锁并暂停接管，再手动锁定或重新装备恢复。卸下保留当前目标作为普通手动锁定，停止自动普攻、激光与续锁。自动神通释放编排留待后续法宝面板，本次不实现。

按住左或右Alt，右下角当前法宝放大并描边，上下显示已掌握法宝的半透明预览；滚轮立即循环装备，仅列出已持有法宝。松开Alt完成当前换位后收起预览。Alt期间滚轮由法宝独占，常规相机、地图编辑相机与体素演示相机均不缩放；松开后普通滚轮恢复缩放，不残留惯性输入。面板、过场、死亡与摆放状态不允许快捷换法宝。
