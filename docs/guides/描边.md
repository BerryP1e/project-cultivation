## 1. 是什么 / **现在的状态**

屏幕空间的角色描边：**玩家暖金、其他角色（NPC / 妖魔）冷蓝**，只描轮廓、不描脸上的折痕。
做法抄的是 URP 社区那套"4 张图 + 边缘检测"（B 站《Unity后处理线条描边效果思路》），
但**换成 Built-in 渲染管线**的实现（我们不是 URP，见 §4）。

| 项 | 状态 |
|---|---|
| 代码 | ✅ 写完：两个 shader + `GameGlobalOutline`（由 `场景自举` 补到主相机，排在辉光/调色**之前**） |
| 编译 | ✅ 0 error |
| **画面验证** | ✅ **2026-10-03 在 `Sect` 实测**：玩家一圈暖金线、开/关像素差 **4.33%**（22461/518400，最大通道差 525）；截图 `screenshots/描边_开.png` |
| 默认开关 | ✅ **`启用 = true`**（`粗细 = 2.0`）—— 验证过才开的；不想看就在组件上关掉 |
| 想调 | 进 Play → 主相机 → `GameGlobalOutline`（六个旋钮见 §3） |

**先看这些数**（默认值，都在组件上可调）：玩家线色暖金 `(1, 0.86, 0.45)`、其他冷蓝 `(0.55, 0.75, 1)`、
粗细 `1.6` 像素、强度 `0.9`、深度阈值 `0.02`、法线阈值 `0.85`、组 ID 阈值 `0.02`、软化 `0.45`。

## 2. 两趟怎么做

```
① 掩码（CommandBuffer 挂在 CameraEvent.AfterForwardOpaque）
     [Cultivation/OutlineMask] 一趟 MRT 写两张临时图：
       RT0（ARGBHalf）= 相机空间法线(RGB) + 归一化线性深度(A)
       RT1（ARGB32）  = 对象组 ID（0=背景 / 1=玩家(0.25) / 2=其他角色(0.6)）
     每个角色一次 CommandBuffer.DrawRenderer(渲染体, 材质, 0, 0)：
       · **不用动模型**（URP 视频靠"给 mesh 加一套 UV"区分物体；Built-in 按 renderer 画就行）
       · 组 ID 走材质属性 `_ID`（`DrawRenderer` 没有 MaterialPropertyBlock 重载，
         所以**每组一份材质实例**，不是每个物体一份）
       · 只画不透明：ZWrite On + ZTest LEqual；粒子/拖尾跳过（不然法术也会被描）
② 合成（OnRenderImage → Graphics.Blit(源, 目标, 合成材质)）
     [Cultivation/OutlineComposite] 沿 8 方向 × 2 半径采样上面两张图：
       组 ID 差 > 阈值        ⇒ 一定是两个东西的交界（背景=0，所以角色轮廓也走这条）
       深度**相对**差 > 阈值   ⇒ 轮廓（除以中心深度；绝对差在远处天生就大）
       法线夹角差 > 阈值      ⇒ 默认给得很松（0.85≈80°）⇒ 只管轮廓
     然后 smoothstep(软化) 做抗锯齿，再 lerp 上线色。
```

**为什么"线只贴在角色内侧"**：合成里遇到"中心像素是背景（组 0）"直接返回原色 ——
否则角色外一圈也会被画上，糊在场景上。

## 3. 六个旋钮（组件 `GameGlobalOutline` 上）

| 想调什么 | 改哪 |
|---|---|
| 线更粗 / 更细 | `粗细`（像素；1~2 = 细描边，3+ 偏风格化） |
| 线更淡 / 更实 | `强度` |
| 斜边有台阶 | 加大 `软化` |
| **只有轮廓、还是也描折痕** | `法线阈值`：给大（0.9+）= 只管轮廓；给小（0.3）会把五官/衣褶也描出来 |
| 远处不该有边的地方也画线 | 加大 `深度阈值` |
| 两个贴在一起的 NPC 之间没分线 | 减小 `ID阈值` |
| 只描玩家、不描别人 | 关 `描其他角色` |
| 玩家 / 其他角色的线色 | `玩家线色` / `其他线色` |
| 场景里人换了半天才描 | `列表刷新秒`（默认 2；角色列表每 2 秒重收一次，别每帧 `FindObjectsOfType`） |

## 4. 为什么不用"外扩网格"那套

`CharacterOutlineRim` + `CharacterOutlineFill`（`OcclusionOutline` 用的）是"沿法线把网格胀一圈、只画背面"：

| | 外扩网格 | 屏幕空间（本方案） |
|---|---|---|
| 线宽 | 按**米**算 ⇒ 角色在画面里变小就糊 | 按**像素**算 ⇒ 远近一样清楚 |
| 蒙皮网格 | 宽度随骨骼缩放变化（我们的角色全是 Tripo 蒙皮）✗ | 无影响 |
| 成本 | 每个角色复制一份网格 | 每个角色多画一遍（几十个 renderer） |
| 分色 | 要每角色一套材质 | 按**组**分色，一组一个色 |

## 5. 和 `OcclusionOutline`（穿墙显形）的关系

**这轮没动它。** 那套管的是"玩家被挡住时还能看见玩家"（黄色外扩网格 + 剪影），
和"风格描边"是两件事。以后要合并的话：在掩码那一趟把"被遮挡时要显形的物体"
**开着 `ZTest Always` 再画一遍**（给另一组 ID），合成时那组用另一种线色 —— 一套系统就能干两件事。

## 6. 坑（都是这次真踩到的）

| 坑 | 表现 | 修法 |
|---|---|---|
| **CGPROGRAM 里用了中文标识符** | 报 `Unexpected directive '\n'` / `Both vertex and fragment programs must be present` 这种看不懂的错 | HLSL/Cg **只认 ASCII 标识符**；中文只能放注释里 |
| **`line` 是 HLSL 保留字** | 报 `syntax error: unexpected token 'line'`，整个 shader 不生效 ⇒ **整屏粉** | 变量别叫 `line`（改 `edgeColor`） |
| 用"静态数组 + 循环索引"取方向 | 运行时 shader 不受支持 ⇒ 整屏粉，编辑器**不报错** | 方向写成**字面量**逐个调用，别用数组 |
| C# 字符串里嵌**半角引号** | `CS1003: Syntax error, ',' expected` | 用「」或去掉（老坑 B68） |
| 直接 `LoadScene` 后截图全黑 | 黑幕还盖着（过场） | 截图前 `黑幕字幕.清空()`，或**渲染相机到 RT**再存（RT 不含 Overlay UI） |
| 深度/法线边缘 + MSAA 打架 | 描边上有锯齿噪点 | 掩码 RT 固定 `samples = 1`（本实现就是这么建的） |

## 7. 顺带修掉：FXMaker 那 5 个特效 shader 编译不过

Assets/Other/Shader/EffectShader0/ 下 5 个（Distortion / Energy Ball / Additive Turbulence /
Alpha Blended Turbulence / Trail Additive Turbulence）在 d3d11 上报：

```
Shader error: 'vert': output parameter 'o' not completely initialized
```

根因：这些是 FXMaker 生成的 surface shader，oid vert(inout appdata_full v, out Input o) 里**只声明了一堆没用的局部变量、
从没初始化过 o** ⇒ 新编译器直接报错、用到它们的特效（扭曲/能量球/湍流）是粉块或不显示。
修法：在 ert 开头加一行 UNITY_INITIALIZE_OUTPUT(Input, o);（5 个文件各一行）⇒ 重新导入后 0 error。

> 这是**既有问题**（不是描边引入的），只是查 shader 日志时才被发现。
