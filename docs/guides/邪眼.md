# 邪眼

> **管什么**：邪眼的背负法环、环心特效、锁定攻击与外观适配。
> **不管什么**：外观持久化见 [外观系统说明](外观系统说明.md)；伤害公式见 [战斗与伤害](../architecture/战斗与伤害.md)。
> **本文件怎么查**：1 行为｜2 法环与骨骼｜3 调参与测试。
> **来源**：用户指定 Effect_32_DevilEye 与杨戬02法环，定期以粒子激光打锁定单位，特殊＋被动神通伤害。

## 1. 行为

`ability_xieyan` 学会并启用后，`PlayerAbilityLoader` 自动补 `DevilEyeAbility`，所有游玩场景共用内置登记。初版每3秒攻击一次、倍率0.8、最远20米，同时受神识范围约束；没有活锁定目标不攻击。射击使用用户指定的 `Effect_47_PreciseShot`，保留原法阵、五发粒子及拖尾/命中特效；视觉收尾2.4秒，伤害仍每轮结算一次特殊属性、被动神通伤害。每轮攻击先扣3灵气，扣蓝失败时不造成伤害也不生成新射击；恰好3点时允许攻击一次并扣至零。无目标不扣蓝，不足时跳过本轮，按原间隔再检查。数值使用被动神通表的`消耗灵力`，不额外叠加维持消耗。

停用或角色死亡移除法环与光束；技能不改变普通攻击功法。无锁定时可跟随Alt普攻确认的落点独立出击，检查神识范围、被动间隔与灵力；普攻动作尚未结束不阻止已就绪的邪眼，神识外只做方向普攻。命中体素破坏半径0.5米，手动落点范围伤害只影响敌对单位。

## 2. 法环与骨骼

从 `NPC/Human/YangJian/YangJian_02.prefab` 的 **YangJian_02_FaHuan** 烘焙独立网格，不克隆杨戬控制器，也不带回原骨骼引用。原尺寸约1.27×1.27×0.52，保持原姿态、中心归零；源网格只有正面，补背面后84顶点，避免背后观察消失。

输出 `Assets/resources/Abilities/DevilEyeHalo.prefab` 与 `YangJian02Halo.asset`。位置与倾角采用用户在Play中标定的姿态：玩家根空间位置 `(-0.04910,2.23887,-0.91732)`，旋转 `(36.46175,359.32650,359.45850)`，世界尺寸倍率 `1.25768`（玩家根缩放为1时）。在 `DevilEyeAbility.法环位置/法环旋转/法环尺寸` 调整；不直接照抄某一帧的胸骨Euler值，以免其他外观的骨骼轴不同。Humanoid优先UpperChest/Chest，Tripo优先Spine02。以胸骨局部偏移为目标进行指数插值（速率14），滞后最多0.12身高；超过2米的跳变立即归位，避免传送拖尾。外观替换时检测挂点变化并重建。

眼 `Abilities/DevilEye` 位于法环中心，移除原 `Effect_32_ObjectSphere` 和组成白色十字的 `Effect_32_Sphere_2/3`，网格粒子改为局部朝向。`DevilEyePupil.prefab` 是实体球体组成的琥珀眼球、黑色竖瞳与高光，随法环朝向，偶尔用0.65秒扫视后归中，不跟随摄像机；在粒子之后以正常深度测试绘制，避免叠加粒子冲淡竖瞳。

`Abilities/DevilEyeLaser` 已替换为 PreciseShot。原子弹节点旋转Y/Z各180°，本地负Z速度对应根节点正Z；`AbilityPreciseShotVfx` 将根节点正Z对准邪眼至目标身体中心，不使用PurifierBeam的75单位长度缩放。锁定与手动射击整体缩放均为0.024（原0.12的1/5），法阵使用局部空间跟随眼，弹道与拖尾使用世界空间，飞行速度40米/秒，世界终点与射程不随尺寸缩小。源演示碰撞面移除，运行时建立目标处的无碰撞组件Transform平面，粒子碰撞在此结束并触发原三个Collision子发射器。生成工具提供“仅更新邪眼射击特效”，不重建其他神通和场景。

拖尾保留原素材的循环发射，不能随其他单次粒子一起设置为非循环：源周期只有0.1秒，单次播放会留下约4米的一截。运行时粒子寿命取 `max(0.5, 实际距离 / 40 + 0.35)` 秒，保留从邪眼到目标的完整光路；发射率1600/秒，控制多发叠加时的粒子数量。隔离Play实测2、8、18米光路均从起点覆盖到目标附近，沿程粒子间隙小于0.4米，方向与命中特效检查通过。

## 3. 调参与测试

间隔、倍率、距离在被动神通表；挂点与缩放在 `DevilEyeAbility`。学习物品 `item_ability_xieyan`；图标 `devil-eye.png`。验证两套玩家外观、移动/转身/御风、正反面可见、眼在环洞中心、光束起点跟随骨骼，以及停用和锁定单位死亡时清理。
