# 千劫雷狱

被动神通 `ability_qianjie_leiyu`，运行组件 `QianJieLeiYu`，由 PlayerAbilityLoader 内置注册装卸。以玩家神识范围为半径，对范围内敌人间隔造成特殊属性、被动神通伤害；每秒消耗灵力，缺省表值为 3。

## 表现与资源

- 玩家范围圈：`CombatVFX/CombatMagic/lightning-fx/lightning-arc-black-ring`。随神识范围缩放；移除 zaps 整棵装饰子树，保留主体黑圈。
- 敌人雷罚：`CombatVFX/CombatMagic/lightning-fx/lightning-ray`。在伤害判定节点生成一次竖直落雷，取代原 lightning-whirling-arc-zone 常驻效果。
- 原生 prefab 的地面闪光、飞溅和 ray/glow 保留；根设在目标脚部落点，+Z 朝上，宽度系数 0.65。长度按落雷起点到落点计算；敌人模型尺寸继续参与整体缩放。

`LightningRayVfx` 保留原 Stretch Renderer 和粒子速度/寿命，调整 lengthScale 覆盖实际长度；不反复 Play 旧常驻雷罚，不统一加速或提前销毁原粒子。材质、贴图、网格和 Shader 使用 Art/VFX/Shared 的公共依赖。

## 伤害

攻击属性为特殊，类别为被动神通；使用被动伤害加成/减免，不使用主动神通或普攻伤害档位。目标筛选、神识范围和持续扣灵沿用原实现。与雷云可同时装备，各自扣灵与结算。

当前 prefab、场景序列化路径与动态加载路径统一迁移。变更特效后需验证范围内/外目标、单次出手频率、原生粒子生命周期、停用清理，以及多个场景的 PlayerAbilityLoader。
