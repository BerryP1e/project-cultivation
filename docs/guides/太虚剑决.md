# 基础灵剑与太虚剑决攻击模组

更新：2026-10-22。太虚剑决已不是修行功法，其动作模组由独立“基础灵剑”提供。拥有/装备/输入见[武器与修行功法](武器与修行功法.md)；修改动作前必须读[动作定稿登记](动作定稿与重建边界.md)。

## 攻击与资源

方法id为basic_taixu_sword_01，BasicTaixuSword01复用实际武器网格接触与物理普通攻击结算。三式按A1→A2→A3轮转，攻速缩放，动作结束后可接下一式，无额外整轮停顿。A1/2取锦衣卫Attack001/003完整动作，A3取神秘人Attack1；御风攻击取对应已定稿成品，不由新持握烘焙器重建。

出手距离2.3米、判定18%～95%、接触外扩0.55米。物理进入结算后必中，但仍须真实剑身接触目标；一轮对目标去重，挥空不预扣血。物理/特殊与主动/普攻两轴分开。

武器为ShenMiRen_03网格及原材质，成品Weapons/太虚剑决_神秘人剑挂实际玩家R_Hand。待机、地面步态、攻击及御风成品在resources/技能动作/太虚剑决和对应地面/御风目录。

## 定稿持握与安装曲线

地面基准为Magical-Knight Humanoid atk_air01第一帧，已烘焙进持剑_Idle。右肩至手腕9通道、五指20通道、剑子节点7条安装补偿一并决定握姿和剑尖斜下方向。剑子节点以握柄中心校准，不改变原源网格；攻击成品恢复自己的安装TRS，不能把待机角度盖进攻击剑路。武器挂入后重绑Animator，保留重装备与换装后的曲线识别。

地面前进保留原持剑前进下身，其他方向使用各自Knight地面步态。御风身体和腿取当前基础御风，右持剑臂按地面定稿方向传递，剑尖向外斜下；不会退回Flying Mage自由摆臂，也不恢复旧固定胸腰造成的整体侧偏。

SpiritSwordFlightGripBaker逐帧只调整持剑臂，通过HumanPose完整编码保留实际身体；恢复右指及武器安装曲线。YufengDirectionalBaker.RebuildSpiritSword仅更新9段灵剑御风成品，保留GUID，不动地面、攻击、武器挂点。完整八向重建也必须调用同一持握步骤，避免“修好身体又丢持剑”。

最新独立实际Avatar/武器验证：9段各32相位，剑尖约向下36.2°，身体胸髋倾角与基础御风差最大约0.02°；261项覆盖指、安装曲线和实际姿态。详见[定稿登记](动作定稿与重建边界.md)。不把数值检查替代用户最终动作观感验收。
