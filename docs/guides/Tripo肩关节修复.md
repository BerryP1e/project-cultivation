# Tripo肩关节修复工具

> **管什么**：Tripo肩位内收的模型修复、预览、导出与接入。
> **不管什么**：换外观导致的轴向反扭见 [外观系统说明](外观系统说明.md)；动作制作见 [御风前进动作](御风前进动作.md)。
> **本文件怎么查**：§1 使用｜§2 修复原理｜§3 接入边界｜§4 验证。
> **来源**：用户提供肩位标注图；TripoShoulderRepair与隔离骨架、蒙皮和导出检查。

## 1. 使用

退出Play，在Project选择原始Tripo FBX，菜单 **修仙 / 动画 / Tripo肩关节修复工具**。也可拖入不带业务脚本的模型预制体。场景实例及带NPC脚本的预制体不接受。

左侧是原肩位，右侧是修后肩位，红/金连线标出锁骨、肩关节、肘和手。拖动预览可水平旋转。预览采用贴图直显材质以便检查轮廓，导出恢复原材质。

| 参数 | 默认 / 范围 | 含义 |
|---|---|---|
| 双侧联动 | 开 | 调左侧时同步右侧；关闭可分开调 |
| 肩外移 | 0.25 / 0～0.55 | 相对于该侧原上臂长度的外移比例 |
| 肩升降 | 0 / -0.25～0.25 | 相对于原上臂长度的垂直偏移 |
| 动作预览 | 绑定姿势、待机、跑步、御风前进 | 两侧使用同一个片段、同一时间 |

0.25只是试调起点，不是所有人物的最终肩位。以衣服内部的真实肩关节为准，检查抬臂与转身时袖口、腋下的变形。窗口显示肩宽及肘/手位置误差。

“导出新的肩部修复模型”选择Assets内目录，生成独立`.asset`（Avatar与Mesh子资产）和纯模型`.prefab`。文件名唯一，不覆盖原FBX、旧输出或场景。输出前恢复绑定姿势、模型根位置和原材质，不把预览动作或比较舞台偏移存进去。

代码：`Assets/Editor/Tools/TripoShoulderRepair.cs`与`TripoShoulderRepairWindow.cs`。

## 2. 修复原理

移动的是`L_Upperarm/R_Upperarm`的起点，即肩关节。`L_Clavicle/R_Clavicle`的胸侧起点保留，锁骨末端随肩关节延长；不是将整条手臂平移。

上臂朝向重新对齐保留的肘位置，后代肘、手、手指的世界位置和旋转保持，UpperarmTwist节点沿新上臂分布。网格顶点、权重与三角形不变；绑定矩阵按下式修正，以保留修改前的静态蒙皮：

`新bindpose = 新骨骼世界矩阵⁻¹ × 旧骨骼世界矩阵 × 旧bindpose`

根据新骨架重建Humanoid Avatar，并检查isValid/isHuman。优先使用源FBX映射；没有Humanoid映射时使用项目标准Tripo骨骼名映射。缺骨、同名节点或多个Animator会停止处理。副本与预览材质随窗口关闭或参数重建释放。

## 3. 接入边界

当前完成的是工具与隔离验证，游戏中的模型引用尚未批量替换。输出只含视觉模型和Animator，不含NPC逻辑或动画控制器。接入时在既有角色预制体中使用修后视觉模型与新Avatar，保留原NPC业务组件与适配的Humanoid控制器。先验证一个角色，再逐个推广，不重跑场景生成器。

玩家换装共用一套骨架，两件皮肤必须最终使用同一套目标肩位与Avatar；只替换某个皮肤的网格无法改变玩家骨架的肩关节位置。`AppearanceMeshBinding`会以目标骨架的原网格bindposes兼容外观，它不能代替本工具的骨架修复。

Humanoid肌肉片段可以在新Avatar上预览；Generic或Transform曲线可能覆盖新肩位，需要另行重定向后再接入。工具没有重新刷蒙皮权重；明显错误的腋下权重、衣服穿模仍可能需要单独修改权重，不能仅通过外移肩关节解决。

## 4. 验证

| 检查 | 已验证范围与结果 |
|---|---|
| 骨架与静态蒙皮 | 15个人形FBX：玩家两个源模型、大师兄及修复版、师傅、npc_elder、小梅1～4、成男/成女/正太/老头/胖叔村民；Avatar有效 |
| 外移后静态误差 | 最大蒙皮顶点误差约4.2×10⁻⁷模型单位；最大肘/手误差约3.9×10⁻⁷ |
| 动作 | 玩家、大师兄、师傅、成男村民：待机、跑步、御风各61相位，蒙皮无NaN/Infinity，另有绑定姿势截图 |
| 导出再读 | Avatar与Mesh为持久资产，原材质恢复、根位置恢复、Animator启用、纯模型无业务控制器 |
| Console | 编辑模式验证报错0 |

脚本：`.dsh/_diag/tripo-shoulder-check.cs.txt`、`tripo-shoulder-motion-check.cs.txt`、`tripo-shoulder-export-check.cs.txt`，用`exec_editor_script`执行，避免运行时脚本自动进入Play。截图在`cultivation/screenshots/tripo-shoulder-<模型>-<动作>.png`，左原始、右修后，不入库。有限顶点检查证明蒙皮可计算，不代表所有动作、武器握持与衣服穿模均已通过游戏内验收。
