# 体素局部破坏原型

> **管什么**：静态模型离线转换、距离场、分块网格、局部破坏与实验验证。
> **不管什么**：正式地图试点另有文档；技能接线、倒塌、破坏存档尚未实现。
> **正式地图进展**：整张宗门野外的地面、岩石与实体树干已接可撤回的按需替换，见 [正式地图体素试点](正式地图体素试点.md)；本文件仍说明独立原型。

## 1. 体验入口

打开 `Assets/Experiments/Voxel/RockSample/VoxelPrototype.unity`，进入 Play。左侧为原始 `resources/Environment3/nature item/Rock_1.fbx`，右侧为可破坏模型，最长边均归一到6米。

- 左键挖洞，Shift + 左键扩大范围。
- 右键旋转，滚轮缩放，`[` / `]` 调整半径。
- R 还原；左上显示实体数量、排队与重建计时。

菜单 **修仙 / 实验 / 体素局部破坏原型** 可选择静态 FBX/Prefab 生成独立对照场景。每次生成独立目录，不覆盖源模型或游玩场景；不修改源贴图可读性。支持 MeshFilter，尚不支持蒙皮人物及透明树叶。

## 2. 数据与局部更新

`VoxelVolumeAsset` 保存占用字节、连续有符号距离、采样色、分块坐标、预烘焙网格及材质。默认样例为0.12米格子、8³格分块：53,568个格位、17,529个实体格、95块。初始隐藏的内部块也保留，挖开后可生成断面。

平滑模式由 `VoxelDistanceBaker` 离线计算到源三角面的最近距离，使用 BVH 加速、射线奇偶判定内外，距离截断在四格范围。`VoxelSmoothMesher` 用 Surface Nets 按连续距离插值位置，并以距离梯度生成法线，避免二值占用反推斜面的台阶波纹。旧数据没有距离场时保留密度过滤回退。没有增加格子数量，不创建逐体素 GameObject。

运行时复制占用和距离数组，初始直接引用烘焙网格。球形破坏做距离场差集，小切削即使没有移除完整实体格，也会更新曲面。世界坐标球形判定支持缩放实例；非均匀缩放下距离值是保守换算，并非精确世界距离场。

只遍历球与距离带覆盖的范围，平滑版额外标记三格采样边界，包括对角相邻块。脏块队列去重，相同位置重复切削不重建。独立原型每帧最多准备2块，4毫秒为软预算：单块网格与 MeshCollider 重建不能中途抢占。新网格先暂存并预烹饪碰撞，受影响块全部就绪后统一替换，准备期间保留旧表面；首次破坏才创建对应块的独立网格。R 销毁运行时网格并恢复烘焙引用。当前是按块替换网格，并非 GPU 字节缓冲原地更新。正式地图使用共享轮转调度和跨地块统一提交，见[正式地图体素环境 §4.1](正式地图体素试点.md)。

实验路径由场景自举跳过，不启动正式主线、时间 HUD 或存档。

## 3. 自然物与建筑规则

岩石与自然地形可使用平滑等值面，洞口同步平滑。建筑墙、梁柱、门窗需保留平面、直角与硬边，不能套用自然物柔化规则。当前工具可关闭平滑，使用方块面；仍受格子对齐限制，尚未实现任意方向建筑的硬边保形、结构支撑和专用断裂。

关闭填充用于表面壳层，并不自动解决房间、墙厚和建筑结构。正式自然物烘焙已补简单开放端口、统一几何判定尺度并限制实体包围盒；复杂非流形或重叠壳体仍需预处理。单贴图UV使用BVH投影，并按三角面相对尺度判断退化，避免小单位FBX丢失UV插值。

连续距离改善斜面，但 Surface Nets 仍会柔化格子尺度内的尖角，转角和轮廓仍存在误差。默认 Rock_1 是无主贴图的低多边形石块，尚非最终环境美术效果。表面颜色采样源材质与主贴图，内部用混合色，三平面细节贴图补充纹理；尚未完整还原源材质或制作木材、砖石专用断面。

## 4. 验证与限制

菜单 **修仙 / 实验 / 验证体素斜面精度** 检查解析斜面的顶点与法线。此次覆盖2,161个顶点，最大平面误差约0.000000238米，包含跨块边界，验证平面不会产生格子波纹。

菜单 **修仙 / 实验 / 验证体素局部更新（Play）** 在隔离副本按实体格位置切削五次，重建75/95块；与全部重新生成的参考结果比较顶点、法线、三角索引、UV及颜色，同时检查源资产不变与还原。不会改变正在查看的样例。小体积模型改用一次局部切削。

沿相机射线连续19次切削，移除3,049格、80/95块排队、40批次，更新碰撞后射线穿过贯通孔。本地编辑器总同步工作约65.75毫秒、最高批次约4.53毫秒。这是小样例的 CPU 网格生成与碰撞赋值计时，不是独立包帧率或 GPU 压力测试；软预算仍可能超时。

原型尚无倒塌、碎块刚体、掉落物、破坏保存、正式技能接入、LOD、Jobs/Burst 或大地图压力测试。每块重建仍分配列表与网格，高频攻击还需复用缓冲、合并更新及优化碰撞。
