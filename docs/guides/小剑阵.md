# 小剑阵

> **管什么**：小剑阵的布阵点、伤害类别、时序与原特效发射器替换。
> **不管什么**：公式见 [战斗与伤害](../architecture/战斗与伤害.md)；装备槽见 [主动技能与神通](../architecture/主动技能与神通.md)。
> **本文件怎么查**：1 施放与伤害｜2 资源与参数｜3 验证。
> **来源**：用户明确要求主动神通、Effect_34_SwordDance、特殊属性、**被动神通伤害**；数值为初版。

## 1. 施放与伤害

施放动作使用太虚炼气诀普攻片段 `技能动作/普攻_远程_01`。SwordDance 的落剑用 `AbilityFallingSword` 保留原速度40（源素材单位/秒），按父级缩放换算世界运动，剑阵所在高度触地后固定，保留到技能结束；不依赖 `VariousEffectsScene` 的演示全局倍率。

触地后剑身和剑尖粒子停在成形阶段，停止拖尾发射，避免原五秒寿命提前淡出。`DirectedAbilityRunner.OnDestroy` 通知落剑结束，脱离执行体后用0.6秒淡出剑身，同时播放同包收尾特效；每把剑独立随机朝向，细粒子采用球形散射，不再全朝一个方向。收尾不结算伤害，剑和收尾特效分别按时清理。

`ability_xiao_jianzhen` 在主动槽按数字键施放。锁定时以目标脚下为中心；无锁定时以玩家为中心。阵中心固定，不跟着目标移动。范围内敌对单位与该次锁定单位吃伤害；同一NPC多个碰撞体只结算一次。

**手动施放不改变结算分类**：此项 `攻击类别=被动神通`、`伤害属性=特殊`，走被动法术加成/减免和会心；不能因占主动槽改成主动伤害。

## 2. 资源与参数

| 参数 | 初版值 |
|---|---|
| 每跳倍率 / 半径 | 0.55 / 3.2米 |
| 消耗 / 冷却 | 30灵力 / 8秒 |
| 时长 / 首跳 / 间隔 | 4秒 / 0.6秒 / 0.7秒 |

`Assets/resources/Abilities/SmallSwordArray.prefab` 及 `Parts/` 保留原 SwordDance 出剑与刃光部件。`AbilityVfxEmitter` 替代 `MultipleObjectsMake`，复用延迟、次数与随机参数，子物体归属执行体并继承显示层；去掉演示场景的全局尺寸依赖，结束统一销毁。

学习物品 `item_ability_xiao_jianzhen`；图标 `small-sword-array.png`。

## 3. 验证

检查无锁定布阵、锁定布阵、多碰撞体只打一遍，以及被动伤害加成确实作用于剑阵。Play预览不能只查看父粒子系统：本特效需要运行发射脚本才会出剑。隔离Play检查8把剑触地后保持，超过原粒子寿命仍显示，技能结束后开始淡出并清理；锁链另验向内生长、成形后持续保持与取消清理。
