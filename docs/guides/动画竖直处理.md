> **管什么**：动画片段里"上下晃 / 悬空"的成因与解决办法（把片段整体落回地面）、工具 `动画竖直压平.cs` 的用法、影响面。

## 1. 问题是什么（实测数据）

`普攻_远程_01`（太虚炼气诀的普攻动作，**很多功法/神通的普攻与施法动作都在用它**）
是拿**嫦娥的浮空施法动作重定向**来的，所以人整段**悬在地面上方**。

3C_Testbed 实测（站立待机髋骨世界 Y = **0.872m**）：

| 项 | 实测 |
|---|---|
| 攻击片段内髋骨世界 Y | 1.759 ~ 1.790（**片段内部只抖 0.032m**） |
| 攻击姿势最低脚骨 | 0.867 → **整段离地 0.847m** |
| 脚骨与髋骨的距离 | 0.90m（站立时 0.85m）→ **腿是正常垂着的，不是收腿坐姿** |
| 实机（逐帧） | 播动作后 **0.19 秒内髋骨 0.87 → 1.76（窜高 0.89m）**，片段跑完 0.13 秒内落回 0.87 |

**所以"上下晃"不是片段在抖，而是：这个姿势被整体抬高了 0.9m —— 每次普攻窜上去再落回来。**
（片段内部那 3cm 基本看不见。）

> ⚠️ 为什么不能"加个 Y 偏移"：骑乘 / 御风的基准高度和地面不一样，
> 在角色/模型上挂一个固定偏移，换个状态就错。**必须在片段数据里解决** —— 改一次，
> 所有用它的功法/神通、所有状态下都一致。

## 2. 怎么解决：把片段整体落回地面（常量下移 `RootT.y`）

工具做的是**一件事**：把 Humanoid 的根位移竖直分量 `RootT.y` **整体减掉一个常量**
= 整段里最低那根脚骨离地多少。

- `RootT.y` 是**整体平移**：只会把整具骨架一起上下挪，**不碰任何一根骨头的旋转** →
  动作（手臂、身体、出招）**一模一样**；
- 是**常量**而不是逐帧：动作节奏完全不变，脚该抬还抬（不会把脚钉在地上）；
- 改的是**片段数据**（可 git diff / 可回滚），和骑乘、御风、地形高度全都无关。

**改后实测**：

| 项 | 改前 | 改后 |
|---|---|---|
| 整段离地 | 0.847m | **0.001m**（脚踩地） |
| 攻击时髋骨 | 1.759 ~ 1.790 | **0.913 ~ 0.945** |
| 实机每刀窜高 | **0.89m** | **≈0.05m** |
| 片段内部抖动 | 0.032m | 0.032m（原样保留） |

拍图：`screenshots/普攻动作_改前.png`（人悬空、影子分离） / `普攻动作_改后.png`（踩在地上）。

### 2.1 ⚠️ 一次减不干净 —— 要迭代

人形重定向会把 `RootT` 的位移按「目标骨架髋高比」缩放：
本片段实测 **k ≈ 0.89**（名义减 0.847m，实际只落 0.753m）。
所以工具是**循环**的：量剩余离地 → 再减掉 → 复量，误差每轮按 `(1−k) ≈ 0.11` 收敛，
实测 2 轮就进 1mm。

### 2.2 和「贴地补偿」的关系

`PlayerAnimationController` 有一套运行时贴地补偿（按帧量脚底网格顶点、把模型往下/上拉）。
筛选必须限定到受脚部骨骼驱动的顶点。武器网格没有脚部顶点时应跳过，不能退回整个武器的最低点，否则挥刀触地会把整个人向上拉。全部网格筛不到才使用脚骨；空闲基准用同一套筛选，收招残余补偿逐渐归零。八九玄功实测该错误曾造成约 1.6 米的模型补偿，见 [八九玄功 §4–§5](八九玄功.md)。

它和本工具**不冲突**，但职责不同：

| | 运行时装补偿 | 本工具（改片段） |
|---|---|---|
| 管什么 | 个别姿势偶尔陷地 / 悬空 | 片段**整体**高度不对 |
| 代价 | 每帧算、要跟骑乘/御风协商、拉过头会变蹲姿 | 一次性数据修改，状态无关 |
| 实测 | 改后过渡的 0.1 秒里会介入一下（+0.13m），随后归零 | — |

> 这段片段的注释里写过「硬拉回来会变成蹲姿（髋骨 −0.84m）」—— 那是**补偿去钉脚底网格**
> 的结果。本工具是**按脚骨**对齐地面，实测腿是正常垂着的，所以落地后不会蹲。

## 3. 工具用法

在 Project 窗口**选中一个或多个 `.anim`** → 菜单：

| 菜单 | 作用 |
|---|---|
| `修仙/动画/检查竖直抖动（只读）` | 打日志：髋骨 Y 范围 / 片段内抖动 / **整段离地多少**。不改任何东西 |
| `修仙/动画/压平竖直抖动（改片段）` | 只压掉**片段内部**的上下抖（逐帧反相叠加到 `RootT.y`） |
| `修仙/动画/把片段落到地面（改片段）` | **整体常量下移**，让脚骨踩到地面（迭代收敛） |

采样需要一具人形骨架：优先用当前场景的 `Player`，没有就退回场景里任意人形 Animator；
采样走 `AnimationMode`（结束即还原，**不会**污染场景）。⚠️ 结果一律打 Console，不用模态框（踩坑 F8）。

### 3.1 全部技能动作片段的体检（2026-09-29）

| 片段 | 髋骨 Y | 片段内抖动 | 整段离地 | 结论 |
|---|---|---|---|---|
| `普攻_远程_01` | 0.913~0.945 | 0.032m | **0.001m** | ✔ 已落地面（原本 0.847m） |
| `技能引导动作3` | 0.788~0.806 | 0.018m | −0.012m | ✔ 本来就在地上 |
| `技能动作2` | 0.718~0.822 | 0.104m | −0.014m | ✔ 正常（那 10cm 是自然的踏步/下蹲） |
| `技能引导动作1` | 0.875~0.878 | 0.003m | −0.007m | ✔ 正常 |
| `技能动作4` | 0.705~0.806 | 0.101m | −0.011m | ✔ 正常 |

**只有 `普攻_远程_01` 悬空**，其余四个片段本来就是踩地的。

## 4. 影响面（谁在用 `普攻_远程_01`）

| 用它的地方 | 说明 |
|---|---|
| `BasicRemoteAttack01`（太虚炼气诀普攻） | Resources 里按名加载 |
| `BasicFrostSpike01`（沧澜寒渊录普攻） | `普攻动作名 = "普攻_远程_01"` |
| `BasicThunder01`（玄霄雷诀普攻） | `普攻动作名 = "普攻_远程_01"` |
| `HomingBoltSkillRunner`（瞬雷天闪 / 冰暴术） | `动作名 = "普攻_远程_01"` |
| `IcePillarSkillRunner`（寒墟） | `动作名 = "普攻_远程_01"` |

改的是片段本身 → 这**五处一起受益**，不需要逐个改配置 ✓

> ⚠️ 注意：这些招式的**特效锚点**（例如追踪弹"球在手上"的 `R_Hand` 位置）会跟着下降 0.85m。
> 这是**应该的**（人现在站地上了），实测冰暴术/寒墟出弹位置正常。
