# 禁锢锁链

> **管什么**：移动禁锢、持续耗蓝、取消条件与锁链特效。
> **不管什么**：技能槽见 [主动技能与神通](../architecture/主动技能与神通.md)；NPC 行为见 [敌人AI](../architecture/敌人AI.md)。
> **本文件怎么查**：1 行为｜2 消耗与取消｜3 特效和验收。
> **来源**：用户指定 Effect_48_CriticalTumor、无伤害、境界差增加耗蓝、再次按键或蓝耗尽取消；数值为初版。

## 1. 行为

`ability_jingu_suolian` 必须锁定活单位。`BindingChainSkillRunner` 给目标挂 `NpcMovementLock`：共同移动入口停止行走动画，LateUpdate 锚定位置以覆盖跳跃和直接位移；不关闭整个 AI，目标仍能攻击。锁按施法者分别计数，释放一个来源不会释放其他来源。

**此技能不调用伤害结算**。表中伤害倍率是父类的非零占位，不代表锁链有伤害。

## 2. 消耗与取消

初版开销6灵力、冷却2秒、最大施放距离20米。

`每秒消耗 = 4 × (1 + 0.12 × abs(目标境界等级 − 玩家境界等级))`。

两边相差越多，消耗越多，不区分谁境界更高。塔怪使用实际补正等级（可小数），普通NPC使用定义中的境界；不用击杀奖励等级代替。

再次按同槽技能键**先处理取消，再查冷却和灵力**。蓝耗尽、目标死亡/解锁/换锁、卸下、超过20米、玩家死亡/停用/销毁均释放；取消立即解锁，特效随执行体销毁。暂停时消耗自然暂停。

## 3. 特效和验收

`Assets/resources/Abilities/BindingChain.prefab` 来自 CriticalTumor 同目录 `Effect_48_BondageChain` 的主链和侧链。主预制体的同名Chain只是散射细线；真正的束缚链在子目录。球体、粒子爆发、火焰和中间Tumor均不接入。按目标身高缩放，中心对齐目标身体。

学习物品 `item_ability_jingu_suolian`；图标 `binding-chain.png`。Play检查无伤害、距离、境界差耗蓝、冷却中按键取消、蓝耗尽解锁以及多来源锁释放；不得通过禁用 NPC 全部组件实现。
