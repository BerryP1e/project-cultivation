# 默认移动动画

> **管什么**：普通玩家Walk/Run侧摆修正、派生片段、控制器接入与复验。
> **不管什么**：八九玄功持械动作见 [八九玄功](八九玄功.md)；悬空/竖直偏移见 [动画竖直处理](动画竖直处理.md)。
> **本文件怎么查**：§1 曲线处理｜§2 重建｜§3 实测。
> **来源**：PlayerLocomotionPolish与默认动画隔离模型Play取样。

## 1. 曲线处理

默认移动源为`Assets/resources/Animation Library/1/UAL1_Standard.fbx`的`Armature|Walk_Loop`与`Armature|Sprint_Loop`。Humanoid上胸、颈部与脚部的侧扭幅度较大，根旋转还包含整身侧倾；仅减少腿部肌肉不足以消除左右摆动。

派生`Assets/Animations/Locomotion/PlayerWalkSteady.anim`与`PlayerRunSteady.anim`，源FBX不修改：

- 胸/脊柱/头/颈Left-Right、Twist、Turn曲线围绕原中心缩到25%。
- 腿/脚In-Out与Twist、RootT.x围绕原中心缩到30%。
- RootQ按源帧率采样，统一四元数半球，求均值后Slerp保留30%变化，保持平均朝向/姿态。
- 前后迈步肌肉、RootT.y与其余曲线保持源数据；保留循环设置。

两个派生片段**保留原clip.name**，控制器Locomotion BlendTree改引用派生资产。持械覆盖器按原名称替换动作，不能随意改名。修正普通移动不覆盖八九玄功的杨戬Run派生动作。

## 2. 重建

停Play，菜单**修仙 / 动画 / 减轻默认移动侧摆（不动场景）**。工具只更新两个动画与PlayerLocomotion.controller，重复执行保留GUID；不生成玩家、不保存场景。工具在`Assets/Editor/Tools/PlayerLocomotionPolish.cs`。

## 3. 实测

`.dsh/_diag/default-run-steady-check.cs.txt`克隆独立可视骨骼到远处，关闭克隆业务组件；从源/派生clip各取60个相位。不改真实玩家功法、动作或输入。HumanPose肌肉跨度无单位，角度为整身旋转跨度：
