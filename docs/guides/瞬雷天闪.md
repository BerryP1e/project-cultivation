## 1. 效果与数值

体素破坏只缩浅纵向深度，水平范围保持不变：默认半径2.5米、深度0.3125米（原深度的1/8）。此调整针对发射雷球的瞬雷天闪，雷动千闪的位移破坏不变；敌人伤害范围不受影响。

**2026-10-09全状态动作更新**：地面、御风、骑乘统一使用 `Flying_Mage_Volume2/Animations/Humanoid/attack_FlyingAtk01_short.fbx`，非循环派生片段 `技能动作/神通施法/追踪弹_施法`。起手即在实际右手生成雷球，0%～50%平滑凝聚，50%～58%保持完整大小，58%（约1.837秒）放飞；动作连续播放，取消旧40%节点和1.5秒定姿流程。

手上粒子使用Local模拟和Hierarchy缩放，LateUpdate在动画高度补偿后跟随本帧手骨；源包sphere-main单独前移1.64米，施法实例将其归零，使视觉中心也位于右手。飞行仍复用NpcProjectile，保留追踪速度、伤害、充能和命中特效。施法及剩余收招占用动作，防自动普攻截断；弹先命中也会完成收招。释放/销毁只解除自己的占用，不干扰其他动作。

重建入口：**修仙 / 动画 / 重建神通施法（不动场景）**，`DivineCastingBaker` 保留源FBX和派生资产GUID，沿用0.946根高度基准。施法烘焙使用 `HandMotionRetargeting` 保留源动作逐帧的腕指曲线及关节限位，不再使用待机的固定屈指/缩腕规则。源Avatar和玩家Avatar均包含双手手腕与30根手指骨；在玩家骨架上对每段动作采样61帧，32根关节全部实际运动，局部旋转与限位后的源动作最大角差为0°。

天品主动神通，`ability_shunlei_tianshan`；结算方式是一个**新档位** `ActiveSkillKind.追踪弹 = 3`。

当前施放流程：

## 2. 代码与机制

| 文件 | 干什么 |
|---|---|
| `Data/ActiveDivineAbility.cs` | 新增枚举档 `ActiveSkillKind.追踪弹 = 3` |
| `Abilities/HomingBoltSkillRunner.cs` | **新增**。管"施法动作 → 右手凝聚 → 58%放飞 → 追踪/命中" |
| `Abilities/ActiveSkillCaster.cs` | `施放()` 里加一路分流 `施放追踪弹()` |
| `Npc/Ai/NpcProjectile.cs` | **复用**它的追踪模式（没改代码） |

### 2.1 飞行器是现成的

`NpcProjectile.设置追踪飞行(目标, 速度, 转向速率)` 已踩过坑调好：三维方向追踪（**不**把 y 拍平，天上地下都追得到）、按飞过距离补发沿路粒子、目标死了 / 超出 `追踪终止距离` / 超 `最长追踪时间` 都自己收尾。所以追踪这条**一行都没重写**。

⚠️ 球在手上凝聚至58%放飞之前 `NpcProjectile` 是 **`enabled = false`** 的 —— 它的 `Update` 一旦跑起来会以为要飞向世界原点，一帧就"到达"并结算。

### 2.2 出弹时机跟随动画进度

`凝聚完成进度 = 0.50`，`放飞进度 = 0.58`。球的缩放按0～50%进度平滑增长，50%后保持完整大小，58%启用追踪飞行；不按伤害表时间倒计时、不定住动画。缺少动作或被中断时清理未放飞的球并释放占用。

### 2.3 手骨跟随与收招

使用Humanoid实际RightHand，LateUpdate在动画高度补偿后更新挂点；源特效的主体发射器偏移在实例上归零。施法及收招占用动作，自动普攻和其他主动施法不能抢播；弹先命中也会完成剩余收招，结束后只释放自己的占用。
