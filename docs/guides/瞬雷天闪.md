# 瞬雷天闪（主动神通 · 追踪弹）

> **管什么**：主动神通「瞬雷天闪」的实现 —— 追踪弹档机制、动作 40% 出手、定住动作 1.5s 让球长出来、实测。
> **不管什么**：空置的闪电链/落雷特效见 [闪电链特效](闪电链特效.md)；雷云被动神通见 [雷云](雷云.md)；同套电系普攻见 [玄霄雷决与雷动千闪](玄霄雷决与雷动千闪.md)。
> **本文件怎么查**：§1 效果与数值 → §2.1 现成飞行器 → §2.2 动画驱动出手 → §2.3 定住动作 1.5s → §3 实测。
> **来源**：本仓库法术特效实现记录（原流水章节号已去除）。

## 1. 效果与数值

天品主动神通，`ability_shunlei_tianshan`；结算方式是一个**新档位** `ActiveSkillKind.追踪弹 = 3`。

用户需求原话：「使用太虚练气决的那个普攻动作，也是在动画的 40% 节点对锁定的敌人召唤发射一个闪电球，特效是 `lightning-sphere`，闪电球用比较快的速度向锁定单位飞去，**带追踪**，命中后特效 `lightning-explode`。对锁定单位造成**特殊、主动神通**伤害，冷却时间 10s，每次冷却完可以积累一次使用，最多可以积累 3 次，**消耗大量灵力**。」

```
普攻动作 普攻_远程_01（1.2s）
  ↓ 播到 40% 节点（0.48s）出弹
一颗闪电球（lightning-sphere）从角色胸口飞出，**带追踪**、22 m/s
  ↓ 命中锁定目标（胸口高度）
命中特效 lightning-explode + 一次【特殊 + 主动神通】伤害
```

| 项 | 值 |
|---|---|
| 神通id / 名称 | `ability_shunlei_tianshan` / 瞬雷天闪 |
| 神通品阶 | 天品 ⚠️ 我填的 |
| 结算方式 | `追踪弹`（新档位） |
| 伤害属性 / 倍率 | 特殊 ✓ / **3** ⚠️ 占位 |
| 范围 | 20（= **追踪最大距离**）⚠️ 占位 |
| 冷却 / 可积攒次数 | 10 ✓ / 3 ✓ |
| 需要锁定目标 | **是** ✓「对锁定的敌人」 |
| 消耗灵力 | **55** ⚠️「大量灵力」我按 雷动千闪 30 / 焚天 60 之间取 |
| 特效资源路径 | `…/lightning-fx/lightning-sphere` ✓（表里这列 = **闪电球**） |
| 施法动作 | **留空**（本档动作由 runner 按**普攻动作**播，留空才不会被插第二个动作） |

命中特效 `lightning-explode` 不走表里那列 —— 它是**另一个用途的资源**（不是同目录的变体），配在 runner 自己的 `命中特效路径` 上。

学习物品：`item_active_ability_shunlei_tianshan`（瞬雷天闪 神通玉简，天品）→ 效果 `学主动神通`。

## 2. 代码与机制

| 文件 | 干什么 |
|---|---|
| `Data/ActiveDivineAbility.cs` | 新增枚举档 `ActiveSkillKind.追踪弹 = 3` |
| `Abilities/HomingBoltSkillRunner.cs` | **新增**。管"播普攻动作 → 节点出弹 → 追踪 → 命中结算" |
| `Abilities/ActiveSkillCaster.cs` | `施放()` 里加一路分流 `施放追踪弹()` |
| `Npc/Ai/NpcProjectile.cs` | **复用**它的追踪模式（没改代码） |

### 2.1 飞行器是现成的

`NpcProjectile.设置追踪飞行(目标, 速度, 转向速率)` 已踩过坑调好：三维方向追踪（**不**把 y 拍平，天上地下都追得到）、按飞过距离补发沿路粒子、目标死了 / 超出 `追踪终止距离` / 超 `最长追踪时间` 都自己收尾。所以追踪这条**一行都没重写**。

⚠️ 球在"手上长"的 1.5 秒里 `NpcProjectile` 是 **`enabled = false`** 的 —— 它的 `Update` 一旦跑起来会以为要飞向世界原点，一帧就"到达"并结算。

### 2.2 出弹时机跟着**动画**走，不跟表的「首次造成伤害时间」

节奏由**动作进度**驱动：`Update()` 里 `if (动画.动作进度 >= 出手进度) 发射();` —— 和玄霄雷决的普攻（`BasicThunder01`）**同一套口径**。实测触发时进度 **0.400~0.402**。

播不上动作（没有 `PlayerAnimationController` / 找不到片段）就**立刻走同一条流程**（照样在手上生成、照样停 1.5 秒再飞），免得变成哑炮。

### 2.3 到节点**把动作定住 1.5 秒**，让球长出来再飞

`lightning-sphere` 要零点几秒才成形，而球飞 3.7m 只要 0.17 秒 —— **直接飞的话球还是一片稀的**。用户给的办法是：「当动画播到球生成的时候，会停止 1.5 秒，直到让球的粒子基本长出来，然后再继续播，球再飞出去」。所以现在是两段式：

```
动作播到 40%   →  ① 生成球（挂主角 R_Hand 骨骼，先不飞）
                  + 动画定住（animator.speed = 0），停 长球停顿时长（1.5s）
               →  ② 时间到：动画放开继续播 + 球放飞（开始追踪）
               →  命中：目标身上生成 lightning-explode + 结算伤害
```

为了让"定住"生效，给 `PlayerAnimationController` 加了正式接口 **`定住动作(bool)`** / **`动作已定住`**（见 [踩坑总库](../ai/踩坑总库.md)）：它的 `Update` **每帧都重写 `animator.speed`**，外面直接 `animator.speed = 0` 会被立刻覆盖。

⚠️ **收尾时一定会 `定住动作(false)`**（`收尾()` 和 `OnDestroy()` 各一道），否则玩家动画永远僵在那一帧。
⚠️ **定住的是「动画」，不是「人」** —— 角色照样能走动。所以球在手上等的那段时间里**每帧都要贴着手**（`球.transform.position = 出弹点()`），不然只摆一次的话人一走球就落原地。实测：一边定住一边把角色往 +x 走 1.1m，**球到手距离全程 0.000** ✓。

| 字段 | 默认 | 说明 |
|---|---|---|
| `长球停顿时长` | **1.5** | 到节点后定住多久。**填 0 = 不停、立刻飞**（球会偏淡） |
| `出弹挂点名` | `R_Hand` | 球生成在主角哪根骨骼上；找不到就退回「角色根 + 出弹抬高」 |

**定住期间实测**（3C_Testbed）：t=0.69/1.19/1.95s 时 `动作进度=0.407`、`animator.speed=0.00`、`定住中=True`，球粒子 0 → 25 → 50 颗；t=2.21s 起 `动作进度=0.435`、`speed=1.00`、球已飞出。★ 手上正好停 **1.50s**，球从 0 颗长到 50 颗。（拍图 `screenshots/瞬雷天闪5/`：手上是一团**带电弧网纹的完整雷球**。）
