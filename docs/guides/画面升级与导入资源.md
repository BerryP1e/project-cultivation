### 本轮修复

- ASP 的 LWGUI 编辑器使用当前 Unity 2022 没有的 `MaterialProperty.propertyType/propertyFlags`。新增兼容接口，保留 ShaderPropertyType/Flags 的原有语义，底层读取 `type/flags`。
- 新水和草的地形编辑着色器与 URP 14 重复声明线性采样器。给资源私有采样器加前缀，保留 Linear/Clamp/Repeat 的采样含义；没有修改 PackageCache 的着色器库。
- 旧水引用已从引擎移除的 ProceduralMaterial/SubstanceImporter，原 `.sbsar` 的两个纹理子资源也实际缺失。保留原 Substance 源文件与序列化引用，取消失效生成器，材质面板直接编辑颜色、水波、泡沫和贴图。
- `LegacyWaterTextureBaker` 生成确定性、可平铺的兼容法线及通道图：R 用于波动高光、B 用于岸边泡沫。只为缺失贴图的水材质补引用，已修复两个材质。这是新的兼容输出，不是原 Substance 的风格变体还原。
- 旧水的三个 Pass 宏改为有条件声明，消除宏重定义警告。
- 运行复验发现隐藏神通页面提前分配 PlayableGraph、退出 Play 时未释放的警告。改为页面打开后才创建预览，保留待展示条目；隐藏、打开、销毁及从未打开的四项生命周期检查通过。
- 雾的旧 Prefab 断开 API 改为先检查实例、再完整解包；无主相机时不会空引用。DynamicFogOfWar 的旧 API 由引擎针对该文件更新。
- 旧水示例场景取消失效的实时 GI 烘焙引用。原 2016 年缓存保留为 `Demo/SWS_Demo/SWS_LightingData.bytes`，不再作为当前版本的 LightingDataAsset 加载；需要烘焙时重新生成。

## 2. 灰暗与粗糙的来源

当前主场景已有 `Default-Skybox`，环境光为 Skybox，主光强度为 1；并非完全没有天空盒。需要进一步调整天空环境与阴影中的可读性。

当前全局调色叠加了饱和度 0.82、青灰染色 0.22、较强 Hable 压缩、墨阶 0.35、留白 0.25 和纸纹 0.18。实际同相机截图中，减轻这些处理后，地面斑点明显减少，材质颜色更清楚；建筑阴影仍偏黑。纸纹确实参与了粗糙感，地面贴图本身仍需改造。当前定位到的是这些直接参与渲染的参数，没有据此断定有某张 LUT 导致全部问题。

`GameGlobalGrade` 新增组件菜单：

- **画面试验 / 清朗水墨调色**：曝光 1.20、饱和度 1.08、染色 0.06、墨阶 0.15、纸纹 0.055、留白 0.10，较轻的高光压缩。
- **画面试验 / 恢复原水墨调色**：恢复既有默认参数。不会恢复用户自定义的每一个参数；需要保留自定义值时使用 Inspector 的撤销或另存。

正式默认调色未自动覆盖。Play 中相机由场景自举补齐组件，可在 `Main Camera > GameGlobalGrade` 的组件菜单做比较。既有 GameGlobalOutline、辉光及战斗逻辑保留。

同视角截图在仓库根 `.local/diagnostics/world-grade-original.png` 与 `world-grade-clear.png`。

## 4. 迁移建议与顺序

建议逐步迁移 URP，因为新草、新水和 ASP 都依赖这条管线。切换管线本身不会自动让粗糙纹理变漂亮；可先在现有管线验证光照、调色与材质方向。

1. 先在代表性的宗门/室外视角调整天空光、主光和阴影，明确角色、建筑和地面的大明暗层次。以较高纯度和明度为方向，避免单靠抬黑位变成灰幕。
2. 做草地与水岸样板：地面保留低频色块和道路，真实草承担轮廓与风动，减少密集碎斑。设草的距离裁剪、LOD 和密度预算，再铺到正式地形。
3. 角色、石头、树和建筑分别调材质。ASP 优先试角色，不给整个世界统一套角色 Shader。保留原有墨线；后续素材的造型、贴图和明暗设计也要匹配。
4. 适配正式 URP 后处理：现有 GameGlobalOutline、GameGlobalBloom、GameGlobalGrade 依赖 CameraEvent / OnRenderImage；目前只有试验描边适配完成。其余项目 Surface Shader、遮挡轮廓和部分战斗材质要逐项移植和回归。
5. 远处云雾分层遮地图空地。当前导入的体积雾是 Built-in 屏幕后处理，迁移时需要适配或使用对应 URP 方案；不能直接装在 URP 相机上。云网格与可控远景雾可以先做组合样板。
6. 验证角色外观、龙吐息、飞弹、透明粒子、UI 3D 预览、暂停/慢放，以及质量级别与构建，再切换正式项目管线。
