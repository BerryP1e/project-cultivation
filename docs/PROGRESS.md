## 1. 需求原文（用户 2026-10-01 给的完整设计）

### 第一阶段：洞府安顿，解锁核心基础 —— **灵田**（新手入门·资源挂机）

大师兄送你抵达僻静清幽的专属洞府后，并未立刻离去，而是开启宗门弟子基础养成教学，
解锁第一个核心日常设施：**洞府后山灵田**。

**剧情细节**：大师兄告知你，宗门弟子修行根基在于自给自足，灵石、灵药皆是后续炼丹、炼器、
修炼的核心资源，而专属灵田是外门、内门弟子最基础的挂机养成本命之地。
你的灵田初始为**一阶下品**，灵气稀薄，仅可种植基础聚气灵草，**无养护损耗、可全天候自动生长**，
完美适配离线挂机玩法。

大师兄亲手传授你基础灵植培育心法，赠予一阶灵种（聚气草、凝露花）、基础灵田滋养符箓，
叮嘱你每日简单打理即可，无需耗费大量时间，灵草成熟后可自动留存、一键收取。
同时交代规则：灵田可随你的修为提升、宗门贡献升级，升级后可种植高阶灵药，
生长速度、药效大幅提升。

**阶段解锁**：正式开启【灵田挂机养成】，日常循环：播种→挂机生长→一键收取→积累灵药资源，
为后续炼丹、炼器铺垫物资基础。

### 第二阶段：宗门日常授业，解锁双进阶设施 —— **炼器房 + 炼丹房**

安顿次日，大师兄如约前来，带你熟悉宗门核心修炼区域，循序渐进解锁两大进阶玩法，
形成「灵田产出→丹器消耗→实力提升」的闭环养成体系。

**1. 解锁炼器房（装备养成）**

- 宗门公共炼器阁，新手弟子可**免费使用基础炼器炉、普通火种**，无需消耗灵石，
  仅需耗费矿石、木材等基础材料
- 赠予一套**新手炼器图谱**（一阶法器：灵剑、护身法衣、储物袋）+ 基础炼器矿石
- **炼器为主动玩法**：手动操控熔炼、塑形、凝器，**成功率随熟练度、修为提升上涨**
- 炼制的法器可自用、上交宗门换贡献、或宗门坊市交易
- 熟练度达标后可申请**洞府专属小型炼器台**，免往返公共炼器阁
- **小剧情**：初次炼器大概率小幅失败（正常新手设定），大师兄顺势点拨

**2. 解锁炼丹房（修为提速）**

- 宗门炼丹房自带**稳定地火灵力**，新手可免费使用基础丹炉
- 传授一阶基础丹方（**聚气丹、清障丹、愈伤丹**），刚好适配灵田种植的基础灵草
- 核心逻辑：**灵田挂机产出灵药 → 炼丹合成丹药 → 丹药辅助修炼、快速提升修为**
- **差异化**：炼丹比炼器**更依赖灵药品阶**；灵田升级、培育优质灵药可大幅提升成丹率与品质
- 高阶丹药可加速修行、完成宗门任务、**兑换镇妖塔准入权限**

**阶段收尾**：拥有「挂机产资源 + 主动炼装备 + 主动炼丹药」的完整新手养成体系。

### 第三阶段：宗门试炼准入，解锁**镇妖塔**（长线挂机+主线突破）

修为稳步提升至**炼气三层**后，师父现身洞府，开启宗门核心长线玩法。

**1. 背景剧情**

- 镇妖塔为上古传承秘境，塔内封印历代宗门镇压的妖兽、残魂
- 层数越高，妖兽越强，蕴藏的灵气、稀有材料、高阶功法、灵石奖励越丰厚
- 主打离线挂机试炼，适配长线养成节奏

**核心规则（需求原文）**：弟子可**派遣自身神魂入塔挂机试炼，无需亲身涉险**，
挂机期间持续积累修为、妖兽内丹、炼器矿石、稀有灵药种子、宗门贡献。
每日可手动领取挂机收益，每隔固定层数解锁一次性极品奖励、永久属性加成。

**2. 闭环与约束**

- 镇妖塔挂机效率、层数解锁上限，与**修为、丹器熟练度、灵田品阶**绑定
- 修为越高解锁更高层数
- 炼器水平决定能否炼制**镇妖塔专属护身法器**，降低挂机损耗
- 炼丹水平决定能否炼制**驻塔凝神丹**，延长挂机时长、提升收益倍率
- 灵田等级提供高阶灵药，支撑丹药持续供给

> ⚠️ **用户 2026-10-01 澄清**：上面"派遣神魂挂机"是**设定上的说法**。
> 实际上就是**带主角进塔、可以不断手动刷塔**；
> 打不过这一层**可以返回上一层**，在能打过的地方**持续挂机**；
> 打完一波**过一会儿自动刷新一波**。

### 第四阶段：稳定日常循环，衔接后续主线

1. **日常挂机**：灵田全天候产出灵药、镇妖塔全天候挂机刷资源与修为
2. **日常主动**：利用挂机产出资源，炼丹提升修为、炼器打造装备
3. **主线伏笔**：**灵田异常灵气**、**镇妖塔妖力共鸣** 两大伏笔持续发酵，
   为后续「灵田异变、镇妖塔解封、宗门秘境开启」预留空间

### 补充需求（用户同日追加）

- 灵田/灵植**没有模型**，要自行生成合适的替代品；灵田有**种植格数限制**
- 种植需要**对应灵植种子**；初始任务奖励**生灵草种**，种下 **3 天成熟**，
  收获**随机数量**生灵草
- 部分灵草有**灵田品质门槛**；更高品质灵田**种出更多**
- 炼丹：需要**材料 + 消耗灵气**；每种丹方有**成功概率**和 **1~9 品品质**，
  品质越高成功率越低；做几个被动技能 `xx炼丹术` 提升 xx 品丹方成功率；
  另做几个被动技能减少炼丹时的**灵气消耗**；丹方通常**一味主材 + 多味辅材**；
  要**设计炼丹 UI**
- 炼器：和炼丹基本一样，只是产物改成法宝。**现在没有法宝，先不管**；
  愿意的话可以做个模子
- **时间系统**：每过一天获得一次修炼机会；这个机会**最多保存 3 天**，3 天后消失；
  每天最多修炼 **10 次**（日常 + 打怪加在一起）；**约 10 分钟 = 1 天**；
  **右上角 HUD 做纪年系统，同时显示时间**
- **破境**：破境**有概率**；**失败要重新刷一整个小境界的经验**；
  服用**对应大境界的破境丹**可提升成功率；**大境界破境需要专属丹药（后续再说）**
- 按以上内容**完善当前主线任务设计**，注意合理使用**对话演出、摄像头调度**
- 师傅模型已导入：`Assets/TripoModels/太虚宗掌门（师傅）/`，
  **常态开启御风，给他用御风的那些动作**

## 5. 待你决定 / 已知冲突

### 5.1 ✅ **破境按钮触发不了 —— 已解决**（选 A）

实测死结：

```
S=99  → 等级1  取累计(1)=100  本级已满=False   ← 99 >= 100 不成立
S=100 → 等级2  取累计(2)=220  本级已满=False   ← 已经晋级了
```

`查境界` 是 `等级 = f(总灵气)` 的**纯函数**，灵气够了就**自动晋级** ⇒
**不存在"攒满但还没晋级"的状态**，破境按钮无从触发。

**已按 A 实现**：新增 `PlayerCultivation.已解锁最高等级`，`查境界` 改为**不超过这个等级** ⇒
总灵气只填进度、到顶就停在当前级（`本级已满`），由**破境按钮**推进等级。
失败才有意义（否则失败时等级早自动涨上去了，破境形同虚设）。
存档 `SaveData` 版本 8 已加 `已解锁最高等级`（**读档时先恢复它、再恢复总灵气**）。
