## 1. 全局演出规则（对所有过场都适用）

1. **说话方立绘变大，不说话方立绘缩小** —— 对话框里谁在说话，他的立绘放大，另一方的缩小。
2. **黑幕白字全部是逐字打出**（打字机效果），**左键长按可加速**，文字**尽量居中**，字号要合适。
3. 对话选项沿现有系统：回答列表 + `需要标记` 控制"什么时候解锁哪个回答"。

## 2. 第一幕：起名与开场（黑幕白字）

存档创建完成后，先进一段过场黑幕白字（逐字打出）：

```
这是一个漫长的故事
讲述了一个少年如何一步步争渡成仙
那个少年的名字叫做：
```

→ **玩家起名**：回车键确认，**5 个汉字以内**。
→ 等 1 秒，**全黑、字幕清空**。
→ 打出：

```
在古古镇上……
```

→ **场景切换到「古古镇」**，主角出生在「**主角小屋**」前方。
（下文用 `xxx` 代替主角名字）

## 3. 第二幕：胖叔的问候

- **胖叔村民走向主角**，说：「嘿，xxx，今天起这么早？」
- 主角回复：「早啊，胖叔」
- 胖叔：「小梅好像在那边找你呢，你快去看看吧」
- **任务目标变为：和小梅对话**；**胖叔村民走回原位**。
- 此时小梅**解锁回答**：「小梅，找我有啥事不？」

后续回复：

- 小梅：「xxx哥哥，昨晚我听到你家后面林子里好像有奇怪的声音，你要不要检查一下啊」
- 主角：「谢谢小梅，我知道了，我等下去看看」
- 小梅：「嗯嗯」
- **任务目标变为：去主角小屋后方观察有什么事情发生了。**

## 4. 第三幕：野猪遭遇战（需要镜头调度）

- 主角来到**主角小屋右侧小树林空地** → 触发剧情：
  1. **生成一只野猪**（`YeZhu`）。
  2. **摄像头平滑移动、对焦野猪**；野猪**暂时不动**。
  3. **摄像头移回玩家**。
  4. 跳出**临时对话框（此时只有玩家立绘）**，**震动特效**，内容：「啊啊啊是妖怪！救命啊」。
  5. **点击结束对话框后**，野猪和玩家**被释放**，**野猪开始攻击玩家**。
- **倒计时 5 秒后**：
  6. **生成大师兄**，大师兄用动画「**御风前进**」**飞过来**。
  7. **黑屏 + 白屏闪一下**，表示击杀了野猪；**野猪扣完血、倒下死亡**。
  8. 大师兄在主角旁边用「**御风 idle**」站立，**调用与主角的对话框**：

```
大师兄：真是不好意思，妖魔跑出来了，你受惊了
主角　：仙人救我狗命，请受我一拜
大师兄：哈哈哈，降妖除魔乃吾辈分内之事，等等……
大师兄：你居然有灵根？
大师兄：少年，你叫什么名字？
主角　：回仙人，我叫xxx
大师兄：xxx，你可愿入我太虚宗？
主角　：回仙人，弟子愿意
大师兄：好，给你一时三刻，你处理好凡间事务，我们即刻回宗
大师兄：（自言自语）下山一趟，竟然给我捞到了一个好苗子，又是大功一件啊
```

- 对话结束：**大师兄解锁回答**「仙人，我准备好了」；**小梅解锁回答**「小梅，我要走了」
  （**支线任务**，之后再展开，目前只留引子）。
- **任务目标变为：料理好凡尘之事后和大师兄对话。**

**两条"别再走回去"的教训**（都是用户实测报的）：

1. **NPC 在不在场，不许由"哪段对话能说"决定。**
   原来洞府里的大师兄是靠 `确保对话NPC在场()` 补的，而它只在"这一阶段点名的对话**此刻能说**"时才补
   ⇒ 玩家一进洞府（阶段17）**人是不在的**（那段对话锁在宗门），必须先回去跟他说句话才见得到他 ✗
   用户原话：「**不能作为大师兄模型是否在洞府中加载的关键**」。
   现在改成阶段18 的 `动作=确保NPC`：**"进了洞府"这一件事**就决定他在不在。
2. **他本来就站在玩家旁边时，别再让他"飞到玩家身边"。**
   阶段19 原来是 `飞到`（目标 = 玩家实时位置）⇒ 他原地起风、抽搐半天（用户截图报的"抽搐"）。
   现在阶段19 是纯等待；`飞到` 只留给"真的要从远处过来"的场合（例：阶段31 师父御风）。

> ⚠️ `确保NPC` 的落点要**自己填**（它内部走 `生成NPC`，位置 = `坐标`；不填就是世界原点）。
> 洞府那一格取的是"出口光往洞里走 3 米"（实测 `(-6.2, 0, -8.8)`：地面 y=0、头顶无遮挡）。
> ⚠️ 角色**说哪句话**在 `对话表.csv`（`文本` / `回答` / `跳转`），**什么时候说**在 `任务表.csv`（`条件` + `对话id`）——
> 两边分工别混：改台词只动对话表。

> **旧版本（阶段18 让对话决定他在不在）留下的那段"灵田初见"台词已经删掉**：
> 它假设洞府里**本来就有一片后山薄田**（「这里，便是你的灵田了」「这一阶下品的灵田虽薄…」），
> 而现在的灵田是**玩家自己用开拓令摆的** ⇒ 那几句全是错的（用户原话：「我的灵田是我自己放下来的，怎么会有这样子的话？」）。
> 该讲的都在阶段20 的心法里（含"拿开拓令自己挑地方开田"）。

**⚠️ 不要靠"往场景里摆一份大师兄"来解决跨场景问题。**
曾经这么做过（把预制体摆进 `3C_Testbed`），但**保存那个场景会连带重排它里面序列化的一份运行时 UI 列表** ——
实测一次保存带出 **1541 行**与本次无关的改动（`Row_*` 那些 `m_AnchoredPosition` 一路排到 `y ≈ -10909`）。
**能用代码解决的事，就别去保存场景。**

**为什么走"按需重建"这条路**：跨场景的剧情 NPC 有三条路 —— 不销毁（`DontDestroyOnLoad`）、摆进场景、**按需重建**；
本工程选第三条，因为它同时解决"漏场景"和"场景噪声"两个问题。而**重建要有"我是用哪个预制体造的"这条记录**
（`生成过的NPC`；`生成NPC` 那边已经补了兜底登记），记录缺失时重建会**静默地永远不生效**。

**实测（2026-10-02 重排后）**：

```
阶段17 在宗门 → 引导 名字=[洞府传送点] 场景=[Sect] 有=True 点=(-18.23, 1.00, 27.54)   ← 箭头指那道光
阶段28 在宗门 等 1.5 秒 → 仍是 q_main_004_28（人还在宗门，不该完成）                  ← 「回洞府」是真的要回去
进洞府（阶段17）→ 完成 17 → [Warning] 确保NPC：npc_dashixiong 不在场 → 重建
                → [任务] 生成 大师兄_任务生成 于 (-6.20, 0.00, -8.80) → 完成 18
0.6 秒后        → 完成 19 → [任务] 调度：强制对话（大师兄）共 6 句
                → 第一句 =「这片后山，往后就是你的本命之地。」                            ← 用户要的"一进来就该说的话"
```

### 6.2 去宗门炼丹阁（阶段25~27 的定式：**黑幕 → 切场景 → 走到跟前**）

「次日带你去看丹房」这一段原来只有**一句目标**（旧阶段25「带上丹方去丹房」`条件=无`），
`条件=无` 是**下一帧就完成** —— 结果那句目标**根本没机会被玩家看到**，
而且玩家还在洞府、场上没有任何指引（既没有 NPC 也没有地点标记）。

改成三步，**每一步都让玩家看得见**：

| 阶段 | 阶段名 | 条件 | 动作 / 关键列 |
