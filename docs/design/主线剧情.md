## 1. 全局演出规则（对所有过场都适用）

1. **说话方立绘变大，不说话方立绘缩小** —— 对话框里谁在说话，他的立绘放大，另一方的缩小。
2. **黑幕白字全部是逐字打出**（打字机效果），**左键长按可加速**，文字**尽量居中**，字号要合适。
3. 对话选项沿现有系统：回答列表 + `需要标记` 控制"什么时候解锁哪个回答"。

## 2. 第一幕：起名与开场（黑幕白字）

存档创建完成后，先进一段过场黑幕白字（逐字打出）：

```
这是一个漫长的故事
讲述了一个少年如何一步步争渡成仙
那个少年的名字叫做：
```

→ **玩家起名**：回车键确认，**5 个汉字以内**。
→ 等 1 秒，**全黑、字幕清空**。
→ 打出：

```
在古古镇上……
```

→ **场景切换到「古古镇」**，主角出生在「**主角小屋**」前方。
（下文用 `xxx` 代替主角名字）

## 3. 第二幕：胖叔的问候

- **胖叔村民走向主角**，说：「嘿，xxx，今天起这么早？」
- 主角回复：「早啊，胖叔」
- 胖叔：「小梅好像在那边找你呢，你快去看看吧」
- **任务目标变为：和小梅对话**；**胖叔村民走回原位**。
- 此时小梅**解锁回答**：「小梅，找我有啥事不？」

后续回复：

- 小梅：「xxx哥哥，昨晚我听到你家后面林子里好像有奇怪的声音，你要不要检查一下啊」
- 主角：「谢谢小梅，我知道了，我等下去看看」
- 小梅：「嗯嗯」
- **任务目标变为：去主角小屋后方观察有什么事情发生了。**

## 4. 第三幕：野猪遭遇战（需要镜头调度）

- 主角来到**主角小屋右侧小树林空地** → 触发剧情：
  1. **生成一只野猪**（`YeZhu`）。
  2. **摄像头平滑移动、对焦野猪**；野猪**暂时不动**。
  3. **摄像头移回玩家**。
  4. 跳出**临时对话框（此时只有玩家立绘）**，**震动特效**，内容：「啊啊啊是妖怪！救命啊」。
  5. **点击结束对话框后**，野猪和玩家**被释放**，**野猪开始攻击玩家**。
- **倒计时 5 秒后**：
  6. **生成大师兄**，大师兄用动画「**御风前进**」**飞过来**。
  7. **黑屏 + 白屏闪一下**，表示击杀了野猪；**野猪扣完血、倒下死亡**。
  8. 大师兄在主角旁边用「**御风 idle**」站立，**调用与主角的对话框**：

```
大师兄：真是不好意思，妖魔跑出来了，你受惊了
主角　：仙人救我狗命，请受我一拜
大师兄：哈哈哈，降妖除魔乃吾辈分内之事，等等……
大师兄：你居然有灵根？
大师兄：少年，你叫什么名字？
主角　：回仙人，我叫xxx
大师兄：xxx，你可愿入我太虚宗？
主角　：回仙人，弟子愿意
大师兄：好，给你一时三刻，你处理好凡间事务，我们即刻回宗
大师兄：（自言自语）下山一趟，竟然给我捞到了一个好苗子，又是大功一件啊
```

- 对话结束：**大师兄解锁回答**「仙人，我准备好了」；**小梅解锁回答**「小梅，我要走了」
  （**支线任务**，之后再展开，目前只留引子）。
- **任务目标变为：料理好凡尘之事后和大师兄对话。**

## 5. 第四幕：启程入宗

点「仙人，我准备好了」：

- 大师兄：「你准备好了，那我现在就带你去宗门吧」
- **停留 2 秒**

- **大师兄和主角来到 sect 场景的 `mainteleport` 这个传送点旁边**
- 大师兄（御风 idle）：「这就是我们太虚宗了，你先在此等候，我去禀报师尊」
- 大师兄：「哦对了，这是我们门派的便服，你先穿上吧。」
- **获得道具「门派便服」**（已有：`item_menpai_bianfu`，使用后获得「修仙者」外观）

- 大师兄（御风前进）：**往前飞到 `environment_Building_luoxiaguan_001_h` 建筑前**。
- **任务目标变为：等候大师兄禀报。**

## 6. 第五幕：等候与洞府

- **等候 60 秒**
- 大师兄（御风前进）**飞过来找你**，开启对话：

```
大师兄：xxx，师傅今日外出了，不过他传信于我，说已经知道你了，叫我先领你去你的洞府看看
主角　：好的仙人
大师兄：以后就不要叫我仙人啦，我是大师兄，你是我的小师弟
主角　：好的大师兄
大师兄：那你跟上我吧。
```

- **任务目标变为：跟随大师兄。**
- 大师兄（御风前进）至 **`sect1 to 3c`** 旁边。
- **解锁大师兄回答**：「这里就是我的洞府吗？」

点「这里就是我的洞府吗？」：

- 大师兄：「嗯嗯，你从这道光进去就好啦」
- **任务目标变为：前往个人洞府。**

### 6.1 洞府里的大师兄（**靠任务系统在他不在场时补出来**）

进洞府之后紧接着是灵田教学（`q_main_004` 阶段17~24：灵田初见 → 带你去后山 → 传你灵植心法 →
收下灵种与开垦令 → 灵田已开 → 次日清晨 → 带你去看丹房），**每一段的 `条件` 都是「对话」**，
而 `dlg_act5_dongfu_1` / `dlg_act5_lingtian_1` 都是 `npc_dashixiong` 的段 —— 也就是说
**大师兄不在场，整条洞府线直接卡死**（对话永远等不到，`完成当前阶段` 永远不会被按）。

**根因（比"NPC 被切场景销毁"更深一层）**：

```
① 大师兄由 `生成NPC` 造出来，是**场景内对象** —— 玩家走 `sect1 to 3c` 传送门进洞府
   （**不是**任务驱动的 `切换场景`）时，他随旧场景一起销毁；
   而任务动作**不会**在新场景重跑（`已执行动作` 按 `任务id#阶段` 跳过）。
② 更关键：`生成NPC()` 原本**只在任务表填了 `动作目标npcId` 时才登记**
   「这个 NPC 是用哪个预制体造的」（`生成过的NPC` 那张表，供 `找NPC` 就地重建）。
   而 `q_main_004` 阶段5 那一行**只填了 `动作参数`（预制体路径）**、`动作目标npcId` 是空的
   ⇒ 大师兄**一次都没被登记过** ⇒ **既有那条重建路径从来没生效过**。
```

**两处代码修法**（都不需要动场景）：

| # | 改哪 | 做法 |
|---|---|---|
| 1 | `任务管理器.生成NPC()` | 登记 id **优先取 `动作目标npcId`，没填就拿刚生成出来那个实例的 `NpcInstance.定义.id` 兜底**；两者都拿不到才打一条警告（"这个 NPC 以后不在场时没法自动重建"） |
| 2 | `任务管理器` 新增 `确保对话NPC在场(阶段)` | 对每个 `条件=对话` 的当前阶段调一次：要跟谁说话而**那人不在场**，就把他**补在玩家旁边**。要跟谁说话 = 任务表 `目标npcId`，没填就用 `对话id` 走 `DialogueDatabase.取NpcId()` 反查 |

`确保对话NPC在场` 的四条约束（都在代码注释里）：

- **只补任务自己生成过的 NPC**（内部查 `生成过的NPC`）⇒ **不会凭空造出场景里本来没有的路人**；
- 调用点在**演出锁之前、条件判定之前** —— 它不参与"条件是否达成"，纯粹是"把场景补齐"，
  所以不该被演出锁挡住（否则过场期间进场景，人得等过场结束才出现）；
- 每个「阶段 + NPC」**只试一次**（失败也不刷屏）；
- 补完立刻能引导（`任务引导` 走同一套 `目标npcId` / `对话id` 解析）。

**⚠️ 不要靠"往场景里摆一份大师兄"来解决。** 曾经这么做过（把预制体摆进 `3C_Testbed`），
但**保存那个场景会连带重排它里面序列化的一份运行时 UI 列表** —— 实测一次保存带出 **1541 行**
与本次无关的改动（`Row_*` 那些 `m_AnchoredPosition` 一路排到 `y ≈ -10909`，重排后最小值变成 `y ≈ -478`，
**728 个坐标值被改写**）。为了一行剧情改动，往提交里塞进无法解释的场景噪声，不划算也不再采用。
**能用代码解决的事，就别去保存场景。**

**实测（跑真流程到洞府）**：

```
阶段5 生成：            [任务] 生成 大师兄_任务生成 于 (24.07, -0.69, -5.29)
进洞府 + 拨到阶段18：    [Warning] [任务] 找NPC：npc_dashixiong 不在场（多半被切场景销毁了）
                                   → 就地重建于 (0.00, 0.02, 1.20)
                        [任务] 「灵田初见」要跟 npc_dashixiong 说话，但它不在场
                                   → 已就地补出来 @(0.00, 0.02, 1.20)
补出来后面板立刻有目标：  [主线 · 拜入太虚宗] [灵田初见]
                        [大师兄说，修行根基在于自给自足。] [目标：大师兄　2.7 米]   ← 头顶感叹号 激活=True
说完那段对话：           阶段 18 → 19，阶段19 的「飞到」正常执行
                        （大师兄_任务生成 飞向玩家实时位置 (0.00, 0.02, 2.00)）
```

截图：`cultivation/screenshots/引导_洞府大师兄.png`（洞府里的大师兄 + 左侧面板 + 头顶感叹号）。

> **通用教训**：**"某样东西一定在场上"这种假设，要在它不成立的那一刻就被兜住。**
> 跨场景的剧情 NPC 有三条路 —— 不销毁（`DontDestroyOnLoad`）、摆进场景、**按需重建**；
> 本工程选第三条，因为它同时解决"漏场景"和"场景噪声"两个问题。
> 而**重建要有"我是用哪个预制体造的"这条记录** —— 记录缺失时，重建逻辑会**静默地永远不生效**
> （这次就是这样：代码路径写得没错，但从来没被走到）。

### 6.2 去宗门炼丹阁（阶段25~27 的定式：**黑幕 → 切场景 → 走到跟前**）

「次日带你去看丹房」这一段原来只有**一句目标**（旧阶段25「带上丹方去丹房」`条件=无`），
`条件=无` 是**下一帧就完成** —— 结果那句目标**根本没机会被玩家看到**，
而且玩家还在洞府、场上没有任何指引（既没有 NPC 也没有地点标记）。

改成三步，**每一步都让玩家看得见**：

| 阶段 | 阶段名 | 条件 | 动作 / 关键列 |
|---|---|---|---|
| 25 | 翌日启程 | `黑幕落下完成` | `黑幕字幕`，台词 `翌日，太虚宗\|大师兄引你往丹房去` |
| 26 | 到宗门丹房 | `无` | `切换场景` + `场景名=Sect` + 落点 `坐标 = (0, 3.5, 14)` |
| 27 | 走近丹房 | `到达`（坐标 = 炼丹阁站点 `(-4.59, 3.48, 29.92)`，半径 5） | `完成加标记=q_主线_丹房已解锁` + `引导坐标=-4.59;3.48;29.92` / `引导地点名=宗门炼丹阁` / `引导场景=Sect` |

阶段27 那三列 `引导*` 就是**左侧追踪面板的内容来源**（
[guides/任务引导](../guides/任务引导.md)）：面板显示「走近丹房 / 宗门炼丹阁　17 米」+ 头顶金色「！」，
走到跟前（离站点 **2.9 米**）→ `q_main_004` **整条完成** ✔，面板与两个标记全部消失。

**⚠️ 落点必须实测"站得住"，不能只看射线打没打到地面。** 选 `(0, 3.5, 14)` 之前先用射线打过地面
（命中 `y = 2`）就填了，结果玩家从那块地方**掉到 `y = -206`** —— **射线命中 ≠ 站得住**
（真实地面在 `y ≈ 4.1`）。后来改成"把玩家放到候选点、等 1.3 秒看它停在哪、`isGrounded` 是不是真"，
才选出 `(0, 3.5, 14)`（离丹房 **16.6 米**，站得住）。见 [踩坑总库 B80](../ai/踩坑总库.md)。

**实测全链路**：洞府 → 黑幕（打完停 **2.18s**）→ `切换场景 Sect` → 落在 `(0.00, 3.50, 14.00)`
且 `grounded=True` → 面板显示「走近丹房 / 宗门炼丹阁 17 米」+ 感叹号 → 走到跟前 → **「拜入太虚宗」全部完成 ✔**。

### 7.2 ❌ 当初缺、后来补上的框架

| # | 缺口 | 做法 |
|---|---|---|
| 1 | **黑幕白字过场**（逐字 + 长按加速 + 居中 + 字号） | 新组件 `黑幕字幕`：全屏黑 Canvas + 居中打字机文本；`左键长按` 提高打字速度；`说(文本[])` / `清空()` / 等 1s 之类做成可被任务动作调用 |

| 3 | **玩家起名 UI**（≤5 汉字、回车确认） | 新组件 `起名界面`（可复用黑幕字幕的画布）；写入 `SaveData.角色名`（已有字段）+ `UIPanelData`/玩家名显示 |
| 4 | **任务调度摄像机** | `任务动作` 新增：`镜头看向(目标/坐标)`、`镜头回玩家`、`镜头移动`（平滑 + 停留 + 可回）；实现放在任务管理器里 |
| 5 | **任务等待/倒计时** | `任务条件` 新增 `等待秒数`（进入阶段即开始计时，到点自动完成）；演出里的"停留 2s / 1s"用同一套 |
| 6 | **任务生成 / 销毁 NPC** | `任务动作` 新增 `生成NPC(npcId, 坐标)`、`处决NPC`（扣完血倒下）、`播动画`（已有）、`攻击玩家`（已有）|
| 7 | **任务驱动 NPC 移动** | `任务动作` 新增 `走向(目标/坐标)`、`飞到(坐标)`（用现有 `NpcAiBase.转向` + 位移；大师兄的"御风前进" = 播该动画 + 位移）|

| 9 | **NPC 专用动画名**（御风前进 / 御风 idle） | 确认这些动作在 NPC 控制器里的状态名（大师兄用的是成男村民控制器，可能没有御风状态） |
| 10 | **跨场景保持状态** | 任务管理器 / 外观 / 背包 / 标记都靠静态字段 + `DontDestroyOnLoad` 活过切场景（见 [任务系统](任务系统.md) 的跨场景一节） |
| 11 | **过场期间锁操作** | 演出/对话/起名期间禁止移动与攻击 —— `演出锁` 统一挡在一个"演出中"标记上 |
