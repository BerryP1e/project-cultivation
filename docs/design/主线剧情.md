## 1. 全局演出规则（对所有过场都适用）

1. **说话方立绘变大，不说话方立绘缩小** —— 对话框里谁在说话，他的立绘放大，另一方的缩小。
2. **黑幕白字全部是逐字打出**（打字机效果），**左键长按可加速**，文字**尽量居中**，字号要合适。
3. 对话选项沿现有系统：回答列表 + `需要标记` 控制"什么时候解锁哪个回答"。

## 2. 第一幕：起名与开场（黑幕白字）

存档创建完成后，先进一段过场黑幕白字（逐字打出）：

```
这是一个漫长的故事
讲述了一个少年如何一步步争渡成仙
那个少年的名字叫做：
```

→ **玩家起名**：回车键确认，**5 个汉字以内**。
→ 等 1 秒，**全黑、字幕清空**。
→ 打出：

```
在古古镇上……
```

→ **场景切换到「古古镇」**，主角出生在「**主角小屋**」前方。
（下文用 `xxx` 代替主角名字）

## 3. 古古镇的清晨

新档与直接运行古古镇都不自带功法。当前第一条任务为 `q_main_001`，共四阶段：主角起床对白「天亮了，出去走走吧。」→ 胖叔叫住「哎，起这么早？过来，胖叔有话跟你说。」→ 玩家走近胖叔交谈，得知小梅在找自己 → 接取 `q_main_002`，前往小梅处。不能跳过胖叔直接出现找小梅的任务。

小梅告知屋后林子有异响，随后引导玩家去查看；野猪触发区仍要求完成 `q_main_002`。

## 4. 第三幕：野猪遭遇战（需要镜头调度）

- 主角来到**主角小屋右侧小树林空地** → 触发剧情：
  1. **生成一只野猪**（`YeZhu`）。
  2. **摄像头平滑移动、对焦野猪**；野猪**暂时不动**，停留 2.2 秒，出生朝向玩家。
  3. **摄像头移回玩家**，停留 2.5 秒。
  4. 跳出**临时对话框（当前 UI 不显示立绘）**，**震动特效**，内容：「啊啊啊是妖怪！救命啊」。
  5. **点击结束对话框后**，野猪和玩家**被释放**，**野猪开始攻击玩家**。
- **倒计时 5 秒后**：
  6. **生成大师兄**，大师兄用动画「**御风前进**」**飞过来**。
  7. 大师兄播放 Attack1，随后出现可见刀光并处决野猪；刀光约 0.06 秒后命中、余光渐隐。
  8. 大师兄在主角旁边用「**御风 idle**」站立，**调用与主角的对话框**：

```
大师兄：真是不好意思，妖魔跑出来了，你受惊了
主角　：仙人救我狗命，请受我一拜
大师兄：哈哈哈，降妖除魔乃吾辈分内之事，等等……
大师兄：你居然有灵根？
大师兄：少年，你叫什么名字？
主角　：回仙人，我叫xxx
大师兄：xxx，你可愿入我太虚宗？
主角　：回仙人，弟子愿意
大师兄：好，给你一时三刻，你处理好凡间事务，我们即刻回宗
大师兄：（自言自语）下山一趟，竟然给我捞到了一个好苗子，又是大功一件啊
```

- 对话结束：**大师兄解锁回答**「仙人，我准备好了」；**小梅解锁回答**「小梅，我要走了」
  （**支线任务**，之后再展开，目前只留引子）。
- **任务目标变为：料理好凡尘之事后和大师兄对话。**

## 5. 第四幕：启程入宗

点「仙人，我准备好了」：

- 大师兄：「你准备好了，那我现在就带你去宗门吧」
- **停留 2 秒**
- 黑幕白字：「从此，一个平凡的少年踏上了修仙路」
- **停留 1 秒**
- **大师兄和主角来到 sect 场景的 `mainteleport` 这个传送点旁边**
- 大师兄（御风 idle）：「这就是我们太虚宗了，你先在此等候，我去禀报师尊」
- 大师兄：「哦对了，这是我们门派的便服，你先穿上吧。」
- **获得道具「门派便服」**（已有：`item_menpai_bianfu`，使用后获得「修仙者」外观）
- 对话结束
- 大师兄（御风前进）：**往前飞到 `environment_Building_luoxiaguan_001_h` 建筑前**。
- **任务目标变为：等候大师兄禀报。**

## 7. 宗门巡览

`q_main_005` 共十阶段，接在 `q_main_004` 之后。

| 阶段 | 内容 | 实际操作要求 |
|---|---|---|
| 1–3 | 前往功德堂、介绍、兑换 | 对白发放 200 贡献；在功德堂成功兑换至少一件，关闭面板 |
| 4–6 | 前往传法阁、介绍、兑换 | 对白再发放 100 贡献；在传法阁成功兑换至少一件，关闭面板 |
| 7–9 | 前往执事阁、介绍、接悬赏 | 接取一级「巡山悬赏·初试锋芒」，关闭面板；其他等级不算 |
| 10 | 大师兄叮嘱 | 逐句对白结束，打上 `q_主线_日常开始` |

贡献不足、错误堂阁交易不算完成；不以背包中已有物品代替本阶段成功交易。首次巡览登场缺少大师兄时，从远处上方生成并飞入，落点避开师父和建筑碰撞体。丹房介绍与传话使用 `StoryCompanionAnchor` 固定原站位，后续引路时解除。

`StoryCompanionGuide` 当前只在目标方向领先玩家几米、停下等候，**尚未实现寻路和绕障**。寻路方案等后续规划确定，本轮不扩展。
