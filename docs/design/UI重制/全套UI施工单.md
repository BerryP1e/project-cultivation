## 3. 两条红线（违反任何一条都算没做完）

**红线 1：不要为了换皮去"重新生成面板 + 保存场景"。**
角色面板等节点是 `CharacterPanelBuilder` 在编辑器里生成、**序列化进 5 个游玩场景**的；
重新生成 + 存场景会把运行时 UI 列表（`Row_*` 的坐标）一起重排 —— **踩坑 A8：一次写脏 +19787 行**。
- **首先考虑运行时换**：由 `场景自举` 补组件（`Assets/Scripts/UI/UIInkSkin.cs` 已经这么做，`UI神通页重排.cs` 是布局那一半）。
- **确实要改生成器**（例如把列表改成卡片网格）：改完必须 `修仙/同步通用角色与UI到所有游玩场景`，
  然后 **`git diff --numstat` 逐个场景核对**，只保留预期改动，多出来的行**一律还原**并在汇报里说明原因。

**红线 2：不许把"没实现的功能"画成能用，不许自己发明玩法/数值/文案。**
未实现的（如法宝/灵阵的实际效果）要在界面上**明确写"待开发"**；数值一律读现有数据，不新增编造的奖励或规则。

### 9.0 为什么动效是硬指标

现在的界面"像贴图"，一半原因就是**没有时间维度**：静态切图不可能有融入感。
动效不是锦上添花，它是**把"贴上去的纸"变成"画在纸上的画"**的那一步。

### 9.1 四个"墨的物理隐喻"（所有动效必须归到这四个里，风格才统一）

| 隐喻 | 用在 | 做法（就是规范） |
|---|---|---|
| **落笔**（出现） | 面板开、卡片/提示出现 | 缩放 `0.96 → 1` + 透明度 `0 → 1`（**绝不从中心弹出**）+ 边缘墨晕由浓转淡；**0.18s** / `EaseOutCubic` |
| **晕开**（强调·选中·装入） | 选页签、装入技能、点按钮的反馈 | 从**点击点**径向扩散一圈淡墨涟漪（最大 1.6×，0.25s）；底色**由中心向外**渐显（radial fill / mask 扩散） |
| **提笔**（离开） | 关闭、取消 | 顺序反过来：**先淡后缩**，比出现**快 0.8×**（0.15s）——提笔比落笔快 |
| **干笔·飞白**（禁用） | 不可用 / 材料不足 | **不是变灰**：降低墨浓度 + 边缘打碎（叠飞白遮罩 α≈0.35），让"纸还在" |

### 9.2 逐元素动效表

| 元素 | 进入 | 悬停 | 按下 / 选中 | 离开 |
|---|---|---|---|---|
| 面板 | **卷轴式**：左边缘固定，宽 `0→1`（0.26s）+ 纸纹横向扫过（0.35s）；**位移必须为 0**（"飞入"最塑料） | — | — | 反向 0.18s |
| 页签 | 交叉淡入 0.18s | 墨浓度 +6% | 选中牌**墨色变浓 + 上浮 2px** | — |
| 列表行 | 逐行错开 30ms 淡入（最多 8 行） | 底墨 +6%、**左侧短笔延长 6px**（0.12s） | 左端短笔成实笔 | — |

### 9.3 时间与曲线常量（**全工程统一，写成一个静态表**）

| 档 | 时长 | 曲线 | 用在哪 |
|---|---|---|---|
| 快 | 0.06–0.12s | `EaseOutQuad` | 按下、悬停 |
| 常 | 0.14–0.22s | **`EaseOutCubic`** | 落笔、晕开、Toast |
| 慢 | 0.26–0.36s | `EaseInOutQuad` | 面板开、演出段落 |
| **禁止** | — | `Back` / `Elastic` / 弹簧 | 会"弹"，与水墨气质冲突 |

**红线**：① 一律 `Time.unscaledDeltaTime`（面板开着时 `timeScale = 0`）；
② **动效期间文字只淡入、不缩放**（缩放会糊）；③ 同时运动的元素 ≤ 6 个；
④ 提供「减少动效」开关（无障碍）。

### 9.4 施工要求（别每个面板各写一套）

动效实现成**一个可复用组件**：`UIInkMotion`（静态方法：`落笔 / 晕开 / 提笔 / 干笔`）+ `UIInkPulse`（挂件，做墨晕脉冲）。
**所有面板调它**。逐面板各写一套 = 每个页面手感都不一样。

### 9.5 动效怎么验

用现成的录像能力（`exec_runtime_script` 的 `record_game_view`，`encodeFps = 5` 出慢放 MP4）录 **6 个必做动作**：
面板开合 / 页签切换 / 卡片悬停 / 拖拽落入槽位 / 数字滚动 / Toast。
判据：**慢放下能看清"落笔—晕开"的层次**；且文字在动效中始终清晰（没糊）。
成品 MP4 放 `cultivation/screenshots/`（不入库）。

## 10. 材质统一：让 UI"吃同一张纸"（**第二阶段**，与 §9 同批）

> ⚠️ 同上：**不要打断第一阶段**。

### 10.1 为什么现在像"贴上去的一块纸"

| 事实 | 后果 |
|---|---|
| 画面的纸纹/调色是**相机后处理**（屏幕空间），而角色面板是 **Overlay Canvas —— 不经过后处理** | 画面有纸纹墨色，UI 是"干净"的，天然分层 |
| UI 素材**自己又带了一层纸纹** | **两层纸尺度不同** ⇒ 一眼假 |
| 素材自带**数字风投影/高光** | 与"墨晕阴影"两种阴影语言混在一起 |

### 10.2 做法（按顺序做，①②一起上才有效）

| # | 做法 | 细节 |
|---|---|---|
| **①** | **UI 纸纹层** | UI Canvas **最上层**加一层全屏 Image，用**同一张** `宣纸纹理_纸纹`，**tiling 与强度跟画面完全一致**（当前：tiling 1、强度 0.18），`Multiply` 混合，总 α 0.10–0.15 |
| **②** | **素材去纹理**（要出图方改） | 面板 / 卡片 / 按钮出一版**素底**：去掉自带纸纹、去掉高光与数字阴影，只留墨线与云纹。**这条不做，① 也白搭** |
| ③ | 让 UI 走后处理（进阶，**先别动**） | 角色面板改 `Screen Space - Camera`，后处理只对 UI 做纸纹/墨色那一半（不做 Bloom/描边）；风险是文字可读性，要分层排除文字层 |

### 10.3 验收

同一个场景、同机位：**开/关 UI 纸纹层各一张截图**，把 UI 区域的纸纹粒度与画面地面/墙面上的纸纹**并排比对**——
**粒度、强度、方向必须看着是同一张纸**。数值证据：两张图在 UI 区域的高频能量（标准差）差值应 < 15%。

### 10.4 与画面的"墨量"对齐（重要）

界面的墨要**比画面淡一档**，不要更重：主色只准用 纸 `#EEE9DC` / 墨 `#303D37` / 玉绿 `#526F5C` / 朱砂 `#9E4E3D` / 哑金 `#9C8355`；
**繁复装饰只留给仪式动作**（破境 / 开炉 / 印章），日常界面走**细墨线 + 四角短皴笔**（见 `提示词-第二轮.md` §3）。
