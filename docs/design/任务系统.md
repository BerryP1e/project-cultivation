# 委托与主线退役边界

更新：2026-10-16。当前保留的是洞府执事阁的交货与宗门野外悬赏，规则与实现见[执事阁与宗门委托](../guides/执事阁与宗门任务.md)。

古古村、宗门主场景、任务管理器、主线开场/教学/追踪/触发区和生成阶段已退出正式工程，任务表不再登记到 DataTableImporter。不要根据历史任务表或旧剧情文档重建这些入口。

通用能力、丹方标记、日常清单、传送落点、角色存档和塔控仍然保留。它们各自负责恢复，不能继续依赖已移除的主线管理器。QuestDatabase 暂作物品 ID 索引，阶段集合为空；历史枚举和序列化字段不代表主线仍在运行。

现用委托由宗门任务纯数据服务、执事阁界面、宗门任务引导和宗门悬赏刷怪协作。塔内击杀不计入野外悬赏。家园交货需要真实物品，悬赏需要本次妖群的真实死亡事件；重复交付不重复领奖。

原阶段链、教学条件和主线演出说明保存在[历史任务系统](当前游戏体系.md)。当前玩法规范见[家园与镇妖阁](家园与镇妖阁.md)。
