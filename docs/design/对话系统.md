# 对话系统

更新：2026-10-16。保留通用 NPC 对话、条件标记、回答跳转和情绪表现；主线运行器、剧情强制对白和师兄/师傅教学流程已退役。旧表中剧情对白仍属历史数据，不会自行启动剧情。

## 数据与交互

对话表.csv → DataTableImporter 定向导入 → Generated/DialogueDefinition → Resources/对话/对话库。字段以[配置表参考](../reference/配置表字段.md)为准。运行时不直接读 CSV。

NpcDialogue 使用 StationInteractable / StationInteractor 的 F 互动与距离检查。DialogueDatabase 按 NPC、分段及当前树查找；树名取 ID 最后一个下划线前的部分，续段不能串入另一棵树。

需要标记必须全部满足，排除标记不能命中。同分段候选按优先值、NPC 专属、带条件、ID 排序。最小分段为入口；回答的跳转为分段号，0 为结束。无回答时提供继续/结束。没有满足条件的入口时不可交互。

## 当前边界

- DialogueUI 保留文字、回答、输入锁及情绪表现；当前对话不显示双方立绘。外观页立绘是另一条资源链路。
- 对话标记还用于丹方学习等通用状态，由 SaveSystem 记录和恢复，不能随主线删除。
- 触发任务/完成任务字段、QuestDefinition 兼容类型仍保留序列化数据；没有任务管理器执行它们。DialogueDatabase 的阶段点名分支现返回空。
- 执事阁委托使用独立的宗门委托系统，不依赖旧对白任务接线。见[委托](../guides/执事阁与宗门任务.md)。

旧剧情点名、教学站位、原 UI 节点与当时排错过程移至[历史快照](../archive/pre-home-20261016/design/对话系统.md)。当前玩法见[家园与镇妖阁](家园与镇妖阁.md)。
