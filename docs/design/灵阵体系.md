# 灵阵体系与浮世万象

更新：2026-10-17。按用户最新多重/打包示意和空间阵效要求重构。与镇妖葫九宫真灵战阵分别管理。

## 入口

传法阁兑换「浮世万象认主符」（120 贡献），使用后在法宝页装备「浮世万象」；P 面板可直接调出学习物品。右键右下角法宝图标编排，关闭后Q进入当前方案引导，左键确认；不再使用E或Alt+E法宝入口。灵阵不占神通 1～6 槽。编排窗口暂停游戏并锁定场景输入，关闭或卸下法宝恢复。

六个方案槽可改名、增删、排序和保存；第五个默认示例改为「正逆分流」。选中打包/多重后添加其子阵，选中普通节点则在它后面添加。保存编排写角色内存，游戏保存时写入存档。

法宝 ID `treasure_spirit_array_talisman`、物品 ID `item_spirit_array_talisman` 保持稳定；更名不影响已认主与已装备引用。配置来源是物品表、法宝表，运行读取生成资产。

## 展开、朝向和执行顺序

| 节点 | 行为 |
| --- | --- |
| 身前布阵 | 后续起点移到身前。阵面法线优先跟随手动引导，其次锁定目标中心，否则人物前方；保留高度角 |
| 目标头顶 | 在锁定目标上方 3.6 米朝下展开；无有效锁定拒绝开始 |
| 顺序打包 | a→b→c 依次执行，沿继承的排列方向展开；嵌套普通打包不重置方向 |
| 逆向打包 | a→b→c 仍依次执行，只反转局部排列方向；阵面法线、灵弹发射方向不反转。嵌套两次逆向恢复正向 |
| 多重施法 | 同时运行所有分支，每支可为单阵、顺序或逆向打包；等待所有分支完整展开后，再执行主序列下一项。允许位于序列末尾 |
| 生成灵弹 | 展开后按延迟发射，8 灵力/枚，初速 27.6 米/秒（原速的 2.3 倍）；其独立“反向发射”选项仍可使用 |
| 追踪 | 穿阵后锁定追踪，参数为每秒最大转向角，最高 360°/秒；3 灵力/枚，无目标不扣 |
| 分裂 | 穿阵后分为 2～5 枚，继承已生效修饰，外倾角控制散射；6 灵力/次 |
| 强化 | 伤害乘倍率，总倍率限制 0.1～8；3 灵力/枚 |
| 加速 | 速度乘倍率，总速度限制 2.3～138 米/秒，随基础速度同比提高；3 灵力/枚 |
| 修正方向 | 把穿阵灵弹调整为当前阵面法线方向；3 灵力/枚 |

原「反向多重」从节点库移除。枚举数值 4 仅作序列兼容，载入编排副本时转换为普通多重；原有数值 0～10 不重排，新逆向打包追加为 11，不能把旧数值 4 改成逆向打包。

多重以主阵法线为轴均匀分布分支，外倾角支持 -75°～75°；0° 时各分支法线平行，非零时每支沿自己的径向外倾。正向包第一节点在主阵前，逆向包第一节点在主阵后；两者的发射方向都朝目标。主序列后续位置按最长分支留出空间，不把并行分支长度相加。打包结束后外层序列恢复外层的排列方向与占位规则。

逆向包若把生成灵弹放在第一项，后面的修饰阵会排列在它身后，该灵弹不会自动倒飞经过它们。需要灵弹穿过同包修饰阵时，可按「加速、强化、生成灵弹」逆向展开，让最后生成的灵弹从远处向前穿阵。这是空间布局的结果，不改变执行顺序。

前摇固定 0.3 秒，默认启动延迟 0.9 秒，可设 0～5 秒。基准阵距保留 0.48 米，再乘当前节点尺寸；不同节点半径与间距相应变化。生成阵尺寸 0.78、强化 1.12、加速 0.86、分裂 1.04、多重 1.5，其余为 1；基础半径 1.15 米。穿阵判定使用同一实际半径。法宝冷却 3 秒。

节点完成功能后在 1 秒内平滑淡出并销毁：生成阵从实际发射后起算，修饰阵从首次成功穿阵附加后起算，多重主仪轨等所有分支完整展开后起算。消散中的修饰阵仍能附加效果，重复触发不延长倒计时；尚未触发的修饰阵保留最多 9 秒，末秒淡出。延迟发射等待期间不提前消散，多重等待也不被普通 9 秒上限截断；死亡、卸下或禁用仍立即清理。

### 节点距离参数

每个节点的参数页可填写“到下一个节点间距”（0～20 米）。未手动改过时，普通仪轨沿用上述随尺寸的默认距离；手动填写后使用输入值，不再乘尺寸。0 可用于重叠仪轨。多重节点的间距控制主阵到各分支入口的轴向偏移；打包节点的间距控制包入口到首个子阵，子阵仍各自控制后续间距。

起手式另有“距角色距离”或“距锁定目标距离”（0～50 米），与下一节点间距分别保存、分别编辑。身前起点从角色施法中心（距地 1.1 米）沿锁定/引导方向偏移；头顶起点从目标位置向上偏移，默认向下展开。两类控制节点默认入口间距为 0，保留原来首阵位置。

例如身前起点 3.2 米、入口间距 0.7 米，首阵在施法中心前方 3.9 米；目标上方起点 6.4 米、向下间距 1.3 米，首阵在目标上方 5.1 米。逆向打包改变排列偏移的正负，不改发射方向。界面说明会提示先定位起点，再偏移首阵，避免把两个距离混为一项。

旧编排不含自定义标记时继续使用旧默认值，不能把缺失字段当成玩家手动设置的零间距。自定义标记和值一起写入角色编排与存档；负数、非有限数及超范围值拒绝保存/施放。参数区可滚动，新增距离项不会覆盖倍率、延迟、倾角或节点操作按钮。

## 表现

节点是组成整套阵列的仪轨部件，不是各自完整的法阵。生成节点用小阵眼与短芒；追踪只有薄轨和游动光点；分裂为三个离散小圈与连线；强化是中央留空的刻线环带；加速是短弧与粒子流；方向修正仅使用空间折线。各自只选用需要的部件，转动/游动节奏不同，组合后形成整体。不能重新给每个节点都叠外环、刻线和中心图案。

生成灵弹时、修饰成功穿阵时触发独立扩张光环、整体亮度变化及符轨加速；灵力不足的触发变红。多重主阵也有独立可见的阵面。使用 Built-in 的 `SpiritArrayGlow`，线条带软边，保留 HDR 颜色，不改全局渲染管线。旧阵纹材质字段保留兼容，但当前阵面不用整图 Quad。

此前的六种中心图案已独立保留在 Assets/Art/SpiritArrays/Centers/，每种包含网格、材质和 prefab，可用于之后确有需要的中心节点；当前不把它们默认塞进全部仪轨。菜单“工具 → 灵阵 → 重建独立中心图案库”可重新生成。

模型来自 `Assets/TripoModels/浮世万象/浮世万象.fbx`。成品将外围拆为 13 个独立部件，中央固定，外围绕各自原位置小幅上下漂浮与摆动；保留原 UV、贴图与全部 8209 个三角面。预览用 unscaledTime，暂停仍展示漂浮；FBX 轴向补偿保留在成品根的子节点，展示页旋转根时不会覆盖。

## 运行与维护

- 原生灵弹完整运动段扫掠，与实体碰撞比较先后；穿阵逐枚扣费，灵力不足不附加、不删弹。分裂继承已穿阵集合，避免同阵重复生效。
- 命中使用 `CombatDamagePipeline` 与来源 `spirit_array`；敌对 NPC 才受伤，墙和地面阻挡。当前生成物为灵弹，未实现普通武器弹或元素转换。
- 每编排最多 64 节点、6 层、8 分支；每角色最多同时 4 套序列、64 阵面、128 灵弹，分裂最多 4 代。死亡、禁用、卸载清理，游戏暂停时施法暂停。
- `SpiritArrayRules` 统一尺寸、耗费和验证；`SpiritArrayCaster` 执行；`SpiritArrayGeometry` 共用几何；`SpiritArrayVisual` 管理节点层次与触发变化；`UIInkSpiritArrayPage` 管理编排输入。
- 默认编排保存在 `Assets/resources/SpiritArrays/array_program_1～6.asset`；节点子阵使用 SerializeReference，JSON 深复制。SaveData v26 保留玩家覆盖和当前选择。
- 成品模型在 `Assets/resources/法宝/浮世万象/浮世万象.prefab`；拆分网格与原生渲染图标在 `Assets/Art/Treasures/WorldsManifest/`。`SpiritArrayArtifactBaker.Bake` 可按原 FBX 重建，保持成品 GUID，不覆盖源文件。菜单：工具 → 法宝 → 重建浮世万象。
- 修改物品/法宝 CSV 后，先 `DataTableImporter.ImportTables(false, new[]{"物品表","法宝表"})` 定向导入，再运行上述法宝重建以补入直接模型与图标引用；不重接或保存场景。
