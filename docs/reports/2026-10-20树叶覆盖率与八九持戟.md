# 树叶覆盖率与八九持戟复核

本轮接续[衣发性能与环境描边实测](2026-10-20衣发性能与环境描边.md)。正式管线仍为 Built-in；没有再次切换 URP，也没有启用 TAA 或镜头抖动。

同日后续更正：本报告的树叶数据保留；八九固定Knight右臂及动作观感结论已撤回，当前实现与验收见[跑步与侧后持戟复核](../guides/八九玄功.md)。

## 树叶

重新使用用户实际透视机位（FOV 40°）检查冷杉群。Stylized Forest 叶片已经有反向共面三角形，旧派生材质再使用 Cull Off 会重复绘制。核查当前调色板16个 Forest 叶槽，反向配对均超过90%；这些材质改为 Cull Back。Far East 粉树不具备这种结构，继续双面，不能全项目统一剔除背面。

新增 `Cultivation/WorldAuthoring/Foliage`：Built-in Forward 有实际 MSAA 时使用 Alpha-to-Coverage，并用屏幕导数平滑覆盖边界；无 MSAA 时退回原 Alpha Clip。Forest 叶纹理增加0.5级 mip 偏移；两个高质量档由2改为4倍 MSAA，低档保持原设置。独立 ShadowCaster 使用原始裁剪并关闭 AlphaToMask，避免覆盖率破坏投影。38个派生叶材质及构建器同步更新，不改源贴图像素。

另修正墨线邻域采样：叶片本身不收墨线，也不再让相邻树干、建筑像素沿每片叶子画黑边。叶片继续遮挡后方墨线；角色描边不启用这个环境专用开关。相关掩码标记写入 ID 图 B 通道。

同一400×800冷杉区域、36帧、平移0.012米/帧与转动0.035度/帧，对比前一提交与本轮最终设置：

| 镜头运动 | 强跳变比例：之前 | 之后 | 降幅 |
| --- | --- | --- | --- |
| 平移 | 4.28% | 2.10% | 50.8% |
| 转动 | 5.39% | 2.88% | 46.6% |

该指标包含正常边缘移动，不能等同于“消灭全部闪烁”。静止帧仍有约0.000009的微小变化；细叶远景的采样残余仍存在。未量测本轮 GPU 帧时，不能宣称4倍 MSAA提升帧率。当前只验证 Built-in，URP分支未做画面验收。

依据：[Unity AlphaToMask](https://docs.unity.com/en-us/engine/6000.7/manual/materials-and-shaders/shaders/writing-custom/shader-writing/sl/writing-shader-render-state-commands/alpha-to-mask)、[Surface Shader keepalpha](https://docs.unity.cn/Manual/surface-shaders-language-reference-optional-directives.html)。实测与截图位于 `.local/diagnostics/tree-flicker-followup-20261020/`，以 `final.json` 为最终对照。

## 八九玄功

旧御风合成把右上臂、前臂、手腕固定成地面参考的世界旋转；身体前倾和转身后，手臂不能正确跟随胸部。旧处理又将腕部动态压到±0.2，只改部分 HumanPose 曲线，导致持握和头部观感不自然。这些是动画重定向问题，外观之间没有额外混合另一境界的动作。

新增离线 `JiubaCarryPoseBaker`：

- 日常持械右肩、上臂、前臂采用用户指定 `Magical-Knight_Set/Animation/Humanoid/move_run_01.fbx` 中段姿态，按目标胸部坐标跟随，包含地面、悬停、八向飞行与闪避。
- 戟的方向与滚转参考杨戬原武器 Bone01。不同 Avatar 的 Chest 骨轴不同，使用双肩、胸、髋构造的人体基准转换，不能直接复制 Chest 四元数。
- 攻击保留原长刀女/杨戬各段动态，用源上臂与前臂方向及武器姿态重定向右臂；没有将攻击统一成静态持械。
- 非攻击头部使用玩家原生 Idle 相对胸部的朝向；攻击保留源动作头部变化。
- 修改后的完整 HumanPose 与 RootT/Q 一起重新编码，保留其余骨骼的实际姿态。只写右臂肌肉或只加 RootQ 会因 Humanoid 身体分解改变而影响未修改部位。
- 重新标定成品武器内层 GripCorrection。外层挂载位置、旋转、缩放不变；源 FBX、源武器网格、材质不变。26个成品动画保留 GUID。没有加入运行时 IK。

验证结果：

| 检查 | 结果 |
| --- | --- |
| 实际 Animator 播放 | 地面/空中攻击、日常持械、八向御风、四闪避共26段、2758帧 |
| 其他骨骼姿态 | Stand及御风前进，各11个未修改骨骼×5相位；最大位置差0.575毫米 |
| 握柄稳定性 | 26段×3相位，整网格PCA轴与四指包握轴偏角≤0.028°；线距离约17.67毫米且跨动作稳定。PCA包含刃部，不能当作手指表面零间隙证明 |
| 实际近战 | 地面四段及御风四段，目标根距离约2.262米，8次真实命中、每段一次伤害事件 |
| 实际外观 | 金丹、元婴、合体，正/侧/背面日常与御风画面；攻击另补8段镜头更新后截图 |
| 源资源 | 重建前后源杨戬与 Knight FBX 哈希一致 |

原杨戬 Attack2 自带快速翻转；逐60Hz对照，其腕部最大帧间转角原114.71°、新120.43°，发生相位一致。不能将所有高速转角都判为新的跳帧，也不能据此保证全部动作没有局部穿插。武器与衣摆没有新增物理碰撞，最终审美与衣物交叠仍需实机观察。

证据位于 `.local/diagnostics/jiuba-pose-20261020/`：`study.json`、`all-actions.json`、`body-regression.json`、`grip-check.json`、`continuity.json`、`contact.json`及`actual-*.png`。完整重建仍使用 `JiubaHandPoseBaker.Rebuild()`。
