# 场景迁移边界与渲染兼容修复

更新：2026-10-16。按用户选择，保留新地图，优先修复与原游戏的兼容性。新建筑包先整理入库，不自动替换现有建筑。

同日工坊收尾修订：恢复 Far East 与新包的原始贴图和色彩，柔化只限最初 Imported 旧建筑。可选库收敛至 475 项，新包仅保留完整建筑／完整组合与自然素材，移除 55 个无引用零件条目。修复高差云海空洞、个人洞府读档、主菜单重复读档、地图保存后自动更新、宗门野外锯齿河岸及桥梁跨水摆放。当前操作方式以 [工坊指南](../guides/运行式场景工坊.md) 为准。

## 场景和地图分别负责什么

| 文件 | 作用 | 是否保留 |
| --- | --- | --- |
| `Assets/Scenes/village.scene`、`3C_Testbed.scene`、`Sect.scene`、`Sect_Wilderness.scene`、`Demon-Suppressing Tower.scene` | 五个游戏场景，装配角色、任务、交互、传送、塔控及地图加载器 | 全部保留，仍是进入游戏的场景 |
| `Assets/Scenes/StartScene.scene`、过渡场景 | 主菜单和原场景切换流程 | 保留 |
| `Assets/WorldAuthoring/RuntimeMapEditor.unity` | 独立运行式地图工坊 | 保留 |
| `maps/source/<地图名>.worldmap.json` | 工坊保存的地图编辑数据 | 可以在加载列表删除；不等于删除游戏场景 |
| `Assets/WorldAuthoring/Scenes/<原场景名>/Map.asset` | 正式游戏实际加载的地图数据 | 正式地图点击保存后，停止工坊自动更新；也可手动重试应用 |

“保存地图”写 JSON，正式地图同时登记自动应用请求；完全停止工坊后自动备份并更新正式资产，解决额外手动应用导致游戏仍加载旧地图的问题。自由新地图不自动覆盖任何正式场景。删除 JSON 不会连带删除正式地图或 `.scene`；当前内存中的地图仍可再次保存，重新产生同名文件。

前一轮迁移确实修改了五个原场景，而非只额外生成五张地图：保留玩法实例、序列化引用和功能锚点，改为由地图数据生成环境外观，移除 2677 个旧树实例及 737 个停用渲染组件。完整迁移前场景和 `.meta` 位于 `.local/backups/scene-migration-20261015-223928/`。这批备份是恢复依据；完整回退还需同时核对地图加载、洞府扩建、功能绑定等脚本，不能只复制场景文件就保证兼容。

## 为什么地图更换会暴露特效问题

地图几何不应负责改写技能表现。实际集成还叠加了工坊与游戏管线不同、环境雾插入位置、相机渲染目标和后期处理差异。之前的 599 项场景检查与 82 项游戏检查主要覆盖地形、碰撞、引用、扩建和功能装配，没有覆盖持续喷射中的逐帧画面。此前以这些检查推断所有特效正常，结论范围过大。

项目原有文档记录了 Built-in 后期、技能表现与素材约束，见 [画面统一调色](../guides/画面统一调色.md)、[战斗命中特效管线](../guides/战斗命中特效管线.md)、[掣电烨霆](../guides/掣电烨霆.md)。问题不是完全没有文档；迁移和验收没有充分遵守这些边界。本报告补充本次跨系统改动及其验证范围。

## 本轮修复

- 日常工坊与正式游戏统一使用 Built-in。URP 资产、导入资源及独立实验入口保留，`WorldEditorPipelineScope.experimentalUrp` 默认关闭；没有把整个项目迁到 URP。
- 共用 `WorldMapLook` 配置，地图加载与工坊使用一致的曝光、调色、Bloom 和室外环境光。保留原方向光朝向，塔内保留原照明；关闭旧宣纸纹理叠加，不再自动加回旧画面基线组件。地图外观转换跳过原生粒子、线和轨迹材质。
- 地图雾移到透明物体之前绘制，避免按不透明地面深度把前方透明技能也盖住；描边遮罩绘制后恢复相机渲染目标。
- 修正 Bloom 金字塔：各层使用对应尺寸的 HDR 缓冲，显式合并两张输入，不再依赖目标缓冲旧内容。相同高亮块在画面中移动的实际 GPU 探针，原来在“零辉光／有辉光”之间跳变；修复后能量随位置变化约 0.33%。这解决闪光不稳定，不能单独据此宣称所有特效已修复。
- 持续龙吐息的马赛克单独复现：冻结相同姿态，仅禁用“热流扭曲”即可消除黑色／彩色像素噪点；龙身、光束、Bloom 和描边的分别排除未得到相同结果。删除该层的命名 GrabPass，改为每个实际渲染相机持有独立颜色缓冲，透明阶段前抓取，匹配尺寸及 HDR 格式；结束或换相机时释放。保持热流折射，并对同一姿态及四喷连续原生帧复测。
- 吐息重复命中的烟层每喷只触发一次并降低透明度，保留命中电弧；太虚远程命中原生灯光从峰值 16、适配后半径约 4 米，收敛到峰值 0.4、半径 1.3 米。没有重写天降技能的粒子缩放曲线、伤害或发射时序。

## 建筑素材与地图管理

最初一轮将新包 84 项全部入库并统一柔化，范围过大，已按用户反馈纠正：55 项无引用零件／整组原始模型从库中移除。保留源包 3 栋完整建筑，从示例中补入完整亭子、门楼及两座桥，再加 26 项自然素材；全库现有 475 项可选项。原 Far East 22 种墙体继续保留，新包零散墙、柱、屋顶等不再显示，也不会在更新时被重新加入。源文件仍作为完整建筑依赖保留；有地图引用的退役条目只保留隐藏引用，不误删已摆物件。

纹理柔化、降对比和饱和度只对最初 `Art/Environment/Imported` 旧建筑启用；Far East 和新亚洲包恢复源颜色、纹理锐度及 UV 缩放。显式读取新包 `_Albedo`、`_AlbedoColor` 与 `_Tiling`，修复白膜；源贴图和第三方素材不覆盖。原旧建筑最终美术仍可由用户选择替换。

维护入口：**修仙 → 场景工坊 → 更新素材库（保留地图）**。完整清单见 [工坊资源完整清单](工坊资源完整清单.csv)。不为每套包创建一次性导入器。

加载面板增加滚动、每张地图的删除按钮和“恢复最近删除”。删除将 JSON 及 `.bak` 移到 `maps/source/.deleted/<时间与唯一标记>/`，恢复时若出现同名文件则拒绝覆盖。本轮没有替用户删除两张试作地图。

## 验证范围与剩余事项

收尾验证额外覆盖完整建筑与源贴图、库删减后的引用、三方向跨水摆桥及实际桥面接岸，共 444 项。真实 GPU 验证底层云海连续覆盖且不盖住前景地面；河岸曲率指标由约 2869 降至 1619，实际湿水覆盖约增加 10.6%，物件和地块轮廓不变。用户当前古古村 856 物件的编辑数据已原样保存，正常停止工坊后正式地图与保存内容字节一致，自动应用队列已确认清空。

高处建筑被雾遮挡另由非居中三色实体 GPU 检查复现：Builtin 云雾的投影矩阵与临时颜色 RT 的翻转混用，重建出了错误射线。现统一 CommandBuffer 屏幕 UV 与投影，不再额外翻转深度；三个不同高度、不同屏幕位置的实体及真实宗门高塔均确认保留遮挡。不能以中心方块通过代替高差场景检查。五场景真实主菜单读档 35 项通过，包含真实暂停保存、重复读档、场景大小写、位置／楼层／朝向、附加场景采集和传送优先。

收尾最终回归：当前用户地图五场景功能与洞府扩建 81 项、墙体与草 13 项、筛选后素材与透明雾合成 64 项通过；两个相关雾着色器编译零错误／警告。测试使用隔离存档，结束核对真实存档哈希一致并撤销隔离；用户编辑会话按开始时的最新内容保留。相关地图修改与旧文件备份见 `.local/backups/map-repair-20261016/`，自动应用前的正式地图版本仍保存在 `.local/backups/map-apply/`。

报告和帧图放 `.local/diagnostics/rendering-repair/`。测试使用工作区隔离存档目录，退出时核对真实存档哈希并撤销隔离配置。
