# 衣发表面计算、树叶采样与环境描边

2026-10-20，Tuanjie 2022.3.61t14，正式游戏和日常工坊仍为 Built-in。本次没有切换渲染管线。此前 10 月 16 日特效收尾统一回 Built-in，并默认关闭工坊的实验 URP 开关；安装了 URP 包不等于当前相机使用 URP。

## 衣发性能

保留现有手工分区、衣型、长发释放、动画和碰撞参数。把原托管逐顶点蒙皮、波动、胶囊接触及法线传递移入 `OutfitSurfaceJob`：逐顶点部分使用 Burst 严格浮点并行任务，接缝平均和法线累积保持原顺序。骨矩阵和九组碰撞变换每步只读取一次，缓冲在换装、重建和销毁时释放，构造失败也释放已分配部分。

同机编辑器、固定时间步、预热 5 次后采样 40 次，单次随动总耗时中位数：

| 着装 | 原实现 | 当前实现 | 下降 |
| --- | ---: | ---: | ---: |
| 筑基 | 37.360 ms | 9.814 ms | 73.7% |
| 金丹对照 | 8.832 ms | 2.787 ms | 68.4% |
| 元婴 | 15.826 ms | 5.032 ms | 68.2% |

各项测得托管分配 0 B/步。表格是隔离 CPU 计算，**不能换算成整场景 FPS**；渲染、Animator、其他游戏逻辑和编辑器开销仍在。与保存的旧方法对照 12 步，三套最大局部顶点差分别为 5.88e-7、1.63e-6、1.55e-6。真实 Animator/LateUpdate 各 390 帧复核 Walk、Sprint、御风前进和 Idle，同点接缝误差为 0，未出现无效坐标；元婴裤靴预览引用自己的骨架。

## 树木和前景遮挡

- 树叶裁剪材质仅按源 alpha 写遮挡，ID 为 0，不再为每片叶子的深度/法线差画墨线。树干保留环境描边。缓存视锥和材质列表，避免每帧重复分配。
- 80 个派生树材质开启 GPU Instancing，生成器同步此规则。同一相机、17 棵树的实际 A/B 总 draw calls 546 → 495，三角形数均为 2,371,543。不是减少树叶或关掉阴影换得的结果。
- 环境掩码改用相机眼空间线性深度，与实际场景深度比较。草等未进入环境掩码的前景也能遮住后方墨线。正交/透视和反向 Z 分别处理；角色描边不启用这项环境开关。
- 树根按接地高度渐淡，范围随树高限制在 0.18～0.65 米，避免底部硬黑边。保留材质、光照和投影，不承诺几何接地自动变得自然。

实际主相机的独立遮挡探针使用后方白方块及前景绿色面，关闭修正时错误黑线像素为 320，启用后为 0；根部渐淡另有开关截图。不是只凭代码推断遮挡已生效。

## 闪动与抗锯齿

18 张叶材质实际引用的源纹理启用 mip alpha 覆盖保持，参考值匹配材质裁剪阈值，并使用三线性过滤和至少 4 倍各向异性过滤。只修改导入配置，原像素不改。单独修改采样，受控移动的亮度二阶帧差从 0.013513 降至 0.010900，改善约 19%，不足以宣称闪动完全解决。

曾接入官方 TAA，但它在此项目的描边/独立后处理链中引入静止帧变化。用户反馈后撤回，**最终实现没有 TAA、投影抖动或时域历史**。普通 PostProcessLayer 的最终通道还会加入随机抖色，因此最终直接调用官方 PostProcessing 3.4.0 的 SMAA 三趟着色器和查表纹理，不创建 PostProcessLayer。

`GameSpatialAntialiasing` 默认 High，排在画面合成末尾，保留原相机 MSAA。它不追加调色、雾、曝光或随机抖色，Overlay UI 不经过抗锯齿。运行相机可用“启用”做同机对照。

同一棵树、同一正交镜头（3.39399）、720×520 区域、32 帧、每帧横移 0.002 米：

| 配置 | 静止帧差 | 移动二阶帧差 |
| --- | ---: | ---: |
| 原采样 | 0 | 0.013513 |
| 新采样、无 SMAA | 0 | 0.010900 |
| 新采样、官方 SMAA | 0 | 0.009168 |

最终相对原采样的指标下降约 32.2%，静止的非预期变化消失。这个指标包含移动边缘的正常变化，只能用于相同镜头对照。密集亚像素叶片仍可能有残余锯齿，不能承诺任意距离完全无闪；Game View 的 0.7 非整数缩放也会影响观察，原生截图与缩放预览应分开看。没有把渲染分辨率翻倍来掩盖开销。

使用的成熟实现见 [Unity 官方抗锯齿说明](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.4/manual/Anti-aliasing.html)。当前环境树根/实际场景深度修正在 Built-in 分支，实验 URP 分支未作为本轮验收对象。
