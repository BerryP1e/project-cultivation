# 浮世万象与仪轨重构

日期：2026-10-17。未 push，未重建或发布 Windows 包。

## 已实现

- 法宝显示名改为浮世万象，学习物品为浮世万象认主符；物品/法宝 ID 保留，CSV 与生成资产已定向同步。右键编排、E 施放、Alt+E 手动引导保留。
- 采用用户导入的浮世万象 FBX、原 UV 和原材质。外围 13 个部件独立漂浮，中央本体及中央饰件固定；全部 8209 个三角面保留。生成模型根独立包装，FBX 轴向补偿保留在子节点，暂停中的展示继续漂浮。
- 节点按仪轨部件构成，不给每个节点重复完整法阵。薄轨、粒子流、刻线环带、离散小圈和空间折线分别承担不同节点表现；触发时有亮度与扩张光环变化。
- 用户指出的中心图案没有丢弃：六套中心网格、材质与 prefab 独立保存在 Assets/Art/SpiritArrays/Centers/，供后续节点复用，当前不默认套在所有节点上。
- 多重支持可编辑的正负倾角，0° 时平行。子阵为嵌套打包时全部展开并等待完成；逆向打包只改变局部排列方向，执行顺序和发射方向保持。嵌套普通打包继承排列方向，修复此前重置为正向的错误。
- 反向多重从节点库移除，旧数值 4 在读取编排副本时转换为普通多重，新逆向打包追加为数值 11。第五默认方案改为正逆分流。主序列为并行分支留位时使用最长分支，避免把它们的长度相加。
- 追加节点独立间距参数，以及身前/头顶起手式独立的角色/目标距离；参数区改为滚动布局。未自定义时保留默认布局，自定义标记与数值一起存档。
- 灵弹速度同比提高到 2.3 倍：初速 27.6 米/秒，加速限制同步变为 2.3～138 米/秒。节点成功完成功能后 1 秒平滑淡出；发射等待实际出弹，多重等待所有分支展开，修饰阵等待成功穿阵，等待期间不会被提前清掉。

- spirit-array-presentation：282 项通过，包含当前仪轨组合、独立中心素材、触发变化、模型三角完整、外围漂浮范围、中央固定及暂停展示。
- spirit-array-save：新枚举 11、嵌套逆向包、负倾角、延迟和发射参数通过真实隔离存档文件往返检查。
- spirit-array-spacing：12 项通过，检查角色/目标距离与入口间距分开计算、普通节点自定距离、逆向排列、多重分支偏移、实际参数页编辑、隔离存档恢复及非法距离拒绝。
