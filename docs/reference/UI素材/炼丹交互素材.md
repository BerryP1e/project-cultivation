# 炼丹交互素材规格与提示词

> **管什么**：丹房独立透明图片、导入规格、实际使用位置和生成提示词。
> **不管什么**：玩法与投料/结算流程见 [炼丹](../../guides/炼丹.md)；通用 UI 接入见 [UI换皮](../../guides/UI换皮.md)。
> **本文件怎么查**：§1 文件与导入；§2 拆件与使用；§3 最终提示词。
> **来源**：用户炼丹原型及“丹方改用竹筒”的要求，内置 imagegen 生成，Unity Play 实测。

## 1. 文件与导入

运行时图片位于 `cultivation/Assets/resources/UI/InkUI/AlchemyInteractive/`。14 张 PNG 保留真实 alpha，Bilinear、无 Mipmap、RGBA32。炉身上限 2048，炉盖和单片竹简上限 1024，药材/卷竹简/丹丸上限 512。单片竹简用 Multiple Sprite 的单个区域，按 alpha > 16 的包围盒裁掉透明侧留白，其余使用 Single Sprite；原始 PNG 保留。导入脚本为 `.dsh/_diag/alchemy-import.cs.txt`，通过编辑期通道运行，不保存场景。原型在 `cultivation/Assets/UIResources/InkUI/Authoring/AlchemyInteractive/prototype.png`。

## 2. 拆件与使用

| 文件 | 使用位置 |
|---|---|
| cauldron-body / cauldron-lid | 中下丹炉的炉身与独立炉盖，抬盖时显示真实开口 |
| recipe-bamboo-roll | 已学丹方列表与未选丹方时的闭合卷竹简，具有竹片与螺旋卷端 |
| recipe-bamboo-slip | 每味药材一片竖排竹简，药材图标和文字独立渲染，逐片展开 |
| recipe-bamboo / recipe-bamboo-tube / recipe-bamboo-tube-open / recipe-bamboo-cap | 第一版来源素材保留，当前界面不再使用 |
| material-item_shenglingcao / material-item_ningluhua / material-item_huichuncao / material-item_qingxinlian / material-item_chiyanzhi | 周围药材、跟手投料图标及炉内位置 |
| pill | 无专属物品图标时的成品丹药图标与成丹弹出；丹方说明不再显示卷竹简图标 |

以上名称对应 `.png`。物品自带图标优先；新药材可使用其 ItemDefinition 图标，或补 `material-<物品id>.png`。材质文字、主辅材数量、按钮、粒子均独立绘制，图片不烘焙文字和槽位。烟气与灵光由 `UIInkAlchemyFX` 动态网格生成，不需要纸面帧序列。旧纸卷轴不接入丹房。

## 3. 最终提示词

### recipe-bamboo-roll

A single tightly ROLLED BAMBOO SLIP BOOK for Chinese xianxia alchemy recipe inventory icon. It is a scroll-shaped bundle made of many distinct narrow bamboo strips bound with two dark teal silk cords; spiral coiled bamboo slips clearly visible from its upper end, small red seal cord tassel on side. NOT a hollow bamboo tube, NOT a paper scroll, no caps. Upright three-quarter view, ivory sage aged bamboo, muted weathered texture, painterly ink wash game illustration and subtle dimensional shadows on the object only. Icon reference is a cylindrical rolled bamboo manuscript with individual strip facets, not a smooth cylinder. Centered entire isolated object, generous transparent margins, no text no symbol no panel no background no haze. True transparent alpha outside object.

### recipe-bamboo-slip

One independent vertical rectangular bamboo manuscript SLIP game UI sprite. A single tall flat aged pale sage ivory bamboo strip, width to height 1:6.5. Subtle irregular worn edges, fine natural vertical bamboo grain, thin dark teal cord crosses horizontally near y=15% and y=87%; these cords will align with adjacent strips when assembled. Broad plain readable inner face for code-rendered vertical Chinese herb information. Do not draw any text, icons, characters, borders or other strips. Painterly Chinese ink wash grounded game prop; restrained depth and dark side edges. Entire single strip centered and fully visible, generous transparent margin. Transparent background, no backdrop, no paper, no tube, no gold ornaments.

使用内置 imagegen，所有调用设置 `transparent_background=true`；炉盖参考炉身；卷竹简与单片竹简为独立新素材。旧竹筒开口与筒盖提示词保留来源记录，不再用于当前布局。每个素材单独生成，以下为实际提示词。
