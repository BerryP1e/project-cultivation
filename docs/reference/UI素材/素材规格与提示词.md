## 0. 通用硬规则（每一张都适用）

1. **必须透明底**：PNG-32 带 alpha 通道，背景**全透明**。
   ⚠️ 不要纸底、不要山水插画、不要投影 —— `screen-studies/skills-assets-v1/` 那 17 张就是**含背景的裁片**，只能当布局参考，不能当 sprite。
2. **不要在图里烘文字**：所有文字（「神通」「装备神通」「1250/1250」）由 Unity 文本层渲染。图上留出空白就行。
3. **九宫格安全区**：凡标注 9-slice 的图，**中央 1/3 必须是可平铺的平面纹理**（素纸/素玉），
   **所有纹样、云纹、端点装饰只能放在四边与四角的安全区内**，否则拉伸时会变形。
4. **四态/三态必须同画布、同构图、同中心**：只有高光、内阴影、明度不同；纹样位置必须像素级一致（否则按钮按下会「跳」）。
5. **不要在图上做明暗渐变**：颜色只用来表达材质（纸 / 玉 / 朱砂 / 哑金）；渐变和阴影由 Unity 端控制的层叠。
6. **命名**：小写 kebab-case，`<部件>-<状态>.png`；按面板分文件夹（同现有按钮包风格）。
7. **交付 2× 尺寸**（高分屏与九宫格缩放都靠它），显示尺寸见规格表。
8. 造型语言统一：**明代宣纸 + 细墨线 + 哑金云纹 + 玉绿/朱砂点缀 + 大量留白**。

**色板（只许用这些）**：纸 `#EEE9DC`｜纸亮 `#F6F1E6`｜正文墨 `#303D37`｜辅助 `#7B8071`｜玉绿 `#526F5C`｜朱砂 `#9E4E3D`｜哑金 `#9C8355`
**用法**：玉绿 = 主行动（装备、修炼、开炉）；朱砂 = 仪式/危险（破境、转修、重生、破境符）；哑金 = 只做边线与纹样。**朱砂不许铺满屏。**

## 4. 生成提示词

### 4.1 统一前缀（每条提示词都贴上）

```
中国水墨仙侠 2D 游戏 UI 部件，明代宣纸质感，细墨线勾边，哑金云纹装饰，
留白为主、色彩克制（纸白 #EEE9DC / 玉绿 #526F5C / 朱砂 #9E4E3D / 哑金 #9C8355），
正面平视、无透视，纯透明背景 PNG（带 alpha 通道），2D UI 资产，高清
```

### 4.2 统一负面词

```
文字, 书法字, 数字, 印章文字, 背景, 山水插画, 场景, 投影, 阴影, 3D 渲染, 照片,
渐变背景, 噪点, 外发光, 水印, 边框超出画布, 多个部件拼在一张图里
```

### 4.3 分组提示词（可直接粘）

**① 父幕布 `panel-sheet.png`**
> 一张正方形的大型宣纸面板，四角有哑金云纹角饰、四边是极细墨线，中央是**完全素净**的宣纸纹理便于九宫格拉伸；左下角可以有一枚极小的朱砂小印但**不带任何文字**。

**② 内板 `panel-inner.png`**
> 比①更淡更薄的一层内衬纸板，四角只有一点云纹收边，中央全素，用于叠在主面板上分区。

**③ 左侧导航条 `nav-rail.png`**
> 竖直长条形导航底板，宣纸质感、上下两端各有一组哑金云纹，中间是素纸（要放 8 个页签）。

**④ 页签三态 `tab-*.png`（三张）**
> 横长条纸签，左端为尖角（像书签切口）、右端平齐并有一点云纹收尾；`normal` 素纸 + 淡墨线；`hover` 纸色略亮、金线提亮；`active` 玉绿描边 + 纸色最亮。**三张必须同尺寸、同纹样位置，只有明度与描边颜色不同**，中央留出写两三个字的空白。

**⑤ 列表行三态 `row-*.png`**
> 横长条极简行底，上下各一条极细墨线，左端有一个很小的哑金菱形标记位；`normal` 素纸、`hover` 略亮、`selected` 玉绿淡染 + 左端标记加亮；**中段必须是纯平面**以便左右拉伸。

**⑥ 六槽环形 `active-ring.png`**
> 一个正圆形的技能环底座：外圈是细哑金云纹环、内圈是墨线环，环上有**六个均匀分布的开口/凹槽**（用于放六个玉符槽），六个开口之间用极细的连线相连；**圆的正中央必须完全透明**（不画任何东西）。

**⑦ 主动槽三态 `slot-*.png`（三张）**

**⑧ 右侧详情板 `panel-detail.png`**
> 竖长形详情面板：上半部有一个**大图展示框**（细墨线 + 四角云纹，内部留空放技能大图），中部留出标题与正文的空白，下半部有一条极细分隔线；整体宣纸质感、左侧为直边（贴着列表）、右侧有云纹边。

**⑨ 品阶牌 `badge-tier-*.png`**
> 小型横牌，两端是如意云头收尾、中央素面留白写两三个字；一版**玉绿**（主动/正面）、一版**朱砂**（危险/仪式）。

**⑩ 滚动条 `scroll-*.png`**
> 细长滑轨（近乎直线 + 两端一点点云纹收口）与一枚小巧的滑块（如意图案），哑金与墨色搭配，极简。

**⑪ 条底与填充 `bar-*.png`**
> `bar-track`：一条凹槽形的细长条底，两端有一点云纹收口，中段纯平面；`bar-fill`：一条**纯色**（纸白或玉绿）细长填充块，上缘可有一条极细高光线，**不要渐变、不要端部纹样**（它会被按百分比裁切）。

**⑫ 丹炉 `furnace-stage.png`**
> 一尊青铜三足丹炉（写意水墨风、哑金与青铜色、炉身有云纹与符文），炉口冒着淡淡白烟；**透明背景**，炉体正前方与两侧留出 5 个空位（1 个大方位 + 4 个小方位）不要遮挡。

**⑮ 图标集 `icon-*.png`**
> 一枚枚独立的仙侠图标，统一造型语言：圆角玉牌/木牌底 + 主题图形（行囊=布囊、功法=书卷、法宝=剑/铃、灵阵=阵盘、战阵=令旗、坐骑=鞍、外观=衣冠、神通=符），哑金细边；**单色或薄彩**，透明底，256×256。

## 5. 我会怎么验收（出图方可以照这个自查）

1. **alpha 边**：图外一圈是透明像素；异形部件的透明区不该是"实心矩形"。
2. **九宫格中段可平铺**：把图按 3×3 切开，只用中段横竖各拉 3 倍，**不出现纹样被切断或接缝**。
3. **四态像素对齐**：`normal/hover/pressed/disabled` 叠在一起差集只在明度/描边。
4. **图里没有文字**（把图放大看没有残留笔画）。
5. **颜色落在色板里**（允许 ±5% 明度偏差）。
6. 交付就是**一张部件一个 PNG**（不要整页合成图、不要图集）。
