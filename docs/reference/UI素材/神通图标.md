# 神通图标

> **管什么**：水炮、锁链、剑阵、邪眼、四种护罩及六门天降/剑幕神通的透明图标、提示词与导入规格。
> **不管什么**：施放和伤害行为见 [主动技能与神通](../../architecture/主动技能与神通.md)；旧神通插画见 [UI换皮](../../guides/UI换皮.md)。
> **本文件怎么查**：1 文件对应｜2 生成与导入｜3 使用与重建。
> **来源**：用户的八种神通需求；图标由内置 imagegen 工具分别生成，未调用外部CLI。

## 2. 生成与导入

单张透明背景、彩墨仙侠、无字无框、主体居中，以64像素识别度为目标。原始PNG保留在上述目录；Unity以Sprite Single导入、最大512、Uncompressed、关闭mipmap、alphaIsTransparency=true，PPU=100。此处是图标，不是UI九宫格底，不能添加border或覆盖原墨底。

逐张完整提示词见 [神通图标-prompts.json](神通图标-prompts.json)。图标同时赋给神通与对应学习玉简；无需新增场景白名单。

## 3. 使用与重建

本批图标和 prefab 已完成导入，原重建器已清理。后续直接维护成品 Sprite、预制体和学习效果引用；CSV 导入保留 Sprite 引用（表无图标列）。
