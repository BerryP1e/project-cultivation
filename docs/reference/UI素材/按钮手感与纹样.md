# 按钮手感与纹样

按用户最新纠正：阴影在物品框外；字体不能因按住改变颜色；分类左右与下缘加强柔化；底纹使用参考生成的云气/传统卷草，不能用程序水波圈应付；外观为圆形。最新追加纠正：关闭玉饰缩小后像十字架且过厚，已撤下，改为轻墨斜叉并明确接入悬停；不再将生成素材本身视作合格。

## 手感依据与本项目参数

检索了 Unity 官方 [uGUI 过渡说明](https://github.com/Unity-Technologies/uGUI/blob/main/com.unity.ugui/Documentation~/script-SelectableTransition.md) 和 [SmoothDamp](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/vector3/smoothdamp)：按钮状态可以立即登记，颜色和位置需要有连续过渡；阻尼可在接近目标时减速，避免机械瞬移。Material 的[运动系统](https://m3.material.io/styles/motion)也说明高阻尼可减少弹跳，并支持中途改变目标。

这些来源没有规定本游戏必须用某个毫秒数。此处自主选择：按下 smoothTime .018秒、释放 .038秒、悬停/选中 .035秒；在常见帧率下快速成形，释放略慢。用 unscaledDeltaTime 并保留当前值/速度，应对暂停、快速连点和移出取消；减少动效时直接到目标。分类最大沉降2.7单位、选中浅沉约.7，文字保持墨色。面板由 CharacterPanelUI 使用0.12秒淡入、0.10秒淡出，反向切换承接当前透明度。
