# 外部素材来源登记

> **管什么**：从外部项目搬进来的**每一条素材**的来源、原始路径、下载地址与 sha256，以及**授权状况**。
> **不管什么**：素材怎么用、怎么接进游戏看 [guides/灵田 §7](../guides/灵田.md)；转换脚本怎么跑看 [tools/参考素材/README.md](../../tools/参考素材/README.md)。
> **本文件怎么查**：授权状况看 §1（**必读**）；来源表看 §2；怎么重新拉一遍看 §3。
> **来源**：由 tools/参考素材/manifest.json 生成 —— 那个文件是抓取时写下的原始记录，本表只是它的可读版。

---

## 1. ⚠️ 授权状况（必读）

素材来自 GitHub 上的公有仓库 **henjicc/yipiantian**（Godot 的江南水乡种田游戏）。

**那个仓库没有 LICENSE** —— GitHub API 返回 "license": null，
它的 Game/legal/ 里只有 **Godot 引擎自己**的版权文件（GODOT_LICENSE.txt / GODOT_COPYRIGHT.txt），
**没有任何针对游戏素材或代码的授权条款**。

按 GitHub 的规则，「公开但没有许可证」= **保留所有权利**。
也就是说：**这批素材目前是在未获授权的情况下使用的。**

**用户 2026-10-01 明确决定：「先不管版权，直接用它的素材」** —— 本文件就是为这个决定留的底：
来源、路径、哈希都记全，将来无论是要**去要授权、加署名，还是整体撤换/删除**，
都能照着这张表一次定位、批量处理。

> 撤换怎么做：把 [tools/参考素材/fetch_and_convert.py](../../tools/参考素材/fetch_and_convert.py) 的 CROPS 换成别的素材源，
> 或直接把 cultivation/Assets/resources/灵田/ 换掉 —— 游戏代码只认「灵植id / 阶段」这个路径约定，
> **换掉模型不需要改一行 C#**（见 [guides/灵田 §9](../guides/灵田.md)）。
