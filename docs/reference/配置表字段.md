## 2. 生成链路（改一处要知道影响哪几层）

```
CSV  ──「修仙/从配置表生成资产」──▶  Generated/<类型名>/<id>.asset
                                        │
                                        │  同一个菜单里自动跟着跑：
                                        │  DialogueDatabaseBuilder.收集()
                                        │  QuestDatabaseBuilder.收集()
                                        ▼
                              Assets/resources/任务/任务库.asset
                              Assets/resources/对话/对话库.asset
                                        │
                                        ▼
                      运行时：QuestDatabase.取() / DialogueDatabase.取()
```

**只有对话库和任务库有 Resources 副本**（因为它们是运行时按 id 频繁查表的）；
其余资产在 `Generated/` 下，运行时靠 Inspector 引用或 `Resources.Load` 各自取。

## 3. 通用规则

- **第一行必须是表头**。导入器按列名映射到字段名（`ApplyRow` + 反射）。
  ⚠️ 往文件开头插数据行会把表头挤下去 → 整张表读不出来（踩过）。
- **id 列**：`FindIdField(Type)` 找名为 `id` / `<类型>id` 的字段；找不到就用第 0 列。
  生成资产的文件名 = `Sanitize(id)`。
- **导入器只写非空值**（`if (!string.IsNullOrEmpty(val)) SetFieldValue(...)`）。
  → **让某字段变空时，必须先删掉对应生成资产再重导**，否则旧值残留（踩过，见 `AI/踩坑`)。
- **属性列**：`TableSpec.AttrField` / `AttrSuffixes` 指定。例如 `功法表` 的
  `每级增益` + 后缀 `增益`，`被动神通表` 的 `增益`。属性列会写进
  `AttributeSet` 里的对应字段（按名字匹配）。
- **小数会被截断**：`阶段`、`分段` 这类 int 字段填 `11.5` 会变成 `11`，
  和原行**撞号** → 只会取到一行。**要用整数重编号，不能用小数插队**（踩过）。

## 4. 重点表：任务表（`任务表.csv`，33 列）

| 列 | 字段 | 说明 |
|---|---|---|
| `id` | `id` | 行唯一 id（惯例 `任务id_阶段`，但**匹配靠 `任务id` + `阶段`，不靠这个**） |
| `任务id` | `任务id` | 同一串阶段共用一个 |
| `任务名` | `任务名` | 面板显示 |
| `类型` | `类型` | `主线 / 支线 / 悬赏` |
| `阶段` | `阶段` | **int**，升序推进 |
| `阶段名` | `阶段名` | 面板显示 |
| `说明` | `说明` | 任务面板的说明文本 |
| `条件` | `条件` | 见 [design/主线-任务与对话](../design/主线-任务与对话.md) 第 3.1 |
| `物品id` `数量` | | `条件=提交物品` 用 |
| `目标npcId` | `目标npcId` | `条件=击杀`、`条件=NPC到位`、NPC 动作的目标 |
| `坐标X/Y/Z` | `坐标X/Y/Z` | `条件=到达`、`移动玩家`、`飞到`、`生成NPC` 用 |
| `到达半径` | `到达半径` | `条件=到达` 用 |
| `对话id` | `对话id` | `条件=对话` 用（**必须是入口段或可达段**） |
| `接取加标记` `完成加标记` | | 分号分隔，写进 `对话标记` |
| `奖励物品` | `奖励物品` | 写法 `物品id:数量|物品id:数量` |
| `动作` | `动作` | 见 [design/主线-任务与对话](../design/主线-任务与对话.md) 第 3.2 |
| `动作目标npcId` | `动作目标npcId` | NPC 类动作的目标 |
| `动作参数` | `动作参数` | 状态名 / 预制体路径 / 任务id，随动作而定 |
| `自动接取` | `自动接取` | 1 = `任务管理器.Start()` 时扫描全表自动接 |
| `前置任务id` | `前置任务id` | 未完成则接不了 |
| `等待秒` | `等待秒` | `条件=等待秒数` 的时长；`黑幕字幕` 时=打完后再停留多久 |
| `动作速度` | `动作速度` | `走向` / `飞到` 的米/秒（默认 3.5，飞太慢会把节奏拖住） |
| `镜头时长` `镜头高度` | | `镜头看目标` / `镜头回玩家` 用 |
| `台词` | `台词` | `黑幕字幕` / `播放对话` 的文本；多行用 `|` 分隔 |
| `说话人` `情绪` `情绪强度` | | `播放对话` 用 |
| `场景名` | `场景名` | `切换场景` 的目标场景（要加进 Build Settings） |

### 任务表的两个"隐性约束"

1. **`条件=无` 会在下一帧就完成** → 一个阶段只能挂**一个**动作。
   要串多个演出就得拆成多行（四幕因此拆到 16 个阶段）。
2. **同一 `任务id` 下不能有两个相同 `阶段` 号** → `取阶段` 按 `(任务id, 阶段)` 取第一条，
   后一条永远读不到。

## 5. 重点表：对话表（`对话表.csv`，20 列）

| 列 | 字段 | 说明 |
|---|---|---|
| `id` | `id` | 段唯一 id（**任务表 `对话id` 填的就是它**） |
| `npcId` | `npcId` | 空 = 通用段（任何 NPC 都能说），`候选()` 排序时通用优先级更低 |
| `分段` | `分段` | **int**。同一个 NPC 的段靠它区分；**入口 = 最小分段** |
| `说话人` | `说话人` | 空 = NPC 自己说；写名字则比对 NPC 名字，不等就当玩家说（影响立绘缩放） |
| `文本` | `文本` | 正文 |
| `立绘` `玩家立绘` | | 资源名，走 `Resources.Load<Sprite>("立绘/…")` |
| `回答1/2/3` | | 空 = 没有回答（UI 会给一个「继续 ▸」或「结束」） |
| `跳转1/2/3` | | 0 = 关掉对话；>0 = 跳到该分段。**没有跳转链就到不了后面的段** |
| `需要标记` `排除标记` | | 分号分隔，决定这一段现在出不出现 |
| `优先` | `优先` | **同段位多条时大的赢**，平手才看别的规则 |
| `情绪` `情绪强度` | | 演出用 |
| `触发任务` | `触发任务` | 按下回答时执行（**目前表里都是空**） |
| `完成任务` | `完成任务` | 按下回答时 `完成当前阶段(<任务id>)` —— 填的是**任务id**，不是阶段id |

> ⚠️ `完成任务` 走的是 `任务管理器.处理对话绑定` →
> `完成当前阶段(任务id)`，它推进的是**该任务当前的阶段**。
> 所以填任务id即可，不用写阶段号。

## 7. 加一列 / 加一张表的步骤

### 加一列到已有表
1. 在目标 `ScriptableObject` 类里加 `public` 字段（字段名 = 列名）
2. CSV 表头加同名列，各行填值
3. 跑 `修仙/从配置表生成资产`
4. 如果这一列是**派生逻辑**（不是简单赋值），在导入器里加专门处理
   （参照 `物品效果导入` 的做法：放在 `ApplyRow` 之后显式处理）

### 加一张新表
1. 写目标 `ScriptableObject` 类
2. 在 `DataTableImporter.Specs` 里加一行 `new TableSpec("新表", typeof(新类型), null)`
3. 建 `Assets/Data/Tables/新表.csv`
4. 若运行时需要按 id 查 → 参照 `QuestDatabaseBuilder` 写一个"收集到 Resources"的步骤，
   并在 `ImportAll()` 里调用
5. 跑 `修仙/从配置表生成资产`，`修仙/检查配置表是否已同步` 复查

## 8. 常用编辑器菜单

| 菜单 | 用途 |
|---|---|
| `修仙/从配置表生成资产` | **主力**：CSV → 资产（并自动收集任务库/对话库） |
| `修仙/检查配置表是否已同步` | 校验哪些表的 CSV 比资产新（**只读**） |
| `修仙/主线/触发区一览（当前场景 / 全部场景）` | 触发区列表 + 体检 |
| `修仙/物品/…` | 见 [design/物品系统](../design/物品系统.md)（现为 `修仙/调试/…`） |
| `修仙/构建角色面板 UI` | ⚠️ 会**重建 CharacterUI 层级**，删掉挂在上面的其它组件（如 `跨场景数据`） |
| `修仙/外观/*` | 外观表生成、资产收集 |
| `修仙/任务/收集任务资产` | 单独重跑任务库收集 |
