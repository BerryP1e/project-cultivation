## 关联规则

灵阵当前直接配置 Assets/resources/SpiritArrays/ 六个 SpiritArrayDefinition，不新增未接线的 CSV；玩家设置保存到 SaveData.灵阵编排。节点和固定参数见[灵阵体系](../design/灵阵体系.md)。

- 物品 ID 保持稳定。练气着装沿用 item_menpai_bianfu / app_player；建筑令指向现有摆放物定义，镇妖阁认主令指向法宝定义。
- 外观表保留字段名“境界解锁等级”，当前含义是赠物门槛：筑基 11、金丹 31 级各赠送对应学外观物品一次；使用物品后才永久解锁并换上。0 不按境界赠物。衣服/长发成品由外观预处理引用，半身立绘按外观 ID 加载。
- 宗门委托使用 resources/宗门/宗门任务.json，工坊地图与塔层/灵丹等专用数据各用原有资源入口，不据本表清单推断它们不存在。
- 属性后缀与字段转换以 DataTableImporter 及物品效果导入代码为准。导入后跑表同步检查及对应运行验收。
- QuestDatabase 当前保留物品 ID 索引，任务阶段列表为空。通用对话标记仍供丹方等现用功能保存恢复。

历史任务表和旧字段语义见[历史字段参考](../archive/pre-home-20261016/reference/配置表字段.md)，当前流程见[存档系统](../design/存档系统.md)。
