## 物品效果和跨表引用

物品表的效果类型决定物品使用效果派生类，效果参数id引用对应功法/武器/神通/法宝/坐骑等定义；说明文案不是业务代码。获得武器使用“获得武器”，参数为武器id；已拥有不能重复获得。学习物品与实际拥有记录分开，导入不会给玩家发奖励。

导入后检查生成定义、物品效果直接引用、PanelDatabase及物品ID索引。导入器按第一条id字段匹配；新增定义应保持稳定ID。淘汰表行后还需明确清理旧生成定义，不能让仅剩旧资产的内容继续进入目录。
