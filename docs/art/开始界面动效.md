# 争渡开始界面

> **管什么**：动态开始界面的构图、图层、交互与素材入口。
> **不管什么**：存档数据与读写流程见[存档系统](../design/存档系统.md)。
> **本文件怎么查**：构图 → 动效 → 存档轮盘 → 素材 → 验证。
> **来源**：StartScene、MainMenuPresentation、MainMenuSaveCarousel 与 MenuAtmosphere.shader。

入口场景：`cultivation/Assets/Scenes/StartScene.scene`。`MainMenuUI.Awake` 接入独立表现层，不需要重新生成整个场景。

最终构图保留外围树林、边缘云雾、石阶和木桩，只有中央山景、远景云海和瀑布挖空，后方使用深青黑渐变底。按反馈取消飞剑；原始 `begin_ui.png` 保留作参考，不再参与开始界面绘制。

动态层从后到前：外围框景、漩涡、远阵法、近阵法、流动灵气、汇聚粒子、风动背影人物。漩涡直径 950，近阵法直径 1080，近阵法压在漩涡边缘上。两层阵法以不同方向和速率缓转。法阵素材使用断墨、纸纹和淡灰绿的晕染，去掉金黄与荧光；漩涡使用带噪声和墨色浓淡变化的灰绿墨气。人物通过分区 UV 风动表现衣摆、袖口和头发，下端脚部保持稳定。

左侧标题采用独立「争渡」透明书法素材，四个按钮使用独立动态墨底，命中范围不随图形运动。按钮列中心下移至设计坐标 (215, 410)。所有动画使用非缩放时间。

存档栏位于漩涡中央。滚轮、拖拽、方向键或点击条目切换选中槽位；停止后吸附到中心，上下条目缩小淡化。确认按钮执行原有新建或读档流程，已有存档保留角色名、境界、时间和二次确认删除。关闭按钮和 Esc 返回纯漩涡状态。

`InkUIRuntimeSkin` 跳过本界面，避免重新添加旧式底板和滚动条。存档路径、数据格式和原有存档操作保持原样，没有新增恢复或迁移逻辑。

素材采用内置 image_gen 生成，最终透明素材位于 `cultivation/Assets/resources/UI/MainMenu/Animated/`；提示词记录在 [main-menu-prompts.json](main-menu-prompts.json)。漩涡、灵气、按钮形变与风动使用 `MenuAtmosphere.shader`，粒子由单个 UI 网格绘制。

验证：在 StartScene Play 中检查构图与层级；五槽位反复开关不重复；滚轮选中第三槽位后吸附 y≈256；第五槽位 y≈512 且不越界；点击条目不切场景；关闭返回正常；暂停 Time.timeScale 时阵法和风动时钟继续推进。验证未写入、删除或载入玩家存档。
