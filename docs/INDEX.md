# 项目文档入口

更新：2026-10-16。当前版本以洞府生产、挂机修炼、宗门野外悬赏和镇妖阁战斗为核心。古古村、宗门主场景与主线运行器已退役。先读[当前玩法](design/家园与镇妖阁.md)，不要根据历史制作记录重建已取消的内容。

## 先查事实

- Unity 工程位于 cultivation/；3C_Testbed 是正式个人洞府，独立地图编辑器是 WorldAuthoring/RuntimeMapEditor.unity。
- 正式游戏与日常工坊使用 Built-in。URP 包、ASP 及试验资产已导入，尚未全项目切换 URP。
- 当前角色存档 v24，从主菜单新建角色验证；旧 RPG 存档文件保留，菜单提示另建角色。
- CSV 是配置来源，运行读取生成资产。修改后定向导入；CS、CSV 使用 UTF-8 BOM。
- 不覆盖用户地图，不把测试存档写入正式目录，不批量重序列化全工程。用户明确要求时再提交推送。

design 写当前规则；architecture 写当前实现关系；guides 写实际操作；reference 记录字段与素材；reports 保存有日期的实测证据。修改系统时同步相应主题文档和本索引，避免在每份文档顶部不断堆叠相互矛盾的版本通告。
