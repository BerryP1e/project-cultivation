# UI 当前结构与维护入口

更新：2026-10-16。UI 仍使用 uGUI，基础场景节点与运行时皮肤/子页控制器配合。早期逐行尺寸盘点已移至[历史快照](../design/当前游戏体系.md)，其中五场景、主线追踪和旧行号不再是当前事实。

## 装配

- StartScene 的 MenuCanvas 接 MainMenuPresentation，处理起名、选档和旧版本提示。
- 洞府、宗门野外、镇妖阁保留 CharacterUI / HudCanvas；UICanvasBoot 开启序列化 Canvas，场景自举处理层级与引用。
- UIInkSkin 接入父导航、幕布、背包、境界、神通、战阵等运行时子页。不要只按基础生成器的旧锚点重建已换皮页面。
- 炼丹、灵田、功德堂、传法阁、执事阁继续使用各自业务面板。五种设施通过家园摆放物的原生 Station 交互打开；炼器仍为占位。
- 主线追踪、剧情开场与村庄任务 UI 已退出运行。执事阁委托使用独立追踪 HUD。
- 外观/神通/法则预览使用隔离模型与相机。带随动的外观必须复制并重新绑定自己的骨链，不能引用玩家的 Transform。
