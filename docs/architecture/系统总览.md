# 系统总览

更新：2026-10-16。当前玩法规范见[家园与镇妖阁](../design/家园与镇妖阁.md)。

## 工程与场景

团结 Tuanjie 2022.3.61t14，Linear 色彩空间，正式游戏与日常工坊均用 Built-in。URP 依赖和第三方 asmdef 已存在；项目自有逻辑主要位于 Assembly-CSharp / Assembly-CSharp-Editor。UI 主要使用 uGUI Text 与 SimHei。

| 场景 | 职责 |
| --- | --- |
| StartScene | 角色存档选择、新建和进入游戏 |
| 3C_Testbed | 正式个人洞府，修炼、生产、建筑令与通往野外的传送阵 |
| Sect_Wilderness | 野外地图和执事阁悬赏的原生刷怪区域 |
| Demon-Suppressing Tower | 镇妖阁内部，原塔控、层表、刷怪及清层入口 |
| WorldAuthoring/RuntimeMapEditor.unity | 独立运行式地图编辑器，不是 3C_Testbed 的子场景 |

古古村 village 与宗门 Sect 的游戏场景、主线组件及正式地图已退役。WorldAuthoring/Scenes/Sect、village 下仍被使用的 Visuals 是可复用美术，不代表旧关卡仍在运行。过场使用黑幕组件；当前构建入口不依赖旧过场场景。

## 运行装配与数据

- 场景自举补齐通用角色、相机、UI 及运行服务；SaveApplier 在玩家上独立负责每局一次的存档恢复和传送落点。
- 普通场景转换由黑幕、Teleporter、跨场景数据接力完成，不重复应用旧存档。镇妖阁法宝额外保存洞府施放位置与朝向。
- WorldMapLoader / WorldMapRenderer 从正式 Map.asset 生成地形、草、水、云雾和物件；地图编辑结果与角色存档分开管理。
- HomeWorld 在当前洞府地图上重放拓境地块，连接相邻地块并重建包边与碰撞；摆放校验保留地形、物件和水岸约束。
- 建筑令沿用摆放物定义、物品使用效果、灵田摆放器和摆设状态；没有另建第二套家园保存格式。
- 原 QuestDatabase 当前作为物品 ID 索引，任务阶段集合为空。宗门任务是独立委托服务，继续保留交货和野外悬赏。

## 现用系统

| 模块 | 入口与职责 |
| --- | --- |
| 修炼与境界 | PlayerCultivation、功法、破境、时间管理器和日常循环 |
| 家园生产 | 灵田、傀儡基站、仓库、兽栏、堆肥和自动炼丹；设施通过 F 交互 |
| 炼丹与兑换 | 原炼丹界面；功德堂/传法阁按物品目录和贡献交易；执事阁独立记录委托 |
| 镇妖阁 | TowerRealmTreasure 接 E 键法宝槽，TowerController / TowerProgress 继续管理原塔内流程 |
| 战斗与特效 | 既有伤害、神通、普攻、命中特效、顿帧及飘字管线；保留原生粒子层 |
| 行游 | 御风、坐骑、闪避、空间腾挪和 Tab 轮盘；已退役的主线目标不再提供导航 |
| 法则与装备 | 现有法则、法宝、战阵、真灵与角色面板继续使用 |
| 外观 | 玩家外观保持人体 Animator；指定衣服使用预处理蒙皮和追加骨链，原村民继续原绑定方式 |
| 画面 | GameGlobalBloom、GameGlobalGrade、GameGlobalOutline 与地图雾；旧宣纸叠加保持停用 |

通用装配同步工具只面向当前三个游玩场景。不要运行旧村庄/宗门构建器恢复已删除内容，也不要用同名对象或源建筑命名推断交互功能。
