## 定稿动画的依赖

灵虚剑决、太虚剑决的成品 `.anim` 已包含 Humanoid 肌肉、根补偿、腕指和武器运动曲线，独立武器也已提取网格、材质、UV。运行时只需要成品、玩家实际 Avatar 和武器资源，不需要法师、锦衣卫的原 FBX。这轮删除原模型及 `LingxuSwordAssets`、`TaixuSwordAssets`、源姿态对照工具；测试获取秘籍菜单由 `FinalizedGongfaTools` 保留。后续直接维护成品，现有姿态不重新烘焙。

太初龙栖诀 A2 和 Guard03 玩家动作为独立 Humanoid 成品；伴龙八套 Generic 动画、对应 Avatar 和蒙皮网格也已提取到 `Art/Characters/DragonPriest`。只移除未显示人物等无用动画轨道，保留龙骨骼、祖先节点、源髋骨校准与召唤节点曲线；保留原蒙皮权重、绑定姿态、材质/贴图 GUID。A1/A2 网格仍可读，其余龙网格保持 GPU 专用。精简 prefab、合批冰晶模板和配置仍归 `resources/Weapons/TaichuDragon`，现有成品 GUID 不变。

2026-10-11 用户确认动作定稿后，移除原22个 FBX、来源目录和 `TaichuDragonAssets` 重建器。八套原生动画/网格/Avatar采用紧凑二进制资产，避免逐帧曲线转换为文本后体积膨胀；项目默认序列化策略不变。后续直接维护成品和配置，不再把原模型导回 Resources 或重烘已确认的玩家动作。

这不等于所有动画 FBX 都可删：直接播放 FBX 内 AnimationClip、使用模型 Avatar、或当前工具仍从中取样的资源需要保留。玩家的手腕和手指记录在实际玩家骨架、Avatar 与成品曲线中，旧 `Assets/Avatar` 是角色特效资产，使用部分已经归入共享 VFX。

## 清理与新增

以正式场景、prefab、生成数据、编辑器工具和动态 Resources 路径为入口，使用 AssetDatabase.GetDependencies 递归检查；另查 Shader.Find、字符串拼接路径及 C# 类型依赖。先确认引用闭包，再删除未使用内容。团结部分 .meta GUID 是加密字符串，不能只用 32 位十六进制正则判定是否使用。

2026-10-11 补充：NPC 的弹道路径由前缀、子目录、主题三段拼接，旧审查漏判后误删了七个主题。实际使用的完整路径登记在 `devtools/maintenance/runtime-resource-roots.json`，资产审查必须把这些资源作为递归闭包入口，缺失任何入口即终止审查；新增主题须同步登记。已恢复21个弹道/闪光/命中 prefab及依赖，共148项资产约41.2 MiB，材质/贴图/网格/Shader仍归共享目录，没有恢复整包样例。

默认保留原材质参数、贴图通道、Shader 名称、粒子速度和时长。专项表现调整放在对应运行实例层，例如雷云/千劫雷狱落雷10倍速，不修改共享源 prefab。共享管理以迁移位置为主，不把不同视觉用途的材质强行合并。新增第三方素材先选实际使用的 prefab，再导入其依赖；不把整包 demo、样例场景和未用变体放进运行库。

已清除 `.dsh`、`somenews`、旧 `tools` 灵田转换管线、`ui-rework-2026-10-03`、旧 screenshots、立绘目录。可用 UI 制作稿/提示词已归入 Art/UI 和 docs/reference/UI素材，灵田只保留已转换成品和简明来源说明。

验证迁移需要编译、动态加载、场景依赖与实际攻击回归。粒子 Renderer 的空主材质或空 Trail 槽可能是刻意配置，应检查序列化引用而不是把每个 null 槽当作丢失；未启用 trails 的第二材质槽不参与显示。`箭矢_Object135` 原有材质引用失效已于2026-10-11修复，复用玄蜂原模型材质。NPC九类实际配置的弹道发射、飞行粒子/网格、直线接触及躲避回归见 `devtools/validation/npc-projectile-resources.cs.txt`。

比较清理前提交 `9d3a63ee` 与整理提交 `c62b3894` 的 `git ls-tree -rl`：跟踪的 Assets 从3764.79 MiB降至3110.80 MiB，减少653.99 MiB；截图、下载包等原本未跟踪的删除内容另计。该提交新增424个可达对象，本机对应松散对象约17.13 MiB。另有15个遗留 Git 临时对象约116.48 MiB，属于本机垃圾文件，不是现行资产。没有清理前全目录快照，不据此推断精确的缓存净增长量。

减小本机体积应分别处理过期构建/备份和可再生成缓存；清理 Library 需要先关闭编辑器，重开将重新导入。不得为了减少体积删除 `.git`、改写项目历史或移除实际依赖。本次仅审查占用，未删除编辑器正在使用的缓存或现有发布包。
