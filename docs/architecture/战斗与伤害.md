## 1. 伤害计算：唯一入口

`Assets/Scripts/Combat/CombatCalculator.cs`。**任何普攻/神通都调用这里，不要各自实现一份。**
一次攻击由两个**正交**的轴描述（`Assets/Scripts/Combat/AttackSpec.cs`）：

| 轴 | 取值 | 决定什么 |
|---|---|---|
| 伤害属性 `DamageNature` | 物理 / 特殊 | 物理必中且走**暴击**；特殊走闪避与**会心** |
| 攻击类别 `AttackKind` | 普通攻击 / 主动神通 / 被动神通 | 分别使用普攻、主动法术、被动法术的加成/减免 |

两轴组合出六种攻击。小剑阵由主动键施放，但用户指定其伤害走特殊＋被动神通；邪眼同样走被动来源。

```csharp
var r = CombatCalculator.Resolve(攻击方, 受击方, AttackSpec.特殊主动神通);
```

旧接口等价：`ResolveBasicAttack(a,d)` == `Resolve(a,d,AttackSpec.物理普通攻击)`，`default(AttackSpec)` 就是物理普通攻击。
> **特殊 ≠ 远程。** 归类由调用方显式传 `AttackSpec` 决定，**不要用「有没有子弹」去推断**。

## 2. 三步公式

**第一步 · 命中**（按伤害属性区分）
```
物理：命中率100%，闪避率0，不进行闪避掷骰。
特殊：闪避率 = clamp(闪避 / (闪避 + max(0,忽视闪避) + max(0,闪避基准)), 0, 闪避上限)
  闪避率 ≤ 0 → 必中；否则 Random.value >= 闪避率才命中。
  特殊攻击显式开启必定命中时也跳过闪避。
```

物理必中规则统一覆盖玩家与NPC的物理普攻、主动和被动神通，包含八九玄功、青山剑法宝；`default(AttackSpec)`同样必中。暴击、伤害倍率及减免仍按原规则结算。必中指进入伤害结算后不被属性闪避，不取消武器求交、攻击范围、目标存活等出手条件。

**第二步 · 加成判定**（按「伤害属性」二选一，互斥）
```
物理 → 免暴率   = (受击方暴击抗性 − 攻击方暴击)   / 受击方暴击抗性
特殊 → 免会心率 = (受击方会心抗性 − 攻击方会心)   / 受击方会心抗性
  ≤ 0 → 必定触发；> 0 → Random.value >= 该概率 才触发（抗性为 0 时也视为必定触发）
加成倍率 = 触发 ? (物理 ? 攻击方暴击伤害 : 攻击方会心伤害) : 1
```

**特殊攻击不经过暴击判定，也完全不吃暴击属性/暴击伤害；物理攻击反之不吃会心系。**

**第三步 · 伤害**（按「攻击类别」三选一）
```
普通攻击 → 攻击方攻击 × (1 + 攻击方普攻伤害加成     − 受击方普攻伤害减免)     × 加成倍率
主动神通 → 攻击方攻击 × (1 + 攻击方主动法术伤害加成 − 受击方主动法术伤害减免) × 加成倍率
被动神通 → 攻击方攻击 × (1 + 攻击方被动法术伤害加成 − 受击方被动法术伤害减免) × 加成倍率
```

**主动神通不吃普攻伤害加成，也不受对方普攻伤害减免影响。** 减免堆到 100% 以上按 0 倍处理，不倒扣血。

## 3. 扣血路径与属性消费

玩家受击由 `PlayerVitals.受到伤害(amount, DamageNature)` 扣当前气血。AI 与玩家目标适配器先按公式结算，再带原伤害属性交给此入口。无敌、死亡和零伤害先过滤，然后处理[四种护罩](../guides/防护罩.md)：主动四御的剩余免伤优先，其次由唯一开启且有灵气的减伤护罩过滤，最后扣血。一次未命中不能消耗棱柱。

`飞剑 QingshanSwordTreasure.执行穿体结算()` → `NpcInstance.ReceiveAttack(attacker, spec)` → `CombatCalculator.Resolve(...)` → `NpcInstance.TakeDamage(伤害, alreadyMitigated: true)`。
出手节奏：`实际穿体间隔 = 0.15s ÷ 攻速系数`（`QingshanSwordTreasure.cs`）。

- **`防御` 是死代码**：`NpcInstance.TakeDamage(amount, alreadyMitigated: false)` 里有一层 `amount − 防御`，但**唯一调用方传的是 `true`** → 防御完全不参与结算。按现在的数值一旦接回减法模型：长老防御 90 > 玩家暴击伤害 63，`Max(0, …)` 会打成 **0 伤害**。接防御得先定模型（减法 / 百分比 / `攻击 × 攻击/(攻击+防御)`）。
- **玩家没有受伤入口**：`PlayerVitals` 只有扣灵气，气血只能被回满 / 存档恢复改写。
- `NpcInstance.Damaged/Died/Revived`、`QingshanSwordTreasure.OnHitLanded` **零订阅者**（飘字 / 音效 / 挨打扣好感都还没接）。血条不受影响 —— `NpcIndicator` 每帧轮询 `HealthPercent`。
- 会被读取的属性：攻击、暴击、暴击抗性、暴击伤害、**会心、会心抗性、会心伤害**、闪避、忽视闪避、普攻加成、普攻减免、**主动法术加成、主动法术减免**、攻速。
- **只被赋值、从不被读取的**：防御、真实 / 真实抗性 / 真实伤害、冷却缩减、治疗加成、被动法术伤害加成 / 减免。

## 4. 【重要】免暴率 / 免会心率是「反转」的

公式分母是**受击方的抗性**，所以不是「暴击越高越容易暴」，而是：

> **攻击方暴击 ≥ 受击方暴击抗性 → 免暴率 ≤ 0 → 必定暴击。**

当前数值下影响**非常大**（对 NPC 表 111 行实测）：玩家暴击 0.15 vs NPC 暴击抗性 → **104/111 行（93.7%）必定暴击**（只有 7 行是概率暴击）；玩家会心 0.10 vs NPC 会心抗性 → **85/111 行（76.6%）必定会心**。

NPC 表抗性大多填在 0.02 ~ 0.16（还有 1 行 0.5 的木桩），玩家的暴击/会心正好压在上面。**要改成"按概率"**，公式得换成 `实际暴击率 = 攻击方暴击 − 受击方暴击抗性` 这类形状；**动之前先确认这是不是策划要的** —— 现在的形状是照策划说明实现的。

## 5. 受伤飘字（伤害数字）

NPC 挨打时旁边弹出伤害数字，**1 秒后自动消失**；**暴击 / 会心的字号更大**（34 → 46），颜色也不同。

飘字本体 `Assets/Scripts/Npc/DamagePopup.cs`（**运行时现建**，场景里不用摆东西）；触发链 `NpcInstance.结算完成` 事件 → `NpcIndicator.处理结算`；开关是 `NpcIndicator.显示受伤飘字`（每个 NPC）与 `DamagePopup.开关`（全局）；样式在 `DamagePopup.默认样式`（存活时长 / 上浮高度 / 字号 / 颜色 / 层级）。

**关键：挂在事件上，而不是各个攻击里。** `NpcInstance.ReceiveAttack` 是**所有伤害的唯一入口**（飞剑普攻、主动神通都走它），在那里广播一次 `结算完成`，**所有伤害来源就自动都有飘字**。事件带完整的 `AttackResult`，拿得到 `暴击` / `会心`；已有的 `Damaged` 只有「实际扣了多少血」，判断不了是不是暴击。

> 反过来写（让 `NpcInstance` 直接 new 飘字）会把「模型」和「表现」绑死，`NpcInstance` 还会反过来依赖 `NpcIndicator`。现在是**视图订阅模型**，方向才对。

三档：普通命中 **34** 号、米白 `(1, 0.96, 0.86)`；**暴击**（物理）**46** 号、橙 `(1, 0.70, 0.16)`；**会心**（特殊）**46** 号、青 `(0.52, 0.86, 1)`。
动画：出现时从 0.55 倍弹到 1 倍（0.09 秒），期间**先快后慢地往上飘 1.1 米**，同时朝水平随机方向散开最多 0.5 米（免得连续几下叠在一起），最后 40% 时间淡出。

- **字体用 Unity 内置的** `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")` —— 伤害数字只有阿拉伯数字，**不用往 `Resources` 里塞字体资产**（既有做法见 `StationInteractor.取字体()`）。
- **WorldSpace Canvas，`sortingOrder = 200`** —— 必须比血条的 `100` 高，否则数字被血条挡住；朝向用和血条同一套 billboard 算法；用 `Time.time` / `Time.deltaTime`（受 `timeScale` 影响），暂停时数字一起定住。
- **飘字不跟随 NPC**：生成后留在原地往上飘。
- 每个飘字是一个**独立的 Canvas**（≈ 1 个 draw call）。焚天炎术一次打 4 个目标、每 0.56 秒结算一次、数字活 1 秒 → 实测**同屏最多 8 个**。目标数量上去要考虑对象池。

## 6. 怎么验证

物理必中专项脚本为`.dsh/_diag/physical-guaranteed-hit-check.cs.txt`，使用`exec_editor_script`。在0、0.08、10000三档闪避，普通/主动/被动三类攻击及双方互换下，3600次物理结算全部命中，闪避率为0，暴击/伤害路由保持；特殊普通攻击保留闪避，显式特殊必中与default(AttackSpec)检查通过。脚本保存并恢复Random.state，不扣真实角色血量。

`CombatCalculator` 全是纯静态函数，**Edit Mode 直接测**（不要靠肉眼读代码，也不要靠进 Play）：

```csharp
var 攻 = new AttributeSet();
攻[AttributeType.Attack] = 100f; 攻[AttributeType.CritDamage] = 2f; 攻[AttributeType.InsightDamage] = 3f;
var A = new AttributeCombatStats(攻);
var D = new AttributeCombatStats(守);
CombatCalculator.Resolve(A, D, AttackSpec.特殊主动神通);
```

关键是**两个轴隔离**验证：让 `暴击伤害 ≠ 会心伤害`、`普攻加成 ≠ 主动法术加成`，四种组合的数值应当两两可区分。示例期望值（`攻击=100 普攻加成0.2 主动法加成0.8 普攻减免0.1 主动法减免0.3 暴伤2.0 会伤3.0`，抗性设为必定触发）：

```
物理普攻 220   特殊普攻 330   物理主动神通 300   特殊主动神通 450
不触发加成时：物普 110  特普 110  物神 150  特神 150
```

```csharp
// 飘字三档并排看一眼最直观
DamagePopup.弹出(pos - 玩家.transform.right, 128f, false, false);  // 普通 34 号
DamagePopup.弹出(pos,                        456f, true,  false);  // 暴击 46 号
DamagePopup.弹出(pos + 玩家.transform.right, 789f, false, true);   // 会心 46 号
```

数数量和生命周期：每帧读 `FindObjectsOfType<DamagePopup>().Length`。实测施放焚天炎术后**同屏最多 8 个**，再等 1.5 秒残留 **0** ✔。

> 玩家暴击 / 会心数值很高（见上文），实际打起来**几乎每一发都是暴击或会心**，很难看到「普通」那一档 —— 想确认普通字号得用上面这种直接调 `弹出` 的办法。


## 体素环境与无锁定施放（2026-10-08）

宗门野外的地形破坏统一进入 `VoxelCombatDamage`，再由 `VoxelMapPilot` 分帧处理。NPC数值伤害仍走原结算入口；环境破坏按实际动作节点、弹道命中、冰柱扫描和落剑位置触发，不按按键瞬间直接挖洞。玩家飞弹可启用体素碰撞，敌方飞弹默认行为不变。

`PlayerManualAim` 挂在玩家身上，由 `ActiveSkillCaster` 自动补齐。无锁定时按住Alt显示引导，默认普攻；F选普攻、E选巨剑、1～6选技能槽，左键确认，松开Alt/右键/Esc取消。普攻的鼠标点只决定朝向，超出近战或神识范围也可出招；近战实际伤害仍由剑身接触决定，远程弹道终点限制在自身神识射程。邪眼独立攻击原始引导落点，仅在神识范围内且已启用、灵力和间隔允许时触发，不受普攻动作或冷却阻止，无Q键绑定。引导同时显示淡墨双线神识范围圈，边缘缓慢波动并贴合Terrain高度。主动技能与法宝仍保留落点距离、资源、冷却检查，不创建伪NPC。UI、演出、死亡和摆放状态拦截输入；Alt+F不会同时打开NPC/设施。调试挖掘开启时优先走P面板工具。

范围、技能覆盖和验证方法见 [正式地图体素环境](../guides/正式地图体素试点.md)。镇妖葫收服和禁锢锁链仍要求真实目标。

2026-10-08调整：八九玄功、太虚剑决与灵虚剑决的近战普攻取消体素破坏，手动方向攻击仍扫描武器接触到的生物。远程普攻、神通及法宝保留环境破坏；邪眼是独立被动，跟随近战瞄准时也仍可破坏引导落点。
