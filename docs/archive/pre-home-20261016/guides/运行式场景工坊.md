# 运行式场景工坊

2026-10-16 当前正式地图只管理个人洞府、宗门野外、镇妖塔内。古古村与宗门主场景已按用户指令退出正式工程，原有可复用外观素材继续保留。建筑功能迁为洞府建筑令；工坊没有另建一套家园物品保存格式。见[家园与镇妖阁](../../../design/家园与镇妖阁.md)。

更新：2026-10-16。五张正式地图已接入同一套地形、素材与功能记录。当前仍需要人工调整构图、植被疏密和局部美术衔接，不能把自动迁移视为已达到参考游戏的最终画面。

## 从哪里启动

Unity 顶部菜单 **修仙 → 场景工坊 → 地图管理与一致性检查**。

管理窗口列出古古村、个人洞府、太虚宗、宗门野外、镇妖塔内。每行有“打开游戏场景”“编辑这张地图”“应用已保存地图”。点“编辑这张地图”会打开独立工坊、运行并载入对应地图。

只想自由制作新地图：**修仙 → 场景工坊 → 打开地图编辑器**，随后点击 Unity 运行按钮。独立场景是 `Assets/WorldAuthoring/RuntimeMapEditor.unity`；`3C_Testbed.scene` 是个人洞府游玩场景。

日常工坊与五个游玩场景统一使用 **Built-in**，共用地图调色、描边和流动雾；当前没有全项目切换 URP。`WorldURP.asset` 及 URP 实验保留，只有明确开启 `WorldEditorPipelineScope.experimentalUrp` 才临时切换。渲染兼容修复及场景边界见 [本轮报告](../../../reports/场景迁移边界与渲染兼容修复.md)。

## 制作和保存

1. 在工坊中左键刷地形，右键旋转机位，中键或 WASD 平移，滚轮缩放。Ctrl+Z/Y 撤销／重做。
2. 用顶部“编辑／游戏视角”或 G 切换。游戏视角显示正式玩家的原尺寸模型与待机，WASD 可沿地面移动，便于检查房屋、树与道路比例；不启用战斗和存档逻辑。
3. 点“保存”或 Ctrl+S，写入仓库根目录 `maps/source/<地图名>.worldmap.json`。
4. **编辑五张正式地图时，点保存后停止工坊即可自动更新游戏地图**，下次读档会使用已保存的新版地形和外观，保留原功能引用。不再要求额外点“应用已保存地图”；该按钮仍保留作手动重试。新建的自由地图只保存文件，需导出才能成为独立关卡。

应用前会备份旧地图到 `.local/backups/map-apply/`。首次迁移的五个原场景完整备份在 `.local/backups/scene-migration-*`，不是覆盖原始文件后无法回退。迁移命令会跳过已经迁移的场景。

停止工坊自动写 `.last-session.json`，下次恢复；它不替代命名地图保存。已有同名文件保存会保留 `.bak`。用户地图未经确认不被样板或验收数据覆盖。

“加载”列表每张地图有“删除”，会连同 `.bak` 移入 `maps/source/.deleted/`，可点“恢复最近删除”；同名文件存在时不覆盖。删除只处理工坊保存文件，不删除正式 `Map.asset` 或游戏场景。当前正在编辑的地图仍留在内存，再次保存会重建文件。

“导出地图”仍用于新环境：停止运行后生成 `Assets/WorldAuthoring/GeneratedMaps/<地图名>/` 中的数据、环境 prefab 和独立场景。原五场景的长期工作流优先使用管理窗口的“应用已保存地图”。

## 地形、草、水与材质

- 新地图可选 256、512、1024 米。已有地图可对称扩展，坐标和原样本不重采样；最高 1025² 个样本，大范围地图通过降低采样精度容纳。只生成实际绘制区域的网格块。
- 抬升、降低、平滑修改同一地形。陡峭高差使用岩质表面与碰撞，普通地面保留浅纹理；包边使用七种主体岩石，沿长轴连续铺排，并避免相邻及闭环首尾重复。
- 草密度滑条 0～100%，随地图保存；默认约 55%，迁移地图为 45%。密度变化保留原刷草范围，设为 0 只隐藏草叶。
- 草刷使用每簇 24 片封闭弯曲草叶、312 顶点／528 三角形，按稳定随机分布实例化；下埋约 4 厘米。草土纹理向外扩约一米，避让实体素材、水域和岸坡。
- 18 种地表笔刷使用导入资源的真实砖路、石板、裸土、草土、森林地表、砂砾和雪／冰贴图。软边混合；“擦材质”恢复底层。画材质时草叶避开整簇范围，擦掉后恢复原刷草数据。
- “擦草”只清草；“填水池”恢复挖掘前地表；“恢复地面”同时清草、填池、清材质，可撤销。
- 水采用两套包的管线对应材质，岸边深度渐变。水域和岸坡为摆放禁区，按完整占地检查。
- 桥采用单独规则：桥身可跨水，两端桥头须有干地支撑，按模型实际桥面高度贴岸；旋转后仍按桥头检查，不再按整个矩形占地禁摆。需手动架空时使用“保留间隙”与摆放升降。普通房屋、石头和树仍避让水岸；可在已有桥身下挖水。
- 宗门野外已平滑迁移河道的覆盖场和岸坡，保留河道走向及物件布局，避免原二值投影造成的密集锯齿。
- “地图／雾设置”可降低雾面、调整流速与浓度。云雾使用岸线高度、三维噪声和深度截断，不自动生成团云或纯色底板；速度 0 可暂停。
- 太虚宗只生成固定在最低地基下方的流动云海（基准高度 -0.7 米，再叠加雾面偏移），不随高台抬升。此设置同时用于工坊预览与正式宗门地图；上层云雾由后续人工布置。
- 固定底层云海连续铺满，由真实地面深度遮挡，不按向下投影的陆地遮罩开洞，修复高差处可见的大块空白。

## 素材与墙体

素材库现有 **475 项可选素材**。新亚洲建筑包保留原有 3 栋完整建筑，并从示例整理完整亭子、带门扇门楼及两座完整桥，共 7 套建筑／桥，加上 26 项自然素材。55 项无引用的零散建筑组件和整组原始模型已从库中移除，后续更新不会重新加入；若旧地图使用退役组件，保留其隐藏引用以免破坏已摆内容。Far East 原有墙体模块继续保留。完整路径及尺寸见 [资源清单](../../../reports/工坊资源完整清单.csv)。新增资源后用 **修仙 → 场景工坊 → 更新素材库（保留地图）**，不自动替换已摆建筑。

Far East 与新亚洲建筑保留源贴图、颜色及细节，不统一压灰。纹理柔化仅作用于最初 `Art/Environment/Imported` 的旧建筑。亚洲包的 `_Albedo`、`_AlbedoColor`、UV 缩放与 `_Tiling` 显式转换，不能只读 `_MainTex` 而生成白膜；完整组合复制示例的网格、原材质及世界变换，不导入整个示例场景。

树木按种类校准尺寸。迁移地图用森林包的完整绿色乔木、松树和冷杉替代旧树；不使用单独树干、雪树或枯树随机填充。原建筑及其他物件尽量保留位置、完整旋转、镜像和非等比缩放。

点击素材显示模型本体预览。选择已摆物件后可旋转、移动、删除，均支持撤销。Q/E 或按钮旋转，角度可直接输入；普通网格有 0.25／0.5／1／2／4 米档位。

建筑尺度固定，不受全局物件倍率滑条影响。原 22 种墙、门、转角与栅栏有独立端口配置：庭院直墙 4 米、门 6 米、转角每臂 2 米；城墙及其他栅栏按自身模块规范处理。按本轮用户要求，新包的零散墙、柱、门扇及屋顶不再进入可选库；完整建筑和桥保持源尺寸的 1.25 倍校准。墙体吸附的是墙身连接面，已占端口不再吸附；开启时采用 90° 旋转，“整理相邻墙段”可修复附近偏位并撤销。源素材不被改写，派生网格与碰撞保存在 `Assets/WorldAuthoring/Modules/`。

自然摆石支持下埋、接触压暗、积尘及微小地表形变；需要架空或留缝时切换“保留间隙”并调整升降。原场景中带负缩放的 28 个外观 prefab 已把盒形碰撞烘焙成共享网格，保留原外观变换。

地图资产存于 `Assets/WorldAuthoring/Scenes/<原场景名>/Map.asset`。旧树实例共 2677 个已移除；737 个停用渲染组件退役。原建筑名称、功能组件和被引用的锚点保留，外观改由地图数据生成。

**原五个 `.scene` 全部继续保留。** 地图 JSON 和 `Map.asset` 是环境数据，不能替代原场景的任务、角色、交互和传送装配。备份及各类文件的恢复边界见 [迁移边界报告](../../../reports/场景迁移边界与渲染兼容修复.md)。

拓境令不再实例化旧地面。每次在相邻位置生成约 20×20 米的圆角地块，实测新增约 402 平方米，约初始洞府的四分之一；接入同一包边与碰撞。保存的扩建坐标会重放到当前洞府基图，摆放范围也检查新地形。

## 外观与功能分离

40 个原有功能模块以独立模板登记，覆盖修炼／炼丹等交互、传送、刷怪区／刷怪点和任务标记／触发区。地图物件用稳定 ID 关联功能，不把外观 prefab 与功能脚本绑死。

顶部“功能／检查”：先选择物件，再选择功能模板赋予它；可只移除功能、保留外观。无外观的功能挂点在工坊中用可选择标记显示，游玩场景不绘制这些标记。移动、旋转、删除与撤销会同步处理关联。工坊只编辑数据，不启动功能。

原五场景直接绑定保留的功能实例，保持既有序列化引用。新地图可实例化相同功能模板，先绑定引用再激活；功德堂、传法阁、执事阁通过功能角色配置装配，不依赖新模型或对象名称。含外部场景引用的模板，独立导出后仍需提供对应场景绑定，检查会指出缺失项。

管理窗口的“检查五场景”共用校验逻辑，核对素材、功能模板、物件关联、出生点、外部绑定及传送目标构建配置。任务行为、NPC、塔控、角色 UI 等继续由原游玩场景装配。

旧体素试点清单按旧模型及层级索引定位；转换地图不再执行该旧清单，避免扫描已删除树木并产生大量警告。新素材的体素破坏需要按新的模型重新烘焙，原体素系统和资源保留供后续接入。

## 工具维护和验证

七个过期村庄／野外构建器和旧清理器已连同 `.meta` 移至 `devtools/archive/legacy-scene-builders/`，不再由 Unity 编译或显示菜单。移出前检查外部类型调用；不删除现用角色、动画、配置和发布工具。重复英文菜单别名已取消，其余维护入口归入“修仙”相应子分类。Unity 自带 Jobs/Burst 和第三方菜单不属于项目的一次性工具。

维护入口是 `WorldWorkshopWindow`、`WorldSceneMigration`、`WorldMapEditorBuilder` 与共享地图运行组件；不为每张地图再生成一个独立工具。

验证配方：`devtools/validation/world-maps-scenes.cs.txt` 检查真实几何、源变换、地形高度、碰撞及功能绑定；`world-maps-gameplay.cs.txt` 在独立 Play 切换五场景，实测拓境与不依赖模型名的宗门功能；`world-authoring-wall-grass.cs.txt` 检查墙端口和可恢复的草密度／材质避让。报告、截图与存档校验只写 `.local/diagnostics/`，不保存验收中的游戏状态。

此前已通过 341 项工坊扩容／素材／操作检查及 12 项墙草检查；五场景几何与关联 599 项、实际游戏 82 项通过。Play使用显式Editor隔离存档目录，塔控自动存档也只写验证档；结束恢复正常目录并核对真实文件。记录见 [迁移报告](../../../reports/五场景地图迁移.md) 和 [一致性报告](../../../reports/五场景一致性检查.md)。这些检查不代表所有地形画法、素材组合与平台均已覆盖。
