# 宗门石台地面

`Sect.scene` 中的11块 `environment_stone_dabingshi` 石台在编辑器离线烘焙为7个高度组，资源放在 `Assets/Art/Environment/Sect/Platform_0～6.asset`，场景节点为 `Level/宗门圆角地面`。游戏直接加载成品，不在运行时重建。

顶面按0.7米采样，轮廓内缩再外扩1.6米形成圆角；外缘1.2米范围平滑收边，最大下降0.45米。邻近高度的平台使用1.5米平滑并集，去除同组内部坡边与重复顶面；相交的高低平台上沿保留落脚面，不把全宗门压成同一高度。建筑、道路、台阶和传送点的位置保持原样。

宗门保留原石板、岩壁材质和贴图。顶面UV从源三角形插值，上沿过渡带平滑连接到顶面中心高度下1.25米处的源岩壁截线，下方保留源岩体的收尖轮廓。接合使用原三角形的实际截线，不使用逐层凸包，避免高度组_6出现穿出岩壁的面片；截面缺失时停止烘焙，不回退到平台中心。不套用洞府草地。显示和碰撞共用生成网格。源FBX及材质未修改，场景内源节点保留、渲染和碰撞禁用，便于检查和调整。

制作入口为编辑器 `SectGroundBaker.烘焙()`，只允许在非Play的Sect执行；更新网格保持GUID，并只保存目标资产，不调用全项目SaveAssets。重新烘焙前保存场景并备份，检查结果后再保存Sect。修正既有网格可使用 `SectGroundBaker.烘焙(true)`，保持场景节点与引用，更新网格资产并刷新碰撞，无需重新保存场景。

验证入口为 `devtools/validation/sect-ground-editor.cs.txt`。报告和前后预览写 `.local/diagnostics/home`，检查原物件变换、原顶面碰撞支撑、材质、重复碰撞、顶面非流形边，以及过渡带两端贴合与内部行的连续性。2026-10-12修正后检查七个高度组的2,753段岩壁接合，接合点到原岩壁截线最大误差约0.000011米；246个顶面采样点全部有支撑，最大高度差0.44米，生成网格共73,284顶点。对高度组_6的近距离前后渲染确认突出面片消失。
