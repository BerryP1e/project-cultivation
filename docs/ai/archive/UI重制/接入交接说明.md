## 3. 三个必须知道的坑（都踩过）

1. **底板/页签的 `Image.color` 是深色**（`Window` 是 0.13 灰）。换 sprite 时**必须把 `color` 重置成白色**，
   否则"纸白 × 0.13 = 还是黑的"，看起来像完全没换。（第一版就栽在这。）
2. **换 sprite 不能改 `Image.type`**：进度条那条 `Fill` 是 `Filled`，改成 `Simple` 就没填充了。
   九宫格要 `Sliced` + **`pixelsPerUnitMultiplier = 2`**（2× 素材）；按钮包是 1× 交付 ⇒ 用 2.6。
3. **不要动场景、不要重跑生成器**：角色面板是 `CharacterPanelBuilder` 在编辑器里生成、**序列化进 5 个游玩场景**的，
   重新生成 + 存场景会把运行时 UI 列表一起重排（**踩坑 A8：写脏过 +19787 行**）。
   所以换皮与布局都走**运行时**（`场景自举` 补组件）。

## 4. 怎么跑、怎么验（照抄就能复现）

在 Unity 里进 Play（任意游玩场景），或直接用 MCP 的 `exec_runtime_script`：

```csharp
var ui = GameObject.Find("CharacterUI");
var 面板 = Object.FindObjectOfType<CharacterPanelUI>();
面板.SetOpen(true);                       // 也可以直接在游戏里按 I
yield return new WaitForSecondsRealtime(0.4f);   // ⚠️ 面板一开 Time.timeScale = 0，
                                                 //    必须用 **Realtime**，否则协程永远不返回（踩过，超时 400s）
foreach (var t in ui.GetComponentsInChildren<Transform>(true))
    if (t.name == "Tab_神通") t.GetComponent<Button>().onClick.Invoke();
yield return new WaitForSecondsRealtime(0.5f);
ui.GetComponent<UIInkSkin>().刷新();       // 换图 + 重排
yield return new WaitForSecondsRealtime(0.5f);
ScreenCapture.CaptureScreenshot("screenshots/verify.png");   // Overlay UI 只能 ScreenCapture，不能相机渲 RT
yield return new WaitForEndOfFrame();
```

**判据**：截图里能看到 ① 幕布是整幅山水纸 ② 左导航是一条立板且当前项有牌 ③ 六槽成环、有编号 1–6
④ 已悟神通是卡片网格 ⑤ 右侧详情**通高**且有大图框 ⑥ 底部保留「滚轮浏览 · 拖动滑块」。
