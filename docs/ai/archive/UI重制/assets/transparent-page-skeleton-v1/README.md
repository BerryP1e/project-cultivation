这一包补齐角色父页面的页面骨架：整块幕布／纸框、左侧导航轨道、普通导航标签、选中导航标签、标题牌和分隔线。所有 PNG 都保留 RGBA 透明通道；纸面或深色玉面是组件内部材质，组件外部透明。

parent-curtain-9slice-source.png 是 9-slice 参考源，Unity 中建议用四角不拉伸、边缘单轴拉伸、中心可平铺的方式重组。它不包含场景山水和角色。

左侧标签文字、图标和选中页状态应在 Unity 中单独叠加，这样背包、境界、神通、法宝、灵阵、战阵、坐骑、外观可以共用同一条父导航。
