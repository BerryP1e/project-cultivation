这些 PNG 全部是 RGBA（4 通道），外部背景透明，可直接作为 Unity Sprite 的初始皮肤素材：

- active-slot-frame：主动神通六槽的异形槽框
- parent-navigation-tab：角色父页面左侧导航按钮
- ability-library-card：已悟神通库卡片框
- enabled-passive-row：生效被动神通列表行
- scrollbar-track-and-thumb：列表滚动轨道与玉色滑块
- primary-action-button / secondary-action-button：主次操作按钮

卡片和列表内部的米色纸纹是皮肤本体，不是抠图残留；只有组件外部及镂空内部为透明。素材来自当前神通页的统一繁纹风格，文字和图标应在 Unity 中另行叠加。
