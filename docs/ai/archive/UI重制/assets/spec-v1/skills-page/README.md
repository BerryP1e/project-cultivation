本目录严格对应根目录的《素材规格与提示词.md》第 1 节。每个部件都是独立 PNG-32，外部透明；状态图从同一基础图派生，保持画布、中心和外形一致。

文件夹按用途分为 common、navigation、skills、status。九宫格边距和 2×尺寸记录在 manifest.json。

面板内部的纸面或玉面是材质本体；面板外部、异形槽位外部和空心环中央保持 alpha=0。文字、数字、图标、技能图和状态文本不烘进素材。
