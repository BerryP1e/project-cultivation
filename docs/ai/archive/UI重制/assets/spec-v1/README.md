本目录是按根目录素材规格文件生成的权威资源目录：

- skills-page/：第一优先级，神通页 21 个独立组件与状态；
- cultivation-alchemy/：第二优先级，丹房与修炼页组件；
- common-panels/：第三梯队通用面板组件；
- icons/：八项父页面功能图标；
- portraits/：对话表真实 ID 对应的透明立绘。

每个部件是一张独立 PNG-32，不是图集。所有输出已按规格表调整到 2×尺寸；九宫格边距记录在各目录 manifest.json。

旧目录 screen-studies/skills-assets-v1/ 和早期 large-ui-pieces-v1/ 是历史布局参考或组合稿，不属于本批最终 Sprite。
