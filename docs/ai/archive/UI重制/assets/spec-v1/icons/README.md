八项父页面导航和功能图标，统一为 256×256 RGBA PNG、透明背景、无文字。名称对应背包、境界、神通、法宝、灵阵、战阵、坐骑、外观。

这些是 UI 图标皮肤初版；数据侧的 DisplayIcon 可以在 Unity 中替换为具体物品、神通、法宝、灵阵、功法或坐骑图标。
