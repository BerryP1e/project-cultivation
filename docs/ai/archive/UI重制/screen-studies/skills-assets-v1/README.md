本包按 Unity 重组所需的功能层裁切出：父幕布与外框、父页面导航、六槽主动环、已悟神通库、生效被动列表、右侧详情、底部 HUD、两个滚动条，以及六个主动槽。裁片仍保留合成稿中的纸底与插画，用于布局验证和切图定位。

## 下一轮透明通道

真正的透明 PNG 需要从分层源图或单独绘制的 UI 皮肤导出。当前先保留纸纹和金线，避免对山水、阴影、金色边缘做有损抠图。既有透明繁纹按钮包在 assets/buttons/，可直接作为 Unity Sprite 参考。

## 交互归属

- 父导航固定；内容页签不滚动。
- 神通库与生效被动列表各自拥有独立滚轮和可拖拽滑块。
- 主动槽 1–6、右侧详情、底部 HUD 固定。
- 被动神通只在神通库与生效列表之间切换，不进入主动槽。
