# 神通界面定向修订
> **管什么**：只读保存的 UI 制作原始记录；不代表当前实现。
> **不管什么**：当前接入状态、资产位置和操作步骤见 [UI换皮](../../../../guides/UI换皮.md)。

依据用户标注截图修订，保留幕布、纸底山水、繁纹外框、场景及八项父页面导航。

- 删除右上角重复的头像、境界及进度；保留关闭入口。删除「六道灵枢」装饰标题与全部标注笔迹。
- 上方保留六个共用主动技能槽。被动神通不进入此栏，也不占底部主动 HUD 槽位。
- 下方划为两个主要区域：统一的「已悟神通」库，以及「生效中的被动神通」列表。神通库包括主动与被动，提供全部／主动／被动筛选。
- 库内停用的被动神通提供「启用」入口；生效列表显示启用状态及「停用」入口。选择被动时详情区也应提供对应启停操作，不显示主动装备操作。
- 两区独立滚动，显示轨道和滑块；神通库用部分露出的下一行提示内容溢出。未溢出的被动列表使用满长滑块，不假装还有隐藏条目。
- 鼠标滚轮只作用于悬停列表，装备槽、详情、页签和主要操作固定。保留选中与滚动位置；拖动接近列表边缘时自动滚动。

## 功能依据

`cultivation/Assets/Scripts/UI/UIPanelData.cs` 已存在 IsPassiveEnabled、被动启停及生效列表接口；已获得被动默认启用，停用与未获得是不同状态。此前对话没有核实就对被动开关作出推断，以代码为准。

`cultivation/Assets/Data/Tables/被动神通表.csv` 的真实条目为凭虚御风、千劫雷狱、雷云。修订示意中前两项启用，雷云停用，表达启用入口及生效列表之间的关系。状态仅为布局演示，不修改游戏数据。

凭虚御风与坐骑的互斥规则继续保留；视觉重排不改动该规则。
