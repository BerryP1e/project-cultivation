> **不管什么**：当前接入状态、资产位置和操作步骤见 [UI换皮](../../../../guides/UI换皮.md)。

本目录回应 2026-10-03 最新要求：依据已提供截图和项目文档，针对每个功能界面的实际使用场景，各生成三套完整示意图。统一使用已选定的「宣纸水墨＋繁纹按钮」；三版比较布局、面板形状、空间感与操作位置，不重新切换成三个不同题材。

范围：闭关修炼、境界突破、转修功法、背包、境界与属性、神通、法宝、灵阵、战阵、坐骑、外观、丹房、灵田互动、常驻 HUD。共 14 类 × 3 版 = 42 个整屏示意。

每个功能生成一张纵向 A/B/C 对照图，每一行是一张完整游戏屏幕；保留原对照图，并提供分开的 A/B/C 图片。图中文字与数值是示意，功能约束与文档来源见 specs.json；法宝／灵阵待开发状态明确标记。

这些是用于逐页选型的美术与布局方案，不代表已经替换 Unity UI。交互逻辑参考上一轮原型，但本轮交付重点是完整界面的多方案图册。
