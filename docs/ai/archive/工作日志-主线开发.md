## 3. 待办（按优先级）

### P1 物品效果引用回填（出包前必须）
`能力查找.按id<T>()` 用 `AssetDatabase`，只在编辑器下有效。目前导入器只给效果资产写 id、
不写引用，**打包后学习物品会失效**。
→ 做法：写一个编辑器步骤（或挂在导入器末尾），按 id 把引用也填上并 `SetDirty`。

### P2 胖叔走向玩家 + 锁操作
现状：二幕只有「去找小梅问问」，胖叔站在原地。
需要两个能力：
1. **`任务动作.走向玩家`**：追玩家**实时位置**（现有 `走向` 只支持写死坐标），
   到位后面朝玩家、切回 Idle
2. **增加第三个锁条件**：现在 `演出锁` 只看 `黑幕字幕.演出中 || DialogueUI.正在显示`，
   胖叔走过来那 2~3 秒两者都没有 → 需要 `任务管理器.剧情锁定` 这类静态开关

目标流程：接 q_main_002 → 胖叔走向玩家（锁操作）→ 强制对话 → 解锁 → 目标改为找小梅。

### P3 「处理凡间事务」是否还有剧情
策划原文只写「任务目标变为：料理好凡尘之事后和大师兄对话」，**没有独立剧情**。
等策划给台词与触发条件，再插到 `q_main_003_13` 之后、`dlg_act3_dashi_21` 之前。

### P4 演示任务噪音

### P5 第 13 阶段的 `飞到` 速度
