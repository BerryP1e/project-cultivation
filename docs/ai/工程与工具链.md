# 工程与工具链

更新：2026-10-16。工作区入口为 CODELY.md，业务文档从[INDEX](../INDEX.md)查阅。

## 环境

Unity 工程为仓库下 cultivation/；引擎 Tuanjie 2022.3.61t14，正式游戏和日常工坊为 Built-in。URP 包及部分第三方 asmdef 已导入，不代表全项目迁移。主菜单 StartScene，游玩场景为 3C_Testbed、Sect_Wilderness、Demon-Suppressing Tower；独立工坊在 WorldAuthoring/RuntimeMapEditor.unity。

CS、CSV 使用 UTF-8 BOM。新增类名和文件名采用 ASCII；不要顺手批量重命名已有中文类型。PowerShell 写多行代码应通过文件编辑工具，不用字符串拼接覆盖大文件；修改前保留工作区差异和本机备份。

## 编辑器控制

打开项目后从仓库根启动 devtools/unity/start-server.ps1 -Background。桥工具由 node devtools/unity/mcp-call.mjs list / schema / call 查询调用；先确认工具真实签名。unity_editor 的 get_state 检查 Play、编译和场景 dirty 状态。

exec_editor_script 可能停止 Play；运行验收用 exec_runtime_script。Refresh、切场景和重建前确认用户没有未保存编辑，不把当前游戏状态当作可丢弃测试夹具。脚本与参数包装见[devtools](../../devtools/README.md)。诊断、截图及一次性转换脚本写 .local/，不塞进 Assets。

原生粒子和拖尾应在实际 MonoBehaviour 协程中 WaitForEndOfFrame 后采样。桥的外部 IEnumerator 与手动 Camera.Render 不能替代连续 Game View 的透明抓屏验收。编译确认看当前 Console 和程序集时间戳，不从旧 Editor.log 尾巴推断。

## 当前维护入口

| 维护项 | 菜单/入口 |
| --- | --- |
| 地图编辑与应用 | 修仙 → 场景工坊 → 地图管理与一致性检查 |
| 独立工坊 | 修仙 → 场景工坊 → 打开地图编辑器 |
| 更新素材 | 修仙 → 场景工坊 → 更新素材库（保留地图） |
| 配置 | 修仙 → 从配置表生成资产；优先 DataTableImporter.ImportTables(false, 指定表) 避免重接场景 |
| 外观成品 | 修仙 → 外观 → 一键：生成表 + 导入 + 收集 |
| 通用装配 | 修仙 → 工具 → 场景装配 → 同步通用角色与UI到所有游玩场景，只处理当前三场景 |
| 检查 | 场景一致性、设施界面引用与工坊检查均使用当前场景名单 |

角色/UI 同步使用源场景副本和 MoveGameObjectToScene 重映射引用；不要直接 Instantiate 后留下跨场景引用。源场景是洞府，保留各目标的环境、玩家落点与相机必要配置。全量 UI 构建器会销毁重建，不能代替局部修复。

## Play 验收与版本控制

先用 world-maps-play-setup 建立真实存档指纹并启用隔离目录，结束停止 Play 后执行 world-maps-play-teardown。当前验收配方见[validation](../../devtools/validation/README.md)。不把真实角色存档和用户命名地图改成测试数据。

提交前分别做差异审查、暂存审查、commit、push，不串成一条未经检查的全量命令。用户要求 push 才推送。不输出远端内嵌凭据，不提交 .local、令牌、账号恢复材料、Library、Temp、日志与生成请求 JSON。新增大型导入资源按仓库 .gitattributes 使用 Git LFS，克隆者先安装 Git LFS，再拉取对应大文件；不重写既有 Git 历史。

旧的五场景菜单和工具说明见[工具链历史快照](../design/当前游戏体系.md)，不按它恢复已退役主线。具体安全规则仍查[工作规范](工作规范.md)。
