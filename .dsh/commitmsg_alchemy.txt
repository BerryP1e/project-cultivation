## 三、UI（`炼丹界面` 整个重写，按用户那张图）

```
丹房                                        灵气 150/150
┌──────────┐ ┌───────────────────┐ ┌──────────────┐
│ 成品预览  │ │ 各种信息的提供      │ │ 获得的丹方    │
│ 聚气丹    │ │ 【材料】…           │ │ [聚气丹]亮    │
│ 1 品      │ │ 【1品丹】成功率 耗气 │ │ [清障丹]亮    │
└──────────┘ └───────────────────┘ │ [愈伤丹]暗…   │
┌────┐┌────┐┌────┐┌────┐┌────┐    └──────────────┘
│主材 ││辅材 ││辅材 ││辅材 ││辅材 │    ┌────────────┐
└────┘└────┘└────┘└────┘└────┘    │   开 炼 ！   │
              提示行                  └────────────┘
                [ 关　闭（ESC / 再按 F） ]
```

- **只列已学会的丹方**（没学会的不显示）；材料够 = 亮、不够 = 暗并标「（缺料）」
- 材料格：第 0 格主材、其余辅材（最多 4 格），逐格「名 ×需（有 N）」，够=绿底 / 不够=红底
- 右下大红「开炼！」，材料不足时变暗；列表是 `ScrollRect`（丹方多了可以滚）

## 四、实测（Play，宗门）

| 检查 | 结果 |
|---|---|
| 未获得任何丹方 | `已学会=0 条`，界面只写「还没有学会任何丹方」✔ |
| 给 4 张丹方 + 材料 | `已学会 4 条`，四个都 `能炼=True` ✔ |
| 点第一行 → 点「开炼！」 | `[炼丹] 聚气丹 1品 耗气8 成功率90% → 成功 ×1`，提示「炼成「聚气丹」1 品 ×1（成功率 90%）」✔；顺带勾上日常循环的「炼一炉丹」 |
| 行高 | 布局组 `childControlHeight` **必须 true**，否则不认 `LayoutElement.preferredHeight`（实测每行默认 100 高 ⇒ 第 4 条被裁出可视区）；改后 4 行都是 **46** ✔ |
