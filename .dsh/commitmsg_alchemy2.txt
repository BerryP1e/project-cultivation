炼丹界面的交互：材料格/成品框可点、右侧丹方↔背包切换、手动摆料按配方匹配

用户第二轮要求（原话）：
「主材和辅材的点一下后右边的丹方框会变成背包，可以往里面放东西，成品结果的框点一下后会变成丹方的框，
点击对应丹方后就是现在的模式，点击高亮可炼制的丹方自动放好预制的材料」
另两条口径：**手动摆的材料要和某个已学会丹方的配方完全一致才能炼**；**背包列全部物品**。

## 做了什么（`炼丹界面.cs` 重写交互层，布局不变）

| 交互 | 行为 |
|---|---|
| 点**主材 / 辅材格** | 右侧从「获得的丹方」切成「**背包**」，之后点背包里的东西就放进"当前选中的那一格"；正在选的那一格描成高亮色 |
| 背包里点同一样（同一格） | 数量 +1（所以「生灵草×2」＝点两下） |
| 背包里点别的 | 换掉该格，数量回到 1 |
| 点**成品结果框** | 右侧切回「**获得的丹方**」列表 |
| 点某个丹方 | 高亮它 + **自动把它的预设材料填进格子**（就是原来那套） |
| **开炼！** | 点过丹方 → 按丹方炼；自己摆料 → **要求和某个已学会丹方的配方完全一致**（按 id 的总数量比），不一致 ⇒ 提示「这些材料配不出丹方」，**不扣材料** |
| 成品结果框 | 结算认得出来就显示那颗丹（手动摆对时显示「聚气丹 1 品」），认不出显示「?（配不出）」 |
| 新增「清空材料」 | 一个 200×46 的小按钮（手动摆料要有地方清） |

## 实测（Play，宗门）

```
点主材格 → 背包行数=30（去重后）
放 生灵草×2 到主材、凝露花×1 到辅材0
   → 主材=[生灵草 ×2 (有 13)]  辅材0=[凝露花 ×1 (有 13)]   预览=聚气丹 1 品      ← 自动认出配方
开炼 → [炼丹] 聚气丹 1品 耗气8 成功率90% → 成功 ×1
        提示=炼成「聚气丹」1 品 ×1（成功率 90%）
点成品结果框 → 丹方行数=4（背包已隐藏）✔
点丹方0（聚气丹）→ 槽位自动填好 → 开炼 成功 ✔
摆错东西（把「生灵草**种**」当主材）→ 提示「这些材料配不出丹方…」且不扣材料 ✔
```

## 顺带修掉一个真 bug

背包列表原来**按"堆"列**（`UIPanelData.物品` 每 `给物品` 一次就多一条）—— 实测 44 行里有 7 行重复的「生灵草」、
3 行「回春丹」。现在**按 `物品id` 去重**，数量取 `物品数量()` 合计（44 → 30 行）。
