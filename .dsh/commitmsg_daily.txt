第四阶段「日常循环」成形：四件事清单 + 「今日」面板 + 两大伏笔按天发酵

用户选了方案 A：机制打通 + 「今日」面板 + 伏笔按天发酵（为「灵田异变 / 塔解封」留钩子）。

## 一、四件事的日常循环（新增 `Core/日常循环.cs`）
| 项 | 判据 | 方式 |
|---|---|---|
| 收灵草 | `灵田.收获` 事件 | 订阅 |
| 炼丹 | `炼丹炉.炼制完成` 且 `结果.成功` | 订阅 |
| 打坐修炼 | `时间管理器.今日次数 > 0` | 轮询 |
| 进镇妖塔 | 场景名 == `Demon-Suppressing Tower` | 轮询 |

- 前两件有现成事件就用订阅（失败的一炉不算）；后两件状态本来就在别处维护（`今日次数` 每天自己
  归零、场景名每帧能问），**再引一层事件反而多一处会断的线**。
- 跨天**只比对 `时间管理器.当前天数`**，不订阅 `过了一天` —— 那个事件只在时间推进时发，
  读档进来不补发；天数比对两条路都覆盖。
- 订阅用 `Update` 里的**补齐订阅**：切场景后 `灵田.取()` / `炼丹炉.取()` 会换成新实例，
  换人就重订（绕开"Start 订阅 + OnDestroy 退订追不上重建"那类坑）。
- 清单进存档（天 + 位掩码），读档回到同一天时勾还在。

## 二、「今日」面板（新增 `UI/今日面板.cs`）
右下角：`今日 · <纪年>` + 四行 `○/✓`（完成变绿）+ 汇总 `n/4　修炼机会 x/10`。
- **第一版放右上角、实测和 Toast 叠在同一行**（截图里"新的一天"和日期糊在一起）⇒ 挪到右下角
  （血条/快捷栏/主线追踪都在左半边，右下是空的），`sortingOrder 2390`（比纪年 2400 低一档）。
- `Text.text` 只在真的变了才赋值（每帧无脑赋值会白白重排版）。

## 三、两大伏笔的异象等级（新增 `Core/伏笔管理器.cs` + `Core/伏笔表现.cs`）
| 线 | 起点（对话标记） | 节奏 | 满级 |
|---|---|---|---|
| 灵田异常灵气 | `q_伏笔_灵田异样`（阶段37） | **每 2 天**一级（第 2 级要第 4 天、第 3 级要第 6 天） | 3 |
| 镇妖塔妖力共鸣 | `q_主线_塔已讲解`（阶段33） | **每进塔 2 次**一级 | 3 |

- **塔线起点为什么不用阶段38**：阶段38 要炼气五层、是长线钩子，伏笔要"发酵"就得从**开始刷塔**
  那一刻起有反馈 ⇒ 阶段38 改成这条线的"正式揭示"（机制一条、剧情一条，不冲突）。
- **为什么要"起点天 / 起点次数"锚点**：只按"天数 % N"算的话，阶段37 之前攒的天数会
  **一次性追补成满级**（进洞府瞬间三级异象）。
- 表现：灵田每块地上飘 `等级` 个绿色自发光**灵气珠**（上浮循环）；塔里每 `max(4, 9-2×等级)` 秒
  一次共鸣提示 + 一层极淡红色**全屏泛光**（`sortingOrder 2200`，压在 HUD 下方不挡字）。
- ⚠️ **微光第一版看不见**：0.10~0.18 米 + alpha 0.26，8 米外的相机里不到 8 像素又半透明 ⇒
  改成**不透明自发光**、0.22+0.07×等级 才一眼能认。教训：**"加了特效" ≠ "看得见"**。

## 四、接线 / 存档 / 顺带修的 UI 坑
- `场景自举.补玩家与相机()` 新增 `日常循环 / 今日面板 / 伏笔管理器 / 伏笔表现` 四个组件
  （和纪年 HUD 同一处，**不写进场景**）。
- `SaveData.当前版本` 13 → **14**，新增 `日常_天 / 日常_掩码 / 伏笔_灵田 / 伏笔_塔`
  （加法字段，老档 = 天 -1 / 掩码 0 / 两条线 0 级）；`SaveSystem` 读档 + 存档各接一段。
- **`ToastUI.顶边距` 24 → 104**：右上角纪年 HUD（顶边距 18 + 约 70 高）和 Toast 本来会叠在同一行。
  ToastUI 是 `提示()` 里 `AddComponent` 现建的，位置只来自脚本默认值 ⇒ 改这里就全局生效。

## 实测（Play，洞府 3C_Testbed）
- 自举四组件都在相机上 ✔；面板文本逐行正确（`今日 · 太虚历…` / `○ 收一次灵草` /
  `○ 炼一炉丹` / `✓ 打坐修炼一次` / `○ 进一次镇妖塔` / `0/4　修炼机会 3/10`）✔
- 打坐：`加日常机会(1)` → `消耗一次修炼()` = True ⇒ `[日常] 完成「打坐修炼一次」→ 1/4` ✔
- 收灵草：放一块田 → 种生灵草 → `推进生长(99)` → `收一块` 收获 ×3 ⇒ 完成「收一次灵草」→ 2/4 ✔
- 入塔：把 `塔场景名` 临时改成当前场景名 ⇒ 立刻勾上 ✔（轮询判据有效）
- 跨天：`推进(4.2)` ⇒ 两条「新的一天」日志 + 清单自动清空 ✔
- 伏笔：打上 `q_伏笔_灵田异样` + 推进 4.2 天 ⇒ **1 级（第 2 天）→ 2 级（第 4 天）**，两级台词都进日志 ✔
- 微光：`2 个（地块 1 × 等级 2）`、单个直径 **0.36 米** ✔
- **布局数值复核**（1920×1080 屏幕坐标，y 向上）：纪年日期 y=1047 / 修炼机会 y=1015（占 1002~1062）；
  Toast「新的一天」y=**950**（934~966）⇒ 落在纪年下面不重叠 ✔；今日面板底板 (1896,22) 420×186，
  四行文字 y 109~190 全在板内 ✔
