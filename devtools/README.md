# 项目开发工具

| 目录 | 用途 |
| --- | --- |
| [unity](unity/README.md) | 本地编辑器 HTTP MCP 启动与调用 |
| [validation](validation/README.md) | 当前流程可复用的 C# 验证配方 |
| maintenance | 只读资产依赖输入与 GUID 引用检查 |

从仓库根运行，Unity 工程是 cultivation。输出写 `.local/diagnostics`；不保留源下载、一次性资产转换器或旧 DSH 程序。项目规则见 [资产与目录](../docs/architecture/资产与目录.md)。
