# 旧实体伴龙回归

这些配方记录 2026-10-14 早期的实体龙日常跟随、扑翼/滑翔、后摇再吐息与固定窗口实现。当时分别通过吐息89项、随行35项、AI/UI17项、动作12项。

用户随后改为鬼火日常、停用预热模型、短促即时续吐与单轮预算，因此这些历史配方不适用于当前运行时，不再作为验证入口。当前使用上层的 `chedian-ghost.cs.txt` 与 `chedian-ghost-preview.cs.txt` 与 `chedian-channel.cs.txt`。骨架、17段派生动画与坐标仍可用 `chedian-editor.cs.txt` 和 `julong-coordinates.cs.txt` 检查。
